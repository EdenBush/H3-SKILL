# 目标画幅（target_aspect_ratio）

画幅是**成品图的画布比例**，不是提示词的气质。它必须比正文先定，因为画幅一变，构图、取景、元素的占比都会跟着变。

---

## 一、优先级

```
用户明确选的比例  >  指令里写明的目标比例/尺寸  >  主参考图的比例  >  16:9
```

### 1. 用户明确选了具体比例

直接照抄，一个字都不改。`3:2` 就是 `3:2`。

任何正整数 W:H 都合法，不限于预设列表，也不受"支持范围"限制。

**用户的这个选择可以覆盖指令里与之冲突的画布措辞**，但指令里其它不冲突的内容约束仍然有效。

### 2. 用户选了 adaptive（自适应）

按下面的顺序判：

**a. 指令里写明了最终的画幅或尺寸**
以指令为最终几何依据，而不是源图几何。精确数字优先于笼统的"竖屏/横屏"。只给了朝向时：超宽 `21:9`、横 `16:9`、方 `1:1`、竖 `9:16`。

**b. 没有明说，就找主参考图**
主参考 = 提供被编辑底图或整体目标构图、且有可用比例的那张。优先级：

```
明确指定的画布/构图参考 > 被编辑的底图 > 整体构图锚点
```

同级打平时按图片顺序取靠前的，跳过缺失或无效比例的。**只提供身份、物件、颜色、风格的图不决定画幅。**

找到起点后，**照抄它的比例**，除非这次编辑本身要求换个画布形状。单纯等比放大缩小、或改某个主体的尺寸，不需要改比例。

**c. 需要扩展或裁切时**

若比例变化是明确可算的：

```
目标比例 = 参考比例 × 宽度缩放 / 高度缩放
（两个缩放都相对于原画布）
```

结果化成最简整数比。

算不出唯一比例的，选一个能容纳目标结果、又尽量保住无关构图的比例。**只为这次编辑需要而调整，不为好看而调整。**

### 3. 都没有

输出 `16:9`。

---

## 二、几个容易搞错的地方

| 误区 | 正确做法 |
|---|---|
| 拿参考图的元数据当目标比例照抄 | 只有在没有别的依据、且不涉及画布变形时才照抄 |
| 因为主体是竖的，就判成竖屏 | 主体朝向不等于画布朝向 |
| 因为用了广角，就判成横屏 | 镜头感不等于画布比例 |
| 参考图是一张多宫格拼图，就拿整张的比例当单格比例 | 宫格的行列数、单格、图内物件、图内文字都不是整张画布比例请求 |
| 把元数据当成图里的文字 | 元数据只用于判定，不进正文 |

---

## 三、比例与描述必须一致

画幅定完之后，正文必须与它自洽：

- 如果画幅变化**导致了重新构图**，Part 2 里相关 Subject 就不能说"完全保留"，Part 3 要写构图变化的后果。
- 如果画幅变化**只是裁切/扩展，元素本身没被重绘**，可以判保留，但要在概述里说清"画布扩展/裁切"这件事。
- 不要一边写着"整体构图完全保留"，一边在正文里把元素挪了位置。

---

## 四、序列化

- 输出 `W:H`，两个正整数，无空格，必须是最简整数比。
- 永不输出 `adaptive`。
- 用户给的具体选择、指令里的精确比例、未变动的参考图比例，都要**原样保留**。
- 其它数字比例或目标尺寸换算成最简整数比，不要向上取整到某个预设值。

---

## 五、检查

- [ ] 用户有具体选择吗？有就照抄了吗？
- [ ] 是 adaptive 吗？按 a→b→c 的顺序判了吗？
- [ ] 主参考的选择依据是"画布/构图"，不是"身份/颜色/风格"吗？
- [ ] 扩展/裁切有唯一解时，算对并化到最简了吗？
- [ ] 正文描述与最终画幅自洽吗（有没有一边说全保留一边改构图）？
- [ ] 输出是 `W:H` 最简整数比、无空格吗？
