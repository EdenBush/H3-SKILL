# 文字、数据与表格的转录规则

图片编辑模型对文字的处理是最容易失守的地方：写模糊了它会糊，写错了它会照着错的画，翻译了它会画成翻译后的字。

---

## 一、三条铁律

**一、源状态的每一处可读文字，在 Part 1 逐字记录一次。**
包括那些指令里要改掉的。原因：不记录源状态，模型就不知道自己改的是哪个字。

**二、目标状态的每一处文字，在 Part 3 写完整的最终结果。**
不许只写"把 A 改成 B"——要写改完之后那一整行长什么样。

**三、不许用替代品。**
禁止 `<Subject N>` 代替文字内容、禁止"一段标题文字"、禁止"若干行"、禁止 `etc.` / `and so on` / 省略号。原文自带的省略号要保留，但不能用它省掉内容。

---

## 二、转录格式

| 项 | 做法 |
|---|---|
| 包裹 | 单引号 `'...'` |
| 语言 | 保留原语言与文字系统，不翻译（除非明确要求翻译） |
| 标点 | 原样保留，包括大小写、全半角、顺序 |
| 多行 | 按阅读顺序逐个单引号串行写出，用散文说明换行位置 |
| 不可读 | 中性描述"该区域文字无法辨认"，不许猜 |

示例（一张海报）：

```
The text in the upper area of <Picture 1> is <Subject 2>, reading '春日出游' on the first line and '4月1日至5月5日' on the second line.
```

---

## 三、翻译任务

用户要求翻译时：

- Part 1 记录**原始**文字。
- Part 3 写**译文**，完整的最终版本，不是"把它翻译成英文"这种指令。
- 说明译文放在哪一行/哪个位置。

```
<Subject 2> is partially preserved; its position, font size and colour remain, while its wording changes. The line now reads 'Spring Outing' above 'April 1 to May 5'.
```

## 四、图表与数据

### 需要做的前置判断

1. 哪些值是可读的？（只处理读得出来的）
2. 这次编辑动到数据的哪一部分？（改某个系列、加一列、改标题）
3. 有没有需要交叉核对的数量关系？

### 交叉核对的三种情况（只在这三种情况下做）

| 图表类型 | 核对什么 |
|---|---|
| 分组柱状图 | 柱的组数是否与图例条目数一致 |
| 雷达图 | 每个轴的数值是否都有对应 |
| 互斥百分比构成 | 各份是否约等于 100% |

**不要**把这些假设强加到其他图表类型上，也不要强加到不完整、可重叠、多选的类别上。

### 源图自身有矛盾怎么办

只记录看得见的证据，或记录不确定性。**不许悄悄替它归一化、修补。**

```
The three legend entries in <Picture 2> are <Subject 4>, labelled 'A', 'B' and 'C', while only two bar groups are visible.
```

如果用户明确要求"修正"，修正值必须来自用户提供或可推导的数据，不许编造真实数据。

### 部分保留的图表关系句

要说清保留与改变的类别：

```
<Subject 3> is partially preserved; the title, both axis labels and all readable values remain, while the colour of the 'B' series changes from pale blue to deep ochre.
```

## 五、UI 与界面

UI 文字按行处理，和海报一样。特别注意：

- 按钮文字、占位符、选项卡标签都属于可读文字，要逐条记录。
- 界面元素的位置关系（左上、右上、底部横条）在 Part 1 里作为定位信息写出，不需要为每个元素建 Subject。
- 手机/平板屏幕上的内容如果是原图的缩略显示，按"内嵌图"类型处理。

---

## 六、用户要求"写文案"的情况

如果用户要的不是图里的字，而是**另外给他一段文字**（文案、标题、介绍语），那就：

1. 这段文字是**交付物本身**，不是图里的元素。
2. 完整写出来，放在 Part 3 的文字交付部分，或作为回复里单独的一段。
3. 明确它的去向：是"作为文字回复提供"，还是"渲染进图的某个位置"。

两种去向的写法完全不同，选错会让模型把文案画到图上。

```
（文字交付，不进图）
The accompanying copy, provided as text rather than as part of the image, reads '...'.

（文字交付，进图）
A new line of text reading '...' is set across the lower third of the frame in white serif type, left-aligned.
```

---

## 七、检查

- [ ] 每处可读源文字是否在 Part 1 逐字记录？
- [ ] 改动过的文字是否在 Part 3 写出了完整的最终整行？
- [ ] 有没有用 `<Subject N>` 或"一段文字"代替内容？
- [ ] 有没有翻译不该翻译的内容？
- [ ] 多行文字是否按顺序串行写出、并说明了换行位置？
- [ ] 图表数值是否逐条列出，没有塌缩成"若干数据"？
- [ ] 源图矛盾是否只是记录，没有被悄悄修复？
- [ ] 用户要的文案是"进图"还是"作为文字回复"，去向写清了吗？
