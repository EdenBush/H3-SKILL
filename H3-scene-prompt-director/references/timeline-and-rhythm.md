# 时间轴与节奏编排

## 一、节拍预算的基本公式

**节拍数 = ⌈时长 ÷ 1.2⌉，末拍延长 1.4–1.6 倍。**

这个 1.2 秒不是玄学，它来自两个约束的交叉：

- **下限**：一次可感知的身体变化（呼吸一次、潮红走一段、手指抬起到落下）至少需要 0.8–1.0 秒，低于这个数，模型会把它压成一帧过渡，观众看不到。
- **上限**：超过 1.5 秒的单一状态，观众会开始觉得"卡住了"。10 秒片子里超过 2 秒的静止，必须是有意的（台词窗口、定格），而且要让镜头或环境提供一点变化（手持漂移、光线微动）。

| 时长 | 节拍数 | 末拍 | 可用转折数 |
|---|---|---|---|
| 4–5s | 4 | 1.2s | 0（只能做一件事） |
| 8s | 6–7 | 1.4s | 1 |
| 10s | 8–9 | 1.6–1.8s | 1（够了） |
| 15s | 12–13 | 2.0s | 1，勉强 2 |

**转折数不要贪。** 10 秒里塞两个转折，每个转折只有 2.5 秒来建立，观众反应不过来。一个转折 + 一个收尾，是 10 秒的最优结构。

## 二、时间码语法

统一写成闭开区间的形式：

```
0.00-1.20s: [这一拍唯一的变化]
1.20-2.40s: [下一拍唯一的变化]
```

规则：

1. **前一段的终点 = 后一段的起点。** 不允许重叠，也不允许留空。留空 = 空白帧，重叠 = 动作打架。
2. **保留两位小数。** `0.00-1.20s` 而不是 `0-1.2s`。精度一致，模型处理更稳。
3. **总时长写在最后一段的终点。** 最后一段结束时间必须等于声明的生成时长。
4. **每一拍以冒号结束，后面接一句完整的英文句子。** 不要写成短语列表。

**关于模型的执行精度**：H3 实测切点误差在 ±0.25 秒以内，超过 0.25 秒的偏移偶发。所以：

- 关键切点尽量放在整拍边界上（3.0 / 6.0 / 9.0），不要放在 3.7 这种位置。
- 成片会比请求时长多 0.5–0.6 秒。**10 秒请求 → 实际 10.5 秒左右**，所以最后一段可以多留 0.3 秒余量，让收尾不被截断。
- 需要精确到 0.1 秒的动作（比如手指触碰的一瞬），写进段落描述里比写进时间码更可靠。

## 三、四种节奏型

节奏不是"快慢"，是**变化的分布方式**。四种够用。

### 型 A：慢—慢—快—停（上升）

```
0.0–2.4  慢：建立，只有呼吸
2.4–4.8  慢：叠加第二层（潮红）
4.8–7.2  快：叠加速率提升，动作幅度加大
7.2–10.0 停：放慢，收在一口长呼气
```

用于情绪上升。关键是第三段必须比前两段明显快，否则整段是一条平的斜线。

### 型 B：快—慢—停（衰减）

```
0.0–2.4  快：残留在高峰状态
2.4–4.8  慢：幅度开始回落
4.8–6.0  停：定格或极缓
6.0–10.0 转折：一个打断，然后重新定格
```

用于事后戏。注意衰减必须真的在减，不能一上来就是"已经很累"的状态，那没有"退潮"感。

### 型 C：停—慢—快—爆（转向）

```
0.0–1.2  停：不动，只有一丝异常
1.2–3.6  慢：逐步确认
3.6–6.0  快：情绪到位
6.0–8.4  爆：台词
8.4–10.0 收：扭头/别过脸
```

用于反转、愤怒、喜剧。前三段全部为最后 2.4 秒服务。

### 型 D：三拍制（5 秒短版）

```
0.0–1.2  建立
1.2–2.4  变化
2.4–5.0  收束
```

短版没有余地做转折，只能做"一件事的完成"。

## 四、节拍边界不均匀原则

**不要把所有拍都切成 1.2 秒。** 均等切分会让 10 秒读起来像节拍器。

分配原则：

- **动作点给短**（0.9–1.1s）：手伸出去、身体下沉、头转动，这类动作本身快，给短反而有力。
- **情绪点给长**（1.4–1.8s）：表情变化、眼神移动、呼吸转换，需要时间被看清。
- **转折点给最短**（0.6–0.9s）：认知的一瞬是快的，"意识到"比"思考"短。
- **末拍最长**（1.6–2.0s）：收尾需要留白。

示例（10 秒，9 拍）：

```
0.00-1.20  1.20  建立
1.20-2.40  1.20  呼吸转换
2.40-3.30  0.90  动作（手进入）
3.30-4.60  1.30  潮红
4.60-5.50  0.90  动作（下沉）
5.50-6.80  1.30  颤动
6.80-7.50  0.70  转折（认知）
7.50-8.60  1.10  台词前半
8.60-10.00 1.40  台词后半 + 收尾
```

## 五、台词窗口的编排

台词需要三样东西同时成立，缺一样就对不上口型：

| 要素 | 要求 |
|---|---|
| 时间窗口 | 足够长。中文语速约每秒 4–5 字，加停顿再加 30% 余量。12 字的句子需要 3.0–3.5 秒 |
| 画面稳定 | 窗口内镜头完全静止，焦点锁死 |
| 脸可见 | 景别不能小于中近景，不能被头发、手、阴影遮住 |

**拆句原则**

- 一句超过 10 个字就拆。
- 拆点在语义停顿处，不在语法停顿处。`说好做完这次，/ 要给我买 token 哦` 比 `说好做完这次要给 / 我买 token 哦` 好。
- 两段之间留 0.6–1.0 秒停顿。这个停顿是全片信息密度最高的地方，观众会自己往里填东西。
- 第二段通常更快、音更高；除非是"越说越小声"的委屈型，那第二段更慢更低。

**破音与气声的位置**：第一个字。情绪崩溃的物理证据必须在开口那一瞬，放到句尾会显得像演完再补的。

## 六、时间码与动作的对应表

写每一拍时问自己一个问题：**"这一拍结束时，观众看到的东西和这一拍开始时有什么不同？"**

答不上来，这一拍就是废拍，删掉或合并。

| 拍类型 | 起止差异应该是什么 | 举例 |
|---|---|---|
| 建立拍 | 无 → 有一个明确的身体状态 | 从静止到第一口深吸 |
| 动作拍 | 位置 A → 位置 B | 手从画面外到触到皮肤 |
| 反应拍 | 表情 A → 表情 B | 眉毛从平到收紧 |
| 过渡拍 | 节律 A → 节律 B | 呼吸从深到浅 |
| 转折拍 | 状态 A → 状态 B（不可逆） | 从放松到僵住 |
| 收尾拍 | 动态 → 静止 | 从移动到定格 |

## 七、常见编排错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 时间码留空 | 空白帧，画面像卡了 | 补满，首尾相接 |
| 时间码重叠 | 两个动作抢同一个身体部位 | 拆开，串行 |
| 一拍塞三件事 | 三件都只做一半 | 拆成三拍 |
| 全部 1.2 秒均分 | 像节拍器，没有轻重 | 按第四节不均匀分配 |
| 转折放在最后一秒 | 观众来不及反应 | 转折最迟在总时长的 70% 处 |
| 台词窗口有运镜 | 口型必散 | 窗口内锁死 |
| 台词塞在背影/微距镜头 | 模型强行插一张脸进来 | 台词只放在脸可见的镜头 |
| 10 秒请求按 10.0 秒切最后一拍 | 成片 10.6 秒，收尾被截 | 最后一段多留 0.3 秒余量 |

## 八、检查清单

- [ ] 节拍数是否等于 ⌈时长÷1.2⌉？
- [ ] 时间码是否首尾相接、累加等于时长？
- [ ] 末拍是否延长到 1.6 秒以上？
- [ ] 每一拍是否能用一句话说出"变了什么"？
- [ ] 节拍长度是否不均匀（有短有长）？
- [ ] 转折是否在总时长的 70% 之前？
- [ ] 台词窗口是否 ≥ 字数÷4.5 + 0.8 秒？
- [ ] 最后一段是否多留了 0.3 秒余量？
