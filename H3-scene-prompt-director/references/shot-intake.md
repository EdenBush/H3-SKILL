# 接镜规程：每个单元开工前的五步（第 0–4 步）+ 2.5 设计预演

**这份文件的目的**：让这套流程**不依赖某一个模型的记忆力和判断力**。

前面那些文档讲的是"规则"（什么该做什么不该做）。这一份讲的是**动作**——每个单元开工前，按顺序做完这五件事，再动笔。

五步 + 一次设计预演走完，你会得到：一张状态卡、七行读图笔记、一句戏眼、一个主设计支点、一个视角决定，以及一条组装好的提示词。前五样直接就是七段骨架的骨架，最后一步把它们装进去。

> **为什么必须走完**：跳步的人会觉得"我都记得"，然后在第 4 个单元开始漂。换成上下文短的模型、或者换一个没跑过前几轮的 agent，跳步会立刻崩——因为它连"记得"的资格都没有。

---

## 第 0 步：填状态卡（从上一单元交接）

**在写任何提示词之前，先把这张卡填出来。** 它不是给自己看的笔记，是**给下一个接手的人（或模型）看的交接单**。

### 模板

```text
【第 __ 单元 · 状态卡】

■ 空间
  房间：____________（例：古宅卧室，床头侧有拔步床，门侧有格扇门与条案）
  他：在 ____________（例：床那侧，半撑起，臀部不离床面）
  她：在 ____________（例：门那侧，站在格扇门前，面向床）
  两人距离：____________（例：约两步，中间隔着月光格纹的地板）

■ 物件
  他手上：____________（例：空，双手撑在身侧）
  她手上：____________（例：银色小刀，垂在右手，刃朝内）
  其他道具：____________（例：桌上茶盘、圈椅、烛台两只）

■ 服装状态
  他：____________（例：灰紫T恤、黑裤、赤脚）
  她：____________（例：一字肩白纱裙、披到脚踝、露肩、赤脚）

■ 光
  主光：____________（例：月光从左（门那侧）进来，冷蓝 5600K，地面硬格纹）
  辅光：____________（例：床头铜烛台，暖橙 2000K，勾他右肩轮廓）

■ 上一单元最后一帧
  画面内容：____________（一句话）
  眼睛状态：____________（她闭眼 / 半睁 / 睁眼，看向哪里）

■ 这一单元要改变的
  唯一一件事：____________（例：她从门口走回来，把手按在他胸口）
```

### 三条纪律

1. **每一项都必须写具体坐标或数值**，不许写"她在他旁边"。要写"她在他右侧约四十厘米"。
2. **上一单元最后一帧那一栏，是整张卡最重要的一行。** 它决定这一单元从哪开始。如果手上没有成片，就必须靠描述填满——不能空着。
3. **"这一单元要改变的"只能填一件事。** 填出两件，说明这是两个单元。

### 填不出来怎么办

| 缺什么 | 怎么补 |
|---|---|
| 不记得上一单元结束时他们在哪 | 看上一单元成片；没有成片就看上一单元的提示词文本；都没有就承认接不上，重新起一个状态 |
| 不知道她手上有没有东西 | 翻上一单元的 TIMELINE 和一致性锁，那里写了就等于那里有 |
| 光和上一单元对不上 | 以**环境卡描述的方位**为准，因为光位由房间决定，不由镜头决定 |
| **对手角色上一单元根本没入画**（纯主观镜头、单人特写都会这样） | 他的姿态**不由上一单元决定，由这一单元的第一个动作决定**。这一栏写"本单元首次入画，从 XX 姿态开始"，并在提示词里把姿态写全——不要试图从上一单元找，那里没有 |
| 上一单元传的参考图，这一单元还要不要 | **每单元重算，不许照抄上一单元的槽位清单。** 上一单元传了男主身份卡，如果他这一单元不入画，就不传（见 `slot-economy.md` 0.6 的硬例外） |

### 空间账本（复杂场景 / 多单元必填）

状态卡是**单元快照**；超过 3 人、有固定席位、正反打、角色进出，或跨 3 个以上单元时，再加一张**空间账本**作为整场真源。账本只建一次，每单元只抄增量；它不新增输出字段，只决定 `World:` / `Slots:` / `Shot:` 里的事实怎么写（完整模板与两个示例见 `spatial-anchoring.md` 第三节、第四节）。

```text
【空间账本 · 场景 __】（整场冻结）
■ 覆盖与假设：环境卡见过哪些墙；未见哪些；反打是否需要第二张环境卡
■ 坐标约定：俯视图上=北（远墙），下=南（镜头侧），左=西，右=东
■ 节点 N：N1 门… / N2 窗… / N3 桌… / N4 沙发… / N5 壁炉…
■ 锚区 P：P1 门内侧 / P2 桌后 / P3 炉前 / P4 沙发左端 / P5 窗边
■ 机位点 K：K1 桌右前（看向 P4）/ K2 炉前（看向 P4）/ K3 沙发右后（看向 P2）/ K4 房间中央（群像）
■ 人物槽位：c1 = 谁 = <Picture 1> = <Subject 1> = S1 → P4（坐，面向 N3）；c2 = … → P2
■ 轴线：c2(P2) ↔ c1(P4)；A 机过 c2 的肩（肩左缘，c1 看左下）/ B 机过 c1 的肩（肩右缘，c2 看右下）；手性固定
■ 光：主光自哪个节点入、色温；辅光在哪

【第 __ 单元 · 交接块】（每单元更新）
■ 上一帧：谁在哪个 P#、视线、手、道具、服装
■ 本单元唯一变化：从哪个 P# 到哪个 P#，用了多久
■ 帧内人数 / 画外名单：…
■ 本单元结束：…（拍完写回账本，下一单元从结束状态开始）
```

### 第 0.5 步：四检

```text
[ ] 身份：每个 c# 的图 / <Subject N> / 说话人 ID 与账本一致
[ ] 拓扑：每个人在哪个 P#；要动的，起止 P# 写清；没有穿门不换段
[ ] 人数：房间总人数 / 帧内人数 / 画外名单；画外的人没传卡
[ ] 轴线：机位在轴的哪一侧；前景肩在哪；视线朝哪；与上一镜连续还是相反
```

## 第 1 步：读图，提取七项

拿到图（尤其是上一单元的成片）时，**不要"看一眼"，按这七项逐条提取**。看不出来的地方要明确写"看不出来"，不要猜。

> **没有图、只有一段文字描述时也算走这一步。** 按文字逐项提取，提取不到的标"需要确认"，然后在提示词里**把它写死**——宁可自己定一个具体值，也不要留空。这一步的目的是**不漏项**，不是必须有图。

| # | 提取项 | 要回答的问题 |
|---|---|---|
| 1 | **人物位置** | 谁在画面哪一侧？两人相对距离多少？谁在前谁在后？ |
| 2 | **姿态** | 各关节状态：坐/躺/站，谁承重，膝盖朝哪，重心在哪 |
| 3 | **手与道具** | 谁的手在做什么？手上有东西吗？放在哪？另一只手呢？ |
| 4 | **表情与眼睛** | 眼睛闭合程度（闭 / 半睁 / 睁）？看向哪？嘴角什么状态？ |
| 5 | **光位** | 主光从画面哪一侧来？辅光在哪？冷暖各在哪一边？有无硬光斑？ |
| 6 | **机位** | 高度（比主体高还是低）、俯仰角度、景别（裁到哪）、有没有明显的焦段感 |
| 7 | **服装状态** | 有没有滑落、褶皱在哪、袖口在哪、有没有沾湿或污渍 |

### 为什么是这七项

因为下一单元的 `POSE AND STAGING` 和 `LIGHT AND ATMOSPHERE` 两段，就是靠这七项写出来的。**少提取一项，下一单元就少一句交代，那一项就会自己长。**

**位置一项要翻译：成片是投影，不是地图。** 画面左右是摄影机坐标；把它抄进账本，下一镜就会把机位当房间。读图时把"她在画面右"翻译成"她在 P4（沙发左端）"；翻译不了写"待确认"，不要猜。

### 常见漏项

| 漏了哪项 | 后果 |
|---|---|
| 手与道具 | 刀不见了、或者凭空出现在另一只手上 |
| 表情与眼睛 | 上一单元闭眼睡着，下一单元睁眼盯着人（最典型的恐怖谷） |
| 服装状态 | 上一单元纱滑到肩下，下一单元又穿好了 |
| 光位 | 月光从左变成从右，房间左右颠倒 |

## 第 2 步：定戏眼（四问）

**这一单元最值钱的那一秒是什么？** 答不出来，就先别写。

### 四个问题，按顺序问

```text
问 1  这一单元结束时，观众得到了什么新信息？
      （如果答案是"没有新信息"，这一单元就没有存在的必要，合并进相邻单元）

问 2  这一单元里，谁在主动、谁在被动？
      （主动的人决定机位高度、景别和光；被动的人被安排）

问 3  观众此刻知道什么、角色知道什么？信息差在哪？
      （短剧的张力九成来自信息差：观众知道她拿了刀，他不知道）

问 4  这一单元最后一个画面，应该是哪一帧？
      （先说清最后那一帧长什么样，再倒推整段怎么走到那里）
```

### 问 4 是抓戏眼的捷径

戏眼几乎总是落在**最后那一帧**上。所以先写最后一帧：

> "最后那一帧是：她的手指在他胸口，笑挂了三秒没散，他的眼睛睁着没眨。"

写出来之后，前面 9 秒的任务就只剩一件：**把他送到那一帧的状态**。

### 如果四问都答完还是找不到戏眼

三种可能，对应三种处理：

| 情况 | 处理 |
|---|---|
| 这一单元只是过场 | 合并到相邻单元，或者压到 5 秒 |
| 有两件事都想说 | 拆成两个单元 |
| 有信息但没有形式 | 缺一个物理动作来承载它。去 `performance-physics.md` 找对应动作 |

## 第 2.5 步：设计预演（动笔前，不是可选项）

戏眼和主动作定了，先别写镜头。把三件事一起过一遍：

**演技**：他想要什么/谁挡着；身体先怎么反应；哪个部位先动；泄露什么、遮盖什么；听者怎么反应。

**调度**：谁在哪；谁进谁退、谁不动；谁走哪条 P# 路径、被什么挡住；谁看谁。

**镜头**：主设计支点（高度/走位/空间/物件/光声）；每一刀为什么存在；有没有不必要的全景；最后一口画面。

在脑子里比较≥2种排法：

- A：高度讲权力（低角王→高角虫）；
- B：走位讲权力（他退→她进→桌成陷阱）；
- C：物件讲权力（杯→礼物袋→椅→杯落地）。

选 1 个主设计支点 + 1 个辅助，一次写成。

三个底线：

- 至少一处**人物位移或刻意的静止**改变关系；
- 至少一个镜头用**中景/近景 + 人物移动或前景/背景**交代空间，而不是全景；
- 至少两镜之间变化的是**权力/信息/立场**，不只是景别。

不要为了设计而设计；如果全场必须静止，写出压力。落笔时，你已经在脑子里比较过三遍。

## 第 3 步：定视角与衔接类型

### 3.1 先查上一单元的机位

把上一单元的机位写成一行：

```text
上一单元：85mm，他的右肩后，俯 3°，近景（胸以上）
```

然后问：**这一单元能用同一个机位吗？**

**不能。** 相邻单元同机位同景别，拼接时观众会感觉"卡了一下"（像卡帧）。所以要变。

### 3.2 再判衔接类型

```text
机位变了吗？  空间变了吗？
├ 都没变  → 同机位延续（只改景别或改动作）
├ 只变机位 → 换机位同空间
└ 空间变了 → 换空间
```

三种类型的证据需求：

| 类型 | 必须带 | 口诀 |
|---|---|---|
| 同机位延续 | 成片锚点（几乎全靠它） | **同机位靠图** |
| 换机位同空间 | 环境卡 + 身份卡 + 位置描述；成片只负责状态 | **换机位靠环境卡** |
| 换空间 | 新环境卡 + 明确的走位路径 | **换空间靠走位** |

### 3.3 选新机位（这一步决定成片质感）

新机位不是随便挑的，它是**叙事选择**——它决定**观众站在谁那边**。所以按"观众该站哪边"来选，不要按"谁主动"来选（谁主动是第 2 步判断戏眼时用的，两个维度不同）：

| 观众该站哪边 / 要什么效果 | 选什么机位 |
|---|---|
| 和他一起被困（他在被看） | 过**她**的肩拍他（前景是她的肩） |
| 看着她、审视她（她是被观察的对象） | 过**他**的肩拍她 |
| 压倒性的压迫（她逼近） | 过肩 + 85mm + 她的脸占满画面 + 他的肩在角落 |
| 交代空间有多大 | **中景 + 人物走位穿过画面**（不要拉全景——H3 全景会把脸做糊，见 `shot-continuity.md` 第三节） |
| 只剩一件事重要（眼、手、刀） | 微距 |
| 收束这一集 | 焦段回到 35mm，人物回到空间里 |

**还有一种不在表里的情况**：机位不动，但人物朝镜头走来，景别在段落内从全景连续变成近景。

这算"机位变了"——因为观众看到的画面一直在变，不会卡帧。但要在 CAMERA 段写清楚：`the figure walks toward the lens, the shot size shifting from a medium wide to a medium close over the take`。不写，模型会自己决定要不要跟。

### 3.4 最后确认三个不许

```text
[ ] 这一单元的机位，和上一单元不同（景别或角度至少有一项变了）
[ ] 这一单元的视角变化，带来了六种新信息里的一种
    （新主体 / 新空间 / 新状态 / 新视角 / 新阶段 / 关键反应）
[ ] 如果这一单元里有人说话，台词窗口在脸可见的镜头里，且镜头静止
```

## 第 4 步：组装

到这里，六样东西都有了：

| 有了 | 填进哪一段 |
|---|---|
| 状态卡 | `POSE AND STAGING`（位置、距离、朝向、承重）+ `LIGHT AND ATMOSPHERE`（光位） |
| 空间账本（复杂场景 / 多单元） | L1 → `World:`；L2 → `Slots:`；L3 → `Shot:` + `CAMERA`；账本是内部表，不新增字段（`spatial-anchoring.md`） |
| 七项读图 | `POSE AND STAGING` 的细节 + `CHARACTER` 的服装状态 |
| 戏眼（最后那一帧） | `TIMELINE` 的末拍 |
| 主设计支点（2.5） | `CAMERA` 段的高度/走位/前景安排 + `POSE AND STAGING` 的路径与景深 |
| 视角决定 | `CAMERA` 段 |

## 附录 B：这套流程的自我检查

每个单元交付前，逐条打勾：

```text
[ ] 状态卡填完了，每一块都有具体坐标或数值
[ ] "这一单元要改变的"只有一件事
[ ] 读图七项都提取了，看不出来的项标了"看不出来"
[ ] 戏眼能用一句话说清，且指向最后一帧
[ ] 这一单元的机位与上一单元不同（景别或角度至少有一项明显变了）
[ ] 这一单元没有用全景拍需要看清脸的内容
[ ] 密度符合默认（有台词 2–4 镜，不设硬上限；无台词 3–5 镜；设计版 5–7 镜；有台词 + 设计版按 5–7 镜且台词窗口静止；超过 7 镜每镜有新信息；POV 单镜除外）
[ ] 主设计支点选定了（高度/走位/空间/物件/光声），且至少两个镜头在兑现它
[ ] 至少一处人物位移或刻意的静止改变了关系
[ ] 每一刀有切因（权力/知识/立场/距离/尺度/节奏至少变一项）
[ ] 视角变化带来了六种新信息之一
[ ] 衔接类型判对了，证据带齐了
[ ] 槽位清单是这一单元重新算的，不是照抄上一单元
[ ] 提示词里没有 as before / previous shot 这类跨条空词
[ ] 画面里所有关键物件都重新陈述了（手上的东西、被子、门）
```

以上任何一条打不上勾，先别交付。
