# 术语表：这套工作方式的每个词，只准有一个意思

**为什么要有这份文件**：这套流程里最容易出的错不是技术错，是**同一个词在两个人脑子里指两件事**。比如"这一镜"，可能指一次 10 秒生成，也可能指其中一个机位段；"锚点"可能指角色设定图，也可能指上一镜截图。

词义一乱，后面所有判断都是错的，而且错得很自然——每个人都能自圆其说。

**使用规则**：

1. 写提示词、写文档、跟用户沟通，一律用本表的词。
2. 用户用了别的说法，先在心里映射到本表的词，再回一句确认（"你说的额外锚点，是指上一镜的成片吧？"）。
3. 本表没收的词，就是不该出现的词。想用新词，先加进本表。

## 一、层级：从整部剧到 0.1 秒

| 词 | 定义 | 不指什么 | 例 |
|---|---|---|---|
| **剧集 / 项目**（series） | 一整部作品，跨集 | 不要用"这个片子"模糊指代 | "这 12 单元算一集试水" |
| **集**（episode） | 一集 = 6–12 个单元 | — | 第 1 集 60–120 秒 |
| **场**（scene） | 同一时间、同一地点的一段戏，可跨多个单元 | 不指一个机位 | "床上对峙"这一场跨了单元 04–11 |
| **单元**（unit） | **一次生成的完整产物**。默认 10 秒（成片约 10.5 秒） | ❌ 不指一个镜头。一个单元里可能有 1–2 个镜头 | 单元 01 = "睁眼看见她"那 10 秒 |
| **镜头**（shot） | 单元内的一个机位段，用 `[Shot N]` 标记 | ❌ 不指一次生成 | 一个 10 秒单元通常 1–2 个镜头 |
| **节拍**（beat） | 时间轴上的一个动作段，约 0.8–1.8 秒 | ❌ 不指镜头 | 0.00–1.20s 是一个节拍 |

> **最容易混的两个：单元 与 镜头。**
> 一个单元 = 一次生成 = 可能含 2 个镜头。
> 所以说"这一镜"永远是含糊的——**规范写法：说"这一单元"或"这个镜头"，不要用"这一镜"。**

## 二、素材：参考图、锚点、五类角色

| 词 | 定义 | 不指什么 |
|---|---|---|
| **素材**（material） | 一切喂给模型的非文字输入（图、视频、音频） | 不指文字描述 |
| **参考图**（reference image） | 从某张具体画面抽出的**语义包**，整体注入生成过程。它只回答三个问题之一：**世界长什么样 / 这个人长什么样 / 上一刻发生了什么** | ❌ 不指"一张能参考的图"这种笼统说法——每张图必须能归到三个问题之一；归不进去，说明你还没想清楚要它干什么 |
| **锚点**（anchor） | **让某个状态"锁住"的输入**：可以是一张图，也可以是一段文字。它是功能词，不是素材类型 | ❌ 不等于"参考图"，也不等于"图"——锚点是"用来锁住某样东西的那份输入" |
| **图锚**（image anchor） | 用图锁状态：身份卡、环境卡、姿态卡、道具卡、成片锚点。寿命与槽位见 `slot-economy.md` | ❌ 不指文锚；❌ 不指"顺便参考画风" |
| **文锚**（text anchor） | 用正文文字锁状态：地标句、动量接力、物件状态链、视线向量、在场者锁。不占槽位 | ❌ 不指旁白；真源是 `text-anchoring.md` |
| **双锚**（dual anchor） | 图锚与文锚穿插使用：图管"看起来是什么样"，文管"在哪里、到哪一步" | ❌ 不是二选一，也不是互相替代 |

> **"锚点"的准确定义**：你给它，是为了让模型**不要变**某个东西。锁什么，就叫什么锚点。
> 锁脸 → 身份锚点（图）；锁房间 → 环境锚点（图）；锁上一刻的位置与道具 → 状态锚点（成片，图）。
> 锁"谁站在哪块地标旁、道具在谁手上、动作停在哪一步" → 文锚（文字）。
> 所以"这个做锚点"这句话必须补一个宾语：**锁什么？**

### 五类角色（详见 `slot-economy.md` 第零节）

| 词 | 提供什么 | 寿命 |
|---|---|---|
| **身份卡** | 脸、发型、发饰、标志痣、服装结构、体型 | 整集 |
| **环境卡** | 房间结构、家具位置、光的方向与形状 | 整集 |
| **成片锚点** | 上一刻的可见状态：谁在哪、手上有什么、光落在哪、什么表情 | 一镜 |
| **姿态卡** | 一个动作怎么摆、机位的垂直高度（不给构图） | 一镜到几镜 |
| **道具卡** | 器物的形状、大小、握法 | 几镜 |

### 两组寿命

| 词 | 定义 | 判据 |
|---|---|---|
| **基本参考图** | 定义"**一直如此**"的素材。脸长这样、房间长这样 | 整集有效，只要该角色入画就传 |
| **额外锚点参考图** | 定义"**刚刚如此**"的素材。她此刻手上拿着刀、他躺在她左边四十厘米 | 一镜有效，换单元就退场 |

**注意：这个分法按寿命，不按重要性。** 二者不能互换、不能合并计账。

### 文锚五锁（详见 `text-anchoring.md`）

| 词 | 定义 | 一句话判据 |
|---|---|---|
| **地标句**（landmark sentence） | 3–4 个固定地标（竖屏 2–3）+ 固定顺序 + 光向写成的**一句英文**，规格卡定义一次，每单元逐字复用 | 把人物删掉，这地方还是同一个地方吗？ |
| **地标坐标系** | 用"在哪块地标旁"表达位置，不用"A 在 B 左边"；世界左右与画面左右分开 | 没有别人在画面里时，这句话还成立吗？ |
| **动量接力**（momentum relay） | 上一单元末拍停在未完成态，下一单元首拍写余力的可见证据（自包含现在时） | 上一单元最后一帧的力，下一帧还在吗？ |
| **物件状态链**（object-state chain） | 关键物件的五字段链：来源 / 持有或位置 / 开合满空 / 下一步转移 / 体积材质 | 这东西上一位主人是谁、现在开着还是合着？ |
| **视线向量**（eyeline vector） | 每镜写清看谁 + 屏幕方向 + 垂直角 + 距离 + 画外方向；正反打两条视线相交 | 两条视线在空间里交于一点吗？ |
| **在场者锁**（bystander lock） | 每镜把非焦点角色写成"位置 + 状态 + 嘴唇闭合"，台词句再锁同场其他人的嘴 | 没说话的那个人此刻在哪、嘴什么状态？ |

### 输入判型与场面调度图（详见 `text-anchoring.md` §2.7、§8.2、§10.1）

| 词 | 定义 | 一句话判据 |
|---|---|---|
| **输入判型** | 先看用户手上有什么，再定锚定强度：连续成片 → 双锚；静态资产图 → 资产锚 + 文锚；**纯文字 → 纯文锚严格模式**；素材矛盾 → 先定唯一事实源 | 有图还是只有字？有字没图就不能默认"双锚" |
| **纯文锚严格模式** | 用户只给文字时的默认档：五锁全写 + 场面调度图 + 入口 + 桌面物件，无槽位声明，每单元复述被拍到的空间 | 遮住提示词，只看正文，能重建同一张平面图与座位表吗？ |
| **场面调度图**（Blocking Map） | 地标句的加深层，不是第六把锁：固定结构（墙 / 窗 / 门 / 柜台 / 通道）+ 固定席位（哪张桌哪一侧面朝哪）+ 入口通道 + 桌面物件。写进规格卡与每单元 `CHARACTER` 段，不占槽位 | 谁坐哪张桌的哪一侧、从哪扇门进？ |
| **席位锚** | 用"哪张桌 + 哪一侧 + 面朝哪块固定地标"表达座位，替代"在他旁边 / 右边四十厘米"这类相对坐标 | 这个人一起身，这句话还成立吗？ |
| **系列常量块**（Series Constant Block） | 五件常量压成一块、**每单元整块重写**：风格锁 + 地标句 + 场面调度图 + 参考映射 + 主体定义。它不是第六把锁，是**复述协议**——每个单元无状态，必须重新拿到同一份"这个世界长什么样" | 遮住动作部分，任意两单元的常量块逐字相同吗？ |
| **入画清单**（participation list） | 逐个角色声明"出现在哪几镜"。六段壳写在 `retention_analysis`，三字段壳写进状态卡与在场者括号；必须与正文实际出现的镜号一致 | 该消失的人真的没出现、该出现的人真的在？ |

### 空间账本与四检（详见 `spatial-anchoring.md`）

| 词 | 定义 | 一句话判据 |
|---|---|---|
| **空间账本**（space ledger） | 整场一份的空间事实源：覆盖与假设 / 坐标约定 / N# 节点 / P# 锚区 / K# 机位点 / c# 槽位 / 轴线 / 光位。每单元只写增量 | 遮住动作，任意两单元的 L1/L2 是否逐字一致？ |
| **L1 世界层** | 房间拓扑 + 节点 + 锚区 + 机位点 + 光向；写成地标句 | 把人物删掉，这地方还是同一个地方吗？ |
| **L2 身份层** | c# ↔ Subject ↔ 图 ↔ 说话人；站位 P#；朝向节点；道具；服装基线；轴线表 | 这个 c# 换图 / 换说话人了吗？ |
| **L3 本镜层** | 屏幕侧、景别、前景肩、帧内人数、朝向/视线变化、位移、台词 | 屏幕侧只在本镜出现一次了吗？ |
| **N# 节点** | 房间里的固定结构与家具锚点（门 / 窗 / 桌 / 沙发 / 壁炉） | 它约束站位吗？ |
| **P# 锚区** | 人物可站 / 坐 / 倚的位置，挂在 1–2 个节点上 | 一个锚区同时只有一个人吗？ |
| **K# 机位点** | 摄影机可站的位置（位置 + 高度 + 默认看向点） | 它和人物锚区重合了吗？ |
| **c# 人物槽位** | 跨单元稳定的人物编号，绑定图 / `Subject` / 说话人 | 本单元用的图还是这个 c# 的吗？ |
| **四检** | 写前 / 生成后只查：身份 / 拓扑 / 人数 / 轴线 | 四条都过了吗？ |
| **手性锁** | "肩侧 = 视线侧"的固定对应，开场定一次 | A/B 两镜视线相反、肩侧相反吗？ |
| **机位移交** | 一次生成内从 A 的肩后推 / 弧线到 B，不跨轴 | 台词前停稳了吗？ |
| **站位图** | 场面调度图的图像版；只给平面关系，占一个槽位，不新增第六类角色 | 它是图，还是文字调度图？ |

**账本不是第六把锁。** 它是地标句 / 调度图 / 五锁的计算底稿；交付 prose 仍以 `text-anchoring.md` 为准。

### 对白表演（详见 `dialogue-performance.md`）

| 词 | 定义 | 一句话判据 |
|---|---|---|
| **话轮**（turn） | 互动的最小单位：谁抢、谁让、谁插不进、谁用沉默回答 | 这一轮服务了哪个关系变化？ |
| **言语不流畅**（speech disfluency） | 心理障碍决定语言失败方式：启动失败 / 重复 / 沉默 / 自我修正 | 失败落在最难面对的词上了吗？ |
| **三股力量**（LEAK / CONTROL / CARE） | 生理泄露、自我控制、关心目标同时存在，不是情绪切换 | 外显是否只留一个？ |
| **对白拍六件套** | 时间码 → 说话目标 → 原句 + 触发词 → 可见反应 → 声音动作 → 话轮 + 听者反应 | 听者在台词中反应了吗？ |

## 三、判断：这一单元到底要做什么

| 词 | 定义 | 怎么找 |
|---|---|---|
| **戏眼**（dramatic point） | 这一单元里**唯一那一下**——观众看完记住的那一秒。一个单元只有一个 | 问四个问题，见 `shot-intake.md` 第 2 步 |
| **钩子**（hook） | 单元结尾让观众想看下一单元的那一下。**和戏眼不一定是同一件事** | 通常落在最后一拍 |
| **情绪曲线** | 一集里张力的起伏分布。每单元一个上行 + 一个钩子 | 画出来，不要只在脑子里 |
| **状态卡**（state card） | 一单元开工前写的**七栏文本快照**：空间 / 物件 / 服装状态 / 光 / 上一帧 / 文锚五锁 / 这一单元要改变的。把"模型不记得但观众知道"的事写下来；复杂场景/多单元另加 `spatial-anchoring.md` 的空间账本（不是新步骤） | 见 `shot-intake.md` 第 0 步 |
| **信息差** | 观众知道而角色不知道（或相反）的那部分。短剧的张力主要靠它 | 每单元问一次"谁知道什么" |

> **戏眼 vs 钩子**：戏眼是"这一单元最值钱的一秒"，钩子是"这一单元最后的一秒"。两者可以重合（收在戏眼上），也可以分开（先给戏眼，再补一个钩子）。

## 四、格式：提示词本身的零件

| 词 | 定义 | 不指什么 |
|---|---|---|
| **三字段** | `integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music` 三个顶层字段 | 不指三句话 |
| **六段壳**（Ref2VA） | 多图 / 参考视频且要 Ref2VA 格式时的外壳：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`。**换壳不换锚**——`detailed_description` 内部仍按七段骨架顺序写 | ❌ 不指六句话；❌ 不替换默认三字段壳 |
| **七段骨架** | 字段一内部的七个全大写小节：CHARACTER → POSE AND STAGING → TIMELINE → CAMERA → PHYSIOLOGY PRIORITY → LIGHT AND ATMOSPHERE → CONSISTENCY LOCK | 不指七个镜头 |
| **时间码**（timecode） | `0.00-1.20s:` 这种首尾相接的区间标记 | 不指帧号 |
| **窗口**（window） | 专门留给某一个动作或台词的时间段，期间镜头必须静止 | — |
| **一致性锁** | 提示词最后一段，锁**人数 + 状态（重心、承重、位置）+ 惯性 + 身份标志物**。**不写肢体数量**——H3 不会融化肢体，写了只是挤占注意力 | ❌ 不指"保持一致"这种空话；也❌不指"防崩清单" |
| **身份标志物** | 4–6 个可辨识、可验证的外形特征（发饰位置、痣的左右、袖型） | ❌ 不指"很漂亮""气质清冷" |
| **风格锁**（style lock） | 逐字复用的一段渲染风格描述，放在每条提示词的第一句 | ❌ 不指调色参数 |
| **可拍摄性** | 一个描述能否被摄像机验证。"她感到害怕"不可拍摄，"喉结吞了一下"可拍摄 | 见 `h3-output-spec.md` 的禁用词表 |
| **意图性动作** | 写"想做什么"（tries to pull away）或"做到了"（he stood up）的动作句。H3 读不出意图，结果又只有最后一帧可拍，所以会演成**静止**。必须改写成"力 + 反作用物 + 中间态" | 见 `performance-physics.md` 第二节 |
| **微表情锚定词** | 紧跟情绪词的 `micro expressions`（如 `quietly hurt micro expressions`），把整脸表演收窄为克制、细小的面部变化；只是幅度锚，仍须接部位 + 顺序 + 一个可见动作，并配台词前准备 / 台词后余韵 | 真源 `acting-performance.md`「微表情锚定词」；❌ 不指写了就自动有微表情，也不指安全词 |
| **3–4 拍微表情链** | 3–4 秒关键近景里 3–4 个按序演进的微节拍：上区先泄露、中区漏出来、下区收住；1–2 秒瞬间 2 拍也可，5 秒长镜可 4–5 拍 | 不是时间码节拍 |
| **反射弧** | 被触碰/被抱住/被拉拽的六拍：局部→惊跳→定向→评估→对抗/顺从→余波；`freeze` 不是第一拍，冻结是反应的缺席 | 见 `acting-performance.md`「反应动作」 |
| **两力模型** | 拉入力 + 后撤力 + 合成（僵住/前倾/踉跄/椅脚刮地）；不写单一结果"他被抱住" | 见 `acting-performance.md`「反应动作」 |

## 五、镜头：四个词经常被互换，但它们完全不同

| 词 | 定义 | 例 |
|---|---|---|
| **机位**（camera position） | 摄像机在空间里的**位置**：高度、距离、偏哪个方向 | "他的右肩后、高于床面六十厘米" |
| **视角**（viewpoint） | 镜头**代表谁的视线**：客观、他的主观、她的主观 | "第一人称，从他眼睛看出去" |
| **景别**（shot size） | 画面**裁到哪**：大特写 / 特写 / 近景 / 中景 / 全景。**H3 里景别越远脸越软**——中景变软但仍可读，全景只剩轮廓。要不要用远景，取决于这一镜需不需要读脸 | "从胸口以上" |
| **焦段**（focal length） | 镜头的**光学特性**：广角压缩还是长焦压缩 | "85mm 等效" |
| **构图**（framing / composition） | 画面内元素的**位置关系** | "他在左三分之一，她的肩在右缘虚化" |
| **角度**（angle） | 俯仰与偏斜：俯拍 / 平视 / 仰拍 / 侧 45° | "俯 15 度" |

> **四个词的关系**：机位决定视角、景别、焦段、构图。
> 写提示词时最容易犯的错是**只写景别不写机位**（"中景"三个字对模型几乎没有约束力），
> 正确写法是把机位写成一个坐标："在他的右肩后、高于床面六十厘米、俯十五度"。

### 镜头关系词

| 词 | 定义 |
|---|---|
| **轴线**（axis） | 两人之间那条看不见的连线。所有机位必须待在同一侧，否则观众会觉得两人突然并肩 |
| **过肩**（OTS, over-the-shoulder） | 机位在某人肩后，他的肩/后脑在前景虚化，焦点在对面那个人 |
| **正反打**（shot / reverse-shot） | 一组对切的过肩镜头：A 机拍他、B 机拍她，两条视线相反 |
| **反打** | 正反打里的第二个镜头，与第一个方向相反 |
| **跳轴** | 违反了轴线规则，空间感崩塌 |
| **画面骨架** | 观众认一张画面靠的四样：**景别档 / 轴线侧 / 主体位置 / 入画人数**；**第五根是高度/角度**。相邻镜头至少换两件，其中一件优先高度/角度或轴线侧。参数变了但骨架没变，等于没变 |
| **起幅重合** | 这一单元的**第一帧**和上一单元最后一帧是同一个构图。最隐蔽的违规形态——因为它常以"我用运镜过渡了"的形式出现（`starts at a medium shot…, then pulls back`），当事人以为自己在变 |
| **抹平** | 一次生成内做正反打时的特有风险：模型不给你一刀切开，而是给一个缓慢的过渡。判断方法是看两个视角之间有没有过渡帧 |
| **变量纪律** | 每种运镜只能写它自己的变量。多写一个变量就是给模型多一个旋钮，它会去转那个旋钮——推拉不写"焦距锁定"会被读成变焦推，横移不写"朝向锁定"会退化成环绕，升降不写"姿态水平"会变成升降+俯仰摇 |

### 设计（2026 升级）

| 词 | 定义 | 不指什么 |
|---|---|---|
| **导演设计链** | 戏核 → 调度 → 表演 → 镜头 → 台词 → 声音 → 连续性。上游决定下游，改一个要顺链重查 | ❌ 不是步骤清单；它是因果顺序 |
| **设计预演** | 动笔前把演技、调度、镜头一起想一遍，比较≥2 种排法，选定一个主设计支点再写 | ❌ 不是反复修改；落笔只有一条 |
| **设计版** | 有权力/信息反转或空间障碍时，用 5–7 镜把变化切成多个权力/信息状态；不是每场都要设计版 | ❌ 不是"镜头越多越好" |
| **设计支点** | 这场戏主要靠什么讲：高度/角度、人物走位、空间压缩、物件接力、光/影、声/画外。选 1–2 个主支点 + 1 个辅助 | ❌ 不是视觉风格；❌ 不是运镜花样 |
| **视觉论点** | 一句话说清"谁从什么变成什么，镜头用什么证明它"。只用于高度支点，不是所有戏的必答题 | ❌ 不等于主题思想 |
| **高度版 / 走位版** | 两种并列的七镜排法：高度版用机位高低讲权力；走位版镜头不动、人物在画框里移动。按戏选一种，不混着堆 | ❌ 不是"高级/低级"之分 |
| **切因** | 这一刀为什么存在：权力/知识/立场/距离/尺度/节奏至少变一项；一项不变就不要切 | ❌ 不是景别变化本身 |
| **走位变焦** | 机位不动，人物朝镜头走来或走远，脸在画框里变大变小；不换镜头也能改变景别 | ❌ 不是光学变焦 |
| **coverage**（覆盖式拍法） | 只为"拍到了"而拍的中景/全景堆叠，镜头之间没有权力或信息变化。它是下限，不是设计 | ❌ 不是"镜头多" |
| **景别三件套** | 中景 → 特写 → 微距，只改变"离脸多近"；是 coverage 的常见形态，不是设计 | 三镜只换了景别吗？ |
| **跨风格三件套** | 槽位排除旧渲染 + 镜头首句钉目标风格 + 细节复述风格；与"景别三件套"不是一回事 | 三个层次都写了吗？ |
| **镜头表** | 写 CAMERA 前的内部表：每镜高度/角度、景别、前景层、发生什么、切因；行数由戏决定 | 表里两镜同高度/同角度/同景别？ |
| **非平视正面** | 低角/高角/侧向/俯拍；略低/略高也算，不是必须极端；侧向仍在眼高，算"非正面"、不算"非眼高"；全单元都在眼高（哪怕侧向）要写理由 | 全单元都在眼高吗？ |
| **镜头设计闸** | 首镜不复用场景图、相邻换两件、至少一个非平视正面、反应/插入、每刀切因、动作场五段 | 六条过了吗？ |
| **动作场五段** | 来向/地理 → 接触 → 受力/证据 → 反应 → 余波；默认 5–7 镜，瞬间 3–4 也可，但必须覆盖五段 | 三镜只换景别了吗？ |
| **漫剧 / 2.5D / 动画风** | 渲染风格，不是机位；包括国漫、日漫、三渲二。镜头应利用剪影、负空间、前景遮挡、低/高角、强透视 | 是不是又退回平视 coverage？ |
| **中全** | 中景偏全的过渡景别，用于交代人物与空间关系；不能替代近景读脸 | ❌ 不是全景 |
| **少全景** | 默认不用全景建立空间；用中景 + 人物移动 + 前景/背景交代空间。全景只给空间规模/孤立/命运、人物变图案、社会关系图 | ❌ 不是禁止全景 |

## 六、流程：单元之间怎么接

| 词 | 定义 |
|---|---|
| **衔接** | **画面状态传不传得过去**。不是"剧情连不连"——剧情可以跳，画面状态不能丢 |
| **衔接类型** | 三种：同机位延续 / 换机位同空间 / 换空间。口诀：同机位靠图，换机位靠环境卡 + 地标句，换空间靠走位。**文锚五锁每单元都写** |
| **接续模式** | 技术上怎么传：A 参考图 / B 尾帧 / C 参考图+成片。与"衔接类型"是两个维度 |
| **尾帧** | 成片的最后一帧。截取时要往前退 0.2–0.3 秒，存 PNG |
| **无状态**（stateless） | H3 每次生成都不记得上一单元。这是整套流程的地基 |
| **同构图拼接跳变** | 相邻单元用了同一个构图时，两次独立生成之间的微差会让画面在剪辑点“跳”一下。这是“必须换视角”的**物理原因**，比“缺乏新信息”更硬 |
| **自包含** | 一条提示词只靠自己就能被理解——不出现 `as before`、`previous shot` 这类没有参照物的词 |

## 七、诊断：错在哪

| 词 | 定义 | 区别 |
|---|---|---|
| **崩点** | 这一类镜头**结构上容易出的错**，可以事先预告（"她可能睁眼""背景可能长出家具"） | 崩点是**预判**，写在交付里 |
| **卡点** | 某个人**读文档或做决策时卡住的地方**（"这里我不知道该传几张"） | 卡点是**反馈**，用于改文档 |

> 两个词不能混用。崩点关于画面，卡点关于理解。

## 九、导演层：档位、设置、特效

| 词 | 定义 | 不指什么 |
|---|---|---|
| **视觉档位**（visual tier） | 三条互不混用的角色视觉路线：默认 **3DCG 档**（FFVII REMAKE 严格 CG）、**游戏内三渲二实机建模档**、**真人电影档**。整条片/整集只选其一 | ❌ 不指单片风格灵感；❌ 不是每镜可换的滤镜 |
| **档位锚** | 某一镜里就地重申档位关键特征的短句（如真人档的鼻唇沟锁定、3DCG 档的柔哑散射皮肤），只写在风险镜 | ❌ 不指全局风格锁 |
| **素材媒介冲突** | 用户给的参考图与当前档位媒介不一致（如 3DCG 档收到真人照片）。处理：只取姿态与他人结构，明确排除其渲染、肤色与真人质感 | ❌ 不指"要换风格"时的跨风格三件套 |
| **镜头数量** | 用户/软件给出的 0–20 整数。0 = AI 自主决定（仍是 1–20 镜）；1 = 真一镜到底；2–20 = 精确镜数 | ❌ 不是上限；❌ 不是动作数 |
| **角度夸张程度** | 1–5 整数，决定透视与机位张力的上限 | ❌ 不指运镜幅度，也不指剪辑快慢 |
| **屏幕时间 vs 故事时间** | 屏幕时间是成片占用（慢放会放大）；故事时间是事件实际经历。慢放倍率只改变前者 | ❌ 不能把慢放当免费时长 |
| **接触点审计** | 逐次攻击核对：谁用什么（哪侧肢体/兵器哪段表面）接触对方哪个部位、实际命中还是落空、之后如何分离 | ❌ 不指笼统的"激烈对打" |
| **状态交接** | 前镜末态 → 后镜初态的可见/可听依据，写在每个连续切点 | ❌ 不指"保持一致"这类空话 |
| **特效最小设计记录** | 每条特效的内部六问：从哪来、多大；主要看什么；如何发展；作用在哪里；怎样融入；留下什么。真源是 `vfx-design.md` §2 | ❌ 不是 H3 新增字段；❌ 不是固定五段模板 |
| **研究受限稿** | 缺少指定参考或一手来源时，明确标注证据范围与替代依据的稿件；不假装看过未看的片段 | ❌ 不指普通初稿 |

## 十、一页速查：最容易混的几组

| 组 | 区别一句话 |
|---|---|
| **单元 vs 镜头** | 单元是一次生成，镜头是单元里的一个机位段。禁说"这一镜" |
| **参考图 vs 锚点** | 参考图是素材通称；锚点是"用来锁住某样东西的那份输入"，说锚点必须补"锁什么" |
| **图锚 vs 文锚** | 图锚管"看起来是什么样"且只活一镜到整集；文锚管"在哪里、到哪一步"且每单元都要重写。双锚穿插，不是二选一 |
| **地标坐标 vs 相对坐标** | "她站在机甲残骸旁"任何机位都成立；"她站在他左边"他一动就失效。人物位置永远挂地标；有座位时挂席位（哪张桌哪一侧面朝哪） |
| **空间账本 vs 地标句** | 地标句是交付 prose；账本是生成它的内部表（N/P/K/c/轴线）。写提示词用前者，查错用后者 |
| **话轮 vs 台词** | 台词是一句话；话轮是一轮互动（谁抢、谁让、谁沉默）。写对白先排话轮，再填台词 |
| **基本参考图 vs 额外锚点** | 一个定义"一直如此"，一个定义"刚刚如此"。按寿命分，不按重要性分 |
| **机位 vs 景别** | 机位是摄像机在哪，景别是画面裁到哪。只写景别等于没写机位 |
| **戏眼 vs 钩子** | 戏眼是这一单元最值钱的一秒，钩子是这一单元最后的一秒 |
| **视觉档位 vs 风格锁** | 档位是整片选定的角色视觉路线；风格锁是把该路线逐字复用的一句文本 |
| **镜数 vs 镜头密度** | 镜数是用户显式设置，严格照办；密度是未设置时的默认经验值（10 秒有台词 2–4 镜，不设硬上限；无台词 3–5 镜；设计版 5–7 镜；有台词 + 设计版取 5–7 且台词窗口静止；超过 7 镜每镜要有新信息） |
