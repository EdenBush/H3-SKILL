## 前置硬闸一：联网研究与创意落实

按 `scene-research.md` 核查；**不能用后面几轮的技术正确替代本项**。

- 联网可用且用户未禁止时，是否在设计前实际检索并打开了相关来源，比较至少两个不同处理的有效案例；同场景微调复用的研究是否确已核查且仍适用。
- 战斗研究是否覆盖分镜、动作因果和人物 / 摄影机调度；是否区分实际观察、来源解释与本稿推导，未把摘要、孤立图片、记忆或不可访问视频当作已看过的过程。
- 正文中能否定位研究转化的具体选择；新设计的战斗须落实动作、调度与镜头 / 节奏，局部优化则在获准修改处落实，其他维度核查并继承用户锁定内容。**只贴链接、作品名或"参考某片"不通过。**
- 交锋或争吵挽留戏是否因人物目标、距离、地形或主动权而动态推进；无理由重复站定互打、开场站桩正反打对话或等时长碰撞特写时，返回场面设计修正。
- 来源与采用点是否按交付要求可核查；实际离线、用户禁网或搜索证据不足时，是否如实说明并标记研究未完成 / 受限，未把草稿宣称为完整验收通过。

有可用网络却跳过研究，应先补研究并据此复核设计，不直接交付为成稿。外部条件确实受限时按 `scene-research.md` 继续草稿流程，不伪造通过。

## 前置硬闸二：用户设置与参数

**镜头数量 0–20**（用户或软件设置时）：

- 0 = AI 自主决定合理镜数（1–20），不是零个镜头。
- 1–20 = 严格等于所选数量，不是上限或建议。1 表示真一镜到底：摄影机路径、焦点和人物调度连续，允许镜内改变景别与角度，**不允许切镜、暗切、遮挡偷切、时间跳跃**。
- 20 镜不等于 20 次攻击；不能复制起手、重复命中或擅加剧情凑数。

**角度夸张程度 1–5**：

| 档位 | 设计要求 | 核查证据 |
|---|---|---|
| 1 标准 | 自然透视、稳定地平线、常规平视与适度仰俯拍 | 无超广角、极限仰俯、强倾斜、贴脸畸变 |
| 2 轻度 | 常规机位为主，情绪 / 动作重音用轻低机位、高机位或适度广角 | 重音处有具体机位 |
| 3 明显 | 转折处用前景遮挡、低机位或高差构图改变观众能看见的信息 | 每处有信息目的 |
| 4 强烈 | 前景尺度、遮挡揭示或路线纵深显著改变画面，保留看懂后果的窗口 | **至少半数镜头有明确透视变化（多镜至少两镜）** |
| 5 极限 | 组合至少两种有对比的透视视点；单镜沿可达路线改变高度或前后景关系 | **至少 3/4 镜头有明显高低 / 纵深 / 前景尺度变化，多镜稿至少两种不同机位** |

高档不自动加快剪辑、增加攻击或把文戏改成打斗。**相机运动幅度 ≠ 角度夸张程度。** 每镜把"情绪 / 战术变化 → 观看目的 → 机位高度、视线方向、透视与运动 → 可读结果"写成具体画面，不只标"夸张 5"。

显式设置优先于高节奏打斗的夸张机位默认；未设置时按故事选择，不凭空施加固定镜数。

**H3 参数**（见 `h3-output-spec.md`）：duration 4–15s、resolution 768P/2K、ratio 从允许列表、24fps 固定。默认 10s / 9:16 / 768P（用户未指定时）。请求时长、提示词时间线、实测文件长度分开记录。

## 机械自检：`scripts/check_prompt.mjs`

```bash
node scripts/check_prompt.mjs prompt.txt --duration 10
# 剧集：多个单元一起过闸，并逐条比对系列常量块与入画清单
node scripts/check_prompt.mjs unit01.txt unit02.txt unit03.txt --series
```

`prompt.txt` 是临时工作副本，跑完删除，不进入交付；也可用 `--stdin` 直接喂正文。

它查这些可判定项：

| 类别 | 查什么 |
|---|---|
| 段落完整性 | CHARACTER / TIMELINE / CAMERA / PHYSIOLOGY PRIORITY / CONSISTENCY LOCK 是否存在（POSE AND STAGING、LIGHT AND ATMOSPHERE 按模板应写；脚本对缺失只提示） |
| 时间码 | 是否从 0.00 起、首尾相接、不重叠、不超时长；节拍数是否接近 ⌈时长÷1.2⌉；有无短于 0.6s 的拍 |
| 对白 | `<d>` 与 `</d>` 成对、每段有语言标签、有说话人编号 |
| 切点句式 | 每个 `[Shot N≥2]` 是否有 `At 00:0X.000, the camera cuts to ...` |
| 镜头密度 | 有台词 >4 镜提示（不是硬上限；设计版可到 7 镜，但每刀要换权力/信息/立场）；无台词 <3 警告、>7 警告（默认 3–5，设计版 5–7 合法）；POV 单镜豁免 |
| 机位冲突 | CAMERA 段内是否同时出现仰拍与俯拍指令 |
| 一致性锁 | 是否有人数锁（`exactly one woman/man/figure...`）与状态锁句式；**不检查也不提示肢体数量锁** |
| 槽位声明 | 开头提到参考图是否有 ignore 从句；多视图是否加了 `render exactly one single figure` |
| 否定式残留 | `no/without/do not/never` 等（合法指令如 `no cuts` / `no hunting` / `no other figures` 已排除） |
| 跨条引用 | `as before` / `previous shot` / `continuing from the previous shot` 等无参照物表述 |
| FACS 泄漏 | 正文是否出现 `FACS` 或 `AU1/AU4/AU7...` 编号（真人档硬闸） |
| **系列常量块**（`--series`） | 每个单元是否都有常量块；相对最长的一条，长度低于 85% 判失败（逐条缩写），词面差异大于 3% 给警告并列出差异词（是状态词还是被改写，由人判断） |
| **入画清单**（`--series`，六段壳） | `retention_analysis` 声明每个 Subject 出现在哪几镜，与 `detailed_description` 里实际出现的镜号逐一比对；环境主体按全镜在场跳过；`<Subject N>'s ...` 视为画外指代不计入画 |

六段壳（Ref2VA）没有七段的段落名与行内时间码，`--series` 对它们只跑槽位 / FACS / 否定式 / 跨条四项加常量块与入画清单，不报段落缺失。

**脚本判不了的三项，必须人工过**：

1. **一拍是否只推一件事**
2. **生理层是否彼此错开**（六层不要同一拍一起动）
3. **有没有不可拍摄的形容**（"她感到""气氛变得"——见 `h3-output-spec.md` 第五节）

**设计闸（人工，2026 升级）**——逐条问，不通过就回阶段 3.5 重想，不要在下游硬修：

- [ ] 主设计支点选定了吗？至少两个镜头在兑现它？
- [ ] 每一刀有切因？两镜做同一件事的，删一个。
- [ ] 有没有不必要的全景？需要读脸的内容是否都在中近景以内？
- [ ] 至少一处人物位移或刻意的静止改变了关系？镜头可以不动，人物不能全站桩。
- [ ] 如果用户说"再设计一点"，现在能指出哪三处不同？指不出，说明还没设计够。

## 第一轮：视觉档位与表演

先按 `art-direction.md` 的六项决定核对当前镜头；本项在联网受限和局部修稿时同样执行，不增加审核轮数。保留用户的风格、强度、剧情和时长；高饱和、大特效及夸张视点不自动构成缺陷。需要对照时只读 `aesthetic-examples.md` 中相关的一两组；这些文字示例未经用户逐条认可，不能作为真实影片或成片证据。

按 `visual-tiers.md` 核对当前选定的视觉档位，保持三套档位独立、绝不混用词条：

- **默认 3DCG 档：** 核对 12 项约束（CG 媒介、角色雕塑、皮肤 / 面颊底色、CG 表情形变、眼口、发型受光、发丝动力学、布料动力学、身体动作、材质分离、美术光影 / 世界光源、时间稳定）。
- **三渲二实机建模档：** ① 未混入 `FINAL FANTASY VII REMAKE`、`soft subsurface scattering`、`fine natural skin microstructure` 或真人实拍词条；② 锁定 `in-game 3D cel-shaded character model` 的三维体积，未写成 `2D illustration` / `splash art` / `flat 2D anime`；③ SDF 二分光影、无毛孔哑光肤质、多层高光瞳孔与绑定口型、几何发束 + 条带高光、风格化 PBR 材质分离、极细本色描线 + 硬边轮廓光六项齐全。
- **真人电影档：** 逐镜执行五项硬闸——① 全局与每个说话 / 哭泣镜均有平滑鼻唇与极小下颌锁；② 自然哑光肤质、零油光；③ 重度去饱和低对比调色 + 所有鲜艳物加 `muted/pale/dusty`；④ 正文零出现 `FACS` / `AU` 编号；⑤ 关键近景包含 3–4 个按时序演进的微表情节拍。

**表演层**（采用 `acting-performance.md` 的片段）额外核查：

- 触发事件与反应是否先后成立；
- 情绪是否只有一个标签（`sad` / `angry`）或只有 `micro expressions` 锚定词，却没有部位 + 顺序的可见动作链；
- 关键近景是否有 3–4 个演进节拍，而不是一句"很悲伤但克制"；
- 台词段是否台词前有半拍准备、台词后有半拍余韵，而不是说完立刻"断电"（视线先离、表情归零）；
- 边说边哭是否写清气口落泪与平滑面颊的双重锁定；
- 不耐烦 / 回避方是否严格执行拒绝直视（偏头 30°、视线只落手腕、闭眼叹气）；
- **跨镜泪痕是否继承**（眼眶湿润 / 单滴滑落 / 面颊湿痕是三个状态，切镜不能凭空消失）；
- 正文是否已彻底清除 `FACS` / `AU` 缩写。

**对白专项**（`dialogue-performance.md`）：话轮不是排队（按戏需要至少一处抢话/叠话/插不进/沉默/失败启动）；听者在台词进行中反应；失语落在最难面对的词且发生在身体；三股力量同时存在、外显只留一个；切镜后情绪连续（湿润/视线/呼吸）。

**多视图来源与侧面朝向**：若为"上方脸部特写、下方全身三视图"，正文须明确上方是唯一面部身份来源，下方正面 / 指定侧面 / 背面只供各自身体、衣装、装备与整体轮廓。**特别核查侧面全身图的朝向**：正左侧面全身图（人物面朝画左）仅在分镜中人物朝画左或从右向左移动时引用；严禁人物在画左、面朝画右时错误引用正左侧面图。

## 第二轮：特效质感

依据 `vfx-design.md` 和 `vfx-families.md` 当前类别，检查**正文中的主要效果**，而非只查风格总述。无特效时略过本轮。

对照最小设计记录逐项核：

```text
[ ] 来源与尺度：谁/什么产生，从哪来，多大，持续多久
[ ] 主形与运动：一句话能说清的主形，有方向、速度、增长/衰减
[ ] 接触与环境：碰到什么，环境怎么响应（光、尘、湿、破坏、残留）
[ ] 光照与曝光：效果照亮了谁，高光峰值可读，没有全屏等亮
[ ] 材质与体积：介质有厚薄、透明度、内部层次，不是平面贴屏
[ ] 时间曲线：起—盛—衰有先后，不是全程同亮
[ ] 主次关系：一个主效果，次级效果服务它；没有每类效果各炸一次
[ ] 可读窗口：关键动作与接触没有被粒子或光效遮住
```

常见廉价感的修法见 `vfx-design.md` 第四节诊断表；材料失效形态见 `vfx-families.md` 的材料表。

## 第三轮：切点与空间

使用 `continuity-ledger.md`，实际比较每个连续切点的 `前镜末态 → 后镜初态 → 新变化`，包括时间、世界位置 / 朝向、机位 / 轴线、动作相位、持物 / 接触 / 支撑、面颊湿润泪痕、衣发余波、特效阶段及残留和世界光源。**反查正文是否保留了台账所依赖的证据；只有内部算对、提示词没写出来，也未通过。**

先查 H3 的四根骨架（见 `shot-continuity.md` 第零节）：

```text
[ ] 相邻单元的构图，四根骨架（景别档 / 轴线侧 / 主体位置 / 入画人数）至少换了一根
[ ] 剪影测试：两帧并排眯眼，黑影分布明显不同
[ ] 起幅 ≠ 上一单元落幅；整条中间没有回到上一单元构图；落幅 ≠ 下一单元起幅
[ ] 每次换视角带来了六种新信息之一（新主体 / 新空间 / 新状态 / 新视角 / 新阶段 / 关键反应）
```

以上四根骨架针对**成片里作为切点的相邻单元**。B 尾帧接续是同一条镜头的两段生成，成片里没有切点，不适用"换骨架"；但接缝必须用遮挡 / 甩镜 / 快速动作藏住，裸拼接一定跳。

剧集接力再核一遍文锚五锁（`text-anchoring.md`）——**图锚接的是样子，文锚接的是位置与进度**：

```text
[ ] 系列常量块是否每单元**整块重写**（风格锁 + 地标句 + 调度图 + 参考映射 + 主体定义），而不是从第 2 单元起逐条缩写？（`text-anchoring.md` §2.8）
[ ] 常量块里是否混进了本单元的状态（"她手里端着缸""缸在桌上""包扣开着"）？状态应全部在 `POSE AND STAGING` 与 `CONSISTENCY LOCK`，常量块只留归属、外形、席位（§2.8 纪律 2）
[ ] 批量交付且单元 ≥ 2 时，抽任意两条并排：遮住动作部分，两侧的常量块是否逐字相同？
[ ] 地标句逐字复用规格卡原文？地标数量、顺序与光向都没动？
[ ] 人物位置全部挂在"在哪块地标旁"，没有"A 在 B 左边"这类相对坐标？
[ ] 有座位 / 入口 / 桌面物件时，是否写了**场面调度图**，席位写成"哪张桌 + 哪一侧 + 面朝哪"？
[ ] 本单元被拍到的家具、席位、入口、桌面物件是否全部重新陈述？新角色是否从已声明入口进入？
[ ] 每单元是否列了**入画清单**（谁在哪几镜），且与画面人数锁、在场者括号、retention 说明三者一致？
[ ] 输入类型判对了吗？纯文字是否走了纯文锚严格模式（`text-anchoring.md` §10.1），而不是默认"双锚"？
[ ] 本单元首拍接住了上一单元末拍的未完成态（蓄力 / 悬空 / 半程 / 余波），且是自包含现在时？
[ ] 关键物件的持有者、位置、开 / 合、鼓 / 瘪逐个重述？服装慢状态链（臂章歪没歪、袖口湿没湿）对得上？
[ ] 每处有意义的视线写齐目标 / 屏幕方向 / 俯仰 / 距离？反打的交点和高度差一致？
[ ] 画内不说话的人写了位置 + 状态 + 闭嘴？说话人编号集内一致？
```

### 空间账本四检（`spatial-anchoring.md` 2.4）

```text
[ ] 身份：每个 c# 的图 / <Subject N> / 说话人 ID 与账本一致
[ ] 拓扑：每个人在哪个 P#；移动的起止 P# 写清；穿门/换空间用了新 L1
[ ] 人数：房间总人数 / 帧内人数 / 进出事件三级一致；画外的人没传卡
[ ] 轴线：机位在轴的哪一侧；前景肩在哪；视线朝哪；与上一镜连续还是相反
```

三条扣分即返修：第一帧就错位 / 镜头一动就乱 / 对视方向不成立（错误路由见 `spatial-anchoring.md` 8.1）。

### 切点矛盾与空间硬闸（任一未解释即返修）

- **【高危】目送离场戏的"正面特写 vs. 后景背影"180°/ 前后景空间悖论**：前镜 B 背对 A 走远，后镜切到 **A 的正面脸部特写（相机在 A 正前方往回拍 A 的脸）**，却仍在后镜写"B 的背影在 A 身后的背景里越走越远"。一旦发现此类正反打前后景颠倒，必须立即返修：拍 B 远去背影用**越过 A 肩膀的后方机位**（前景 A 背影 + 远景 B 背影）；切 180° 反打拍 **A 的正面特写**时，B 必定已向**镜头前方画外**走远，**A 身后的背景只能是反方向的空街道与静止地标**。
- **【高危】常量块逐条变短**：第 1 单元主体定义写全（年龄、发色、发型、发饰、瞳色、服装结构），第 2 单元少两项，第 3 单元只剩"the same woman as before"，第 5 单元只剩一个名字。H3 无状态，缩写的那几项就从第 2 单元起开始自由漂移，到第 5 单元脸已经换人，而每一条单独看都没报错。**返修：从规格卡整块复制常量块，不改任何描述项；状态（刀在谁手上、袖子湿没湿、门开没开）写进 `POSE AND STAGING` 与 `CONSISTENCY LOCK`。**
- **【高危】席位与入口漂移**：上一单元两人并排坐在同一张桌的同一侧，这一单元变成对面坐 / 换了另一张桌 / 一人站到另一侧而无可见走动过程；或新角色凭空出现在画面里，没有从已声明入口进入；或背景里的桌子、窗、柜台换边。这类错误不是"换机位"能解释的，必须返修场面调度图，并在本单元重述被拍到的席位与入口（`text-anchoring.md` §2.7）。
- **【高危】多视图侧面朝向与银幕方向颠倒**：角色位于画左朝画右（展示解剖学右侧），却在提示词中写匹配"正左侧面图（anatomical left-side profile）"。
- **【高危】争吵 / 挽留戏原地站桩单调调度**："B 想走、A 挽留"的戏份缺少边走边追、拉手急停、设计支点宣泄、用力甩开手离去的动态位移链（五段式见 `scene-playbooks.md`）。
- **【高危】跨镜泪痕丢失**：前镜已经写眼泪滑落面颊，后镜切回同一人脸部特写时未写 `preserving the glistening wet tear track on the cheek`。
- **【高危】接触证据含糊**：某次攻击只写"互殴 / 拳脚相撞 / 兵器碰撞"，没有实际接触双方的具体侧别与部位；武器只标一方段位，或瞄准部位和实际格挡 / 命中部位混为一谈。
- **【高危】运动类型重置**：前镜横向飞行，后镜凭空改成原地竖直下坠；上升 / 下降阶段、水平 / 垂直速度或轨迹无依据重置。
- **【高危】重复起手 / 命中 / 未释放**：连续切点重复起手或命中；上镜未接触、下镜已完成交接 / 受伤 / 击飞；设计支点与松手之间缺少甩开或释放过程。
- **【高危】世界状态重置**：世界位置、相对高度、间距或落点重置；自身右侧与画右混用；机位和所写画面左右矛盾。
- **【高危】反打肩侧与视线不同侧**：前景肩在左，焦点人物却看右；或 A/B 两镜都用同一行轴线，两个人都看同一侧。返修：用 `spatial-anchoring.md` 的轴线表取行，肩侧 = 视线侧、A/B 相反、手性开场定一次。
- **【高危】人数三级不一致**：帧内人数与画面实际不符；画外角色被带进画面；出画被当成离场。返修：账本记房间总人数，本镜写帧内人数，时间码写进出事件；删画外身份卡（`spatial-anchoring.md` 六）。
- **【高危】机位移交跨轴或在台词窗口内移动**：移交路径越过两人连线，或台词还没说完镜头还在动。返修：路径锁在轴的一侧，台词前停稳（`spatial-anchoring.md` 六）。
- **【高危】方向反转无依据**：朝向、追逐或投射方向反转，无可见转弯、新轴或明确时间关系解释。

次一级但仍要看：道具交接、握持 / 腕部解脱顺序、格挡 / 命中、转身 / 换位、遮挡 / 画外、两人分离与离场反打、生理后果与泪痕及特效的跨镜继承（详见 `continuity-ledger.md` 第五节）。

## 第四轮：H3 格式与交付合规

按 `h3-output-spec.md` 与 `delivery.md` 核：

```text
[ ] 三字段齐全：integrated_multimodal_description / overall_soundscape / non_diegetic_music
[ ] non_diegetic_music 有内容或显式 N/A（漏写会让模型自补 BGM，音量差可达 25 dB）
[ ] 台词只放在脸可见、镜头静止、焦点锁死的窗口；窗口内不同时安排动作
[ ] 中文 >12 字拆段，中间停 0.6–0.8 秒；破音放在第一个字
[ ] 画面内可见文字加英文双引号
[ ] 全文无跨条空词（as before / previous shot / 光秃秃的 still holding——跨单元时没有参照物；`still` 那一类靠人工判断，脚本只查显式跨条短语）
[ ] 关键物件与服装状态全部重新陈述（手上的刀、盖到胸口的被子、腰包扣着、臂章歪了、关着的门、地上的月光格纹）
[ ] 参数另行给出：duration / resolution / ratio；默认 10s / 768P / 9:16
[ ] 默认在对话里给代码块；用户要求归档时才交付 .txt（UTF-8、只含提示词、无标题/代码围栏/自检附录/中文翻译），回复字符数与链接
```

**压缩时的取舍顺序**：全局重复 → 同义修辞 → 无必要技术参数。**不删**：动作因果、接触证据、交接状态、声音时序、参考关系。

## 收尾：独立重建运动事件线

交付前不得留下未解决的连续性矛盾。**最终从提示词正文独立重建一遍运动事件线**（不看内部台账），确认它表达的就是已核对的轨迹：每一段从哪开始、为什么转向、在哪接触、结果如何、下一镜从哪接上。

正文和台账对不上时，**以正文为准修台账**——因为观众只看到正文生成出来的画面。

## 崩点表：交付时给用户的三条

每条只写这条片子特有的一种失败，格式为"症状 → 修法（具体到句子）"。三条的来源通常是：

1. 本轮最不确定的一处（通常是运镜能力边界或起手景别）
2. 本视觉档位最容易翻车的一处（3DCG 腮红 / 三渲二平面化 / 真人法令纹或油光）
3. 跨单元最脆弱的一处（泪痕、道具、地标、光位、构图重合）

最后补一句"如果不对，先改这三处"，**具体到句子，不要泛泛而谈**。
