# 实战案例复盘

七个已完成案例。每个案例只记四件事：**约束是什么 / 关键决策 / 为什么 / 换个选择会怎样**。

方法论从这些案例反向提炼而来，不要把它们当范文背，要当决策记录读。

> 案例一至六是**单条**任务。案例七是唯一一例**剧集**任务（12 个单元、从零到收尾），
> `series-workflow.md` 的七步流水线就是从它反向提炼的。

## 案例一：躺姿俯拍 · 三镜 · 半裸通用模板

**输入**：一张写实姿势参考（躺姿、双腿抬起交叉、脚掌朝镜头、前景一只手）+ 无角色设定图。要求做成可替换任意人物的通用模板。

**关键决策**

1. 三镜结构：0–3s 全身低机位 → 3.0s 切脚掌微距 → 6.5s 上摇到脸。
2. 人物特征全部用 `the woman from Image 2` 表达，不写死肤色和发色。
3. 收尾用一句长锁句覆盖姿态 + 肢体数量 + 前景手位置。

**为什么**

- 三镜的理由不是"丰富"，是**10 秒里 pose 会漂**。中间插一个微距特写，等于给模型一次"重新确认姿势"的机会，也让观众的眼睛休息一次。
- 不写死肤色，是因为模板要能换任意图。一旦写了 `pale porcelain skin`，换成深肤色参考图时模型会硬压成白的。
- 锁句放最后，因为注意力在序列末尾最集中。

**换个选择会怎样**：如果做成单镜 10 秒，pose 在第 6 秒左右开始塌，尤其脚踝交叉这种精确接触；如果写成 4 镜，每镜平均 2.5 秒，来不及建立任何一个景别，观众会觉得碎。

**崩点**：腿数变三条（前景手 + 两条腿被计成三）；第二镜切回后姿势变化。

## 案例二：POV 骑坐 · 手是唯一节奏源

**输入**：姿势参考是一张 POV 仰拍、双手在画面正中交握、脸被裁掉顶部的图。角色是 2D 动漫设定。

**关键决策**

1. 放弃复刻原图的"脸出画"，改成 8.4 秒让她抬眼直视镜头。
2. 把画面里唯一有节奏的物体（交握的手）作为全片的时间基准。
3. 20mm 超广角，明确 `her face compressed near the top edge`。

**为什么**

- 脸完全出画 → 动漫角色失去唯一识别点（呆毛和发色在画面外）。抬眼这一下用 0.4 秒换回了整条片的角色一致性，值得。
- 生理层六层都在动，但**手是唯一的节拍器**。观众的眼睛被手抓住，其余变化只是氛围。所以手的动作必须写成有明确的上下、快慢、手腕旋转。
- 20mm 是被距离逼出来的：这个姿势相机离她不到 60cm，只有超广角能同时容纳手、胸、脸。

**换个选择会怎样**：如果完全照原图裁掉脸，角色一致性无法验证，用户会觉得"这不是我的人"；如果用 28mm，脸和手无法同时入画，必须删掉一层信息。

**崩点**：手指黏连；丝袜在膝盖处被画成皮肤。

## 案例三：正面骑乘 · 台词版

**输入**：参考图是反向骑乘（背对镜头），用户口述"正面骑乘"，并给了一句台词。

**关键决策**

1. 按用户口述走正面，同时提供一行反向替换句。
2. 台词拆成两段，中间留 0.8 秒停顿。
3. 7.2 秒之后镜头完全静止。

**为什么**

- 参考图与口述冲突时，**以口述为准**，但要把差异明说。用户可能只是随手拿了张图，也可能真的想要那个姿势，说明白了他自己能选。
- 台词的停顿是全片信息密度最高的地方。`说好做完这次，[停0.8s] 要给我买 token 哦` 里那个停顿承担了全部的暧昧，比任何运镜都有效。
- 有台词的窗口必须静止，否则口型必散。

**换个选择会怎样**：如果照参考图做反向骑乘，用户会拿到一条不是他要的片；如果台词一口气说完，3.5 秒塞 12 个字，语速会被迫加快，暧昧感全失。

**崩点**：蝴蝶坐姿塌成跪坐；丝袜变纯黑阴影；台词段落脸崩。

## 案例四：事后困惑 · 衰减型 + 认知打断

**输入**：无姿势参考，台词是喜剧型反转（"刚刚插进来的不是温度计吗？"），半裸 + 白丝。

**关键决策**

1. 选衰减型弧型：0–4.8 秒全部在往下走。
2. 4.8 秒处插一个"吸气卡在中途"的定格。
3. 表情分三级递进：眉先动 → 眼后睁 → 嘴最后开。

**为什么**

- 喜剧的机制是**预期被打破**。如果一上来就惊讶，没有"预期"可打破。所以前 4.8 秒必须是可信的疲惫，衰减要真。
- `the inhale halts mid-way` 是整条片的枢纽。它同时终止了衰减曲线、标记了认知时刻、给观众一个生理层面的"卡住"。这一句比任何表情描写都值钱。
- 三级递进是因为真实的人不会一秒内做完整个惊讶表情。观众对"太快"极其敏感，会觉得假。

**换个选择会怎样**：如果用上升型（她越来越慌），就变成了惊恐而不是喜剧；如果表情一步到位，会像表情包，失去可信度。

**崩点**：演员提前惊讶（笑点提前）；呼吸写成匀速机械起伏；白丝被画成裸腿。

## 案例五：事后发火 · 转向型 + 无参考自建空间

**输入**：无姿势参考，无肢体接触设定，台词是"说好替我充 token 呢——主人又骗我！"。只是角色设定图放在第 2 槽。

**关键决策**

1. 空间三件写死在 POSE AND STAGING：位置（跪在床上）、距离（约一米）、朝向（面对镜头）。
2. 潮红方向反转：两颊中心 → 向外到下颌和耳尖，胸口最淡。
3. 呼吸全程 `fast and shallow`，绝不出现长呼气。
4. 枕头砸向镜头造成 0.2 秒全画面遮挡，然后 0.4 秒复位。

**为什么**

- 没有姿势参考时，模型会自己编一个机位。**距离是三者里最容易被漏、也最致命的一项**——不写距离，"一米"和"三十厘米"是完全不同的两条片。
- 愤怒和情欲在生理上最容易被混淆，区分点只有一个：**呼吸会不会转深**。情欲会，愤怒不会。这一条比潮红方向更本质。
- 枕头遮镜是免费的转场和节奏工具，POV 场景天然允许前景遮挡。

**换个选择会怎样**：不写距离 → 每次生成的景别都不同，无法系列化；如果潮红照情欲方向写（胸口起），观众会觉得她在勾引而不是生气。

**崩点**：三个表情在一秒内全出来；枕头遮镜后机位接不上。

## 案例六：跨风格通用模板（写实参考 → 2D 动漫角色）

**输入**：写实姿势参考 + 2D 动漫角色设定图（三视图 + 细节裁切）。要求做出可换任意角色的模板。

**关键决策**

1. 槽位声明里点名排除 `photorealistic rendering and skin texture`。
2. 镜头首句立刻钉 `flat two-dimensional rendering throughout`。
3. 每一处皮肤描写都复述 `smooth cel-shaded skin`。
4. 设定图加 `render exactly one single figure` + 排除 `the sheet layout, the three standing views, the detail crops`。

**为什么**

- 跨风格渗透发生在三个层次：构图层（槽位）、渲染层（镜头首句）、材质层（细节）。只压一个层次，另外两个会渗回来。这也是为什么必须写三件套。
- 三视图的最大风险不是"画三个"，而是"画成一张设定图的版式"，包括白底、边框、站姿。所以排除句要列到版式层。

**换个选择会怎样**：只做槽位排除 → 构图对了，但皮肤是写实的；只改风格标签 → 整体是动漫风，但特写镜头的皮肤会跳回写实。

**崩点**：三联排站姿；特写镜头风格回退；呆毛和鳍耳在某一镜消失。

## 案例七：竖屏短剧 · 12 单元接力（唯一的剧集案例）

**输入**：一句话需求——"我要做红果短剧，10 秒一个单元，穿越醒来身边躺着个白纱美女，2.5D 画风，我先去生成形象和场景图"。**手上没有任何图。**

**关键决策**

1. **第一步不是写提示词，是写资产生成提示词。** 先给 4 张图的出图提示词（女主立姿卡 / 男主立姿卡 / 卧室空镜 / 床面近景），共用一条风格锁。
2. **拒绝把"侧躺"做进锚点图。** 用户的原始描述是"穿白色长纱、侧躺"，但那是剧情画面。身份卡只做立姿，姿势交给 `POSE AND STAGING` 的关节描写。
3. **出图之后强制核对，并把差异反向写回剧本。** 核出三处：裙型是"一字肩 + 灯笼袖"不是"五层垂坠纱"、瞳色是深棕不是琥珀、男主**没有**虎口疤但颈侧有一颗痣。于是把原定的伏笔"这疤是我咬的"改成"这颗痣，我数过三年"。
4. **成片锚点只留最新一张。** 每个新单元接手时，上一张成片退场。
5. **风格中途跑偏后立刻全线改锚。** 实际成片跑成了写实而非 2.5D，用户说"也挺好"，于是把后面所有提示词的风格锁换成写实，并把 2.5D 的四视图降级为"只提供身份、排除渲染"。
6. **每个单元换一个视角，且每次换都带新信息。** 序列：POV → 正脸特写 → 床侧中近景 → 反向过肩 → 广角（房间另一端）→ 正反打 A → 正反打 B → 眼部微距 → 跟拍走位 → 过肩对峙 → 双人侧面 → 广角收尾（焦段回落）。

**为什么**

- 先做资产，是因为**提示词只能描述已有之物**。先写提示词再去凑图，会撞两个死结：写的特征图上不存在，写的空间关系图上不成立。
- 拒绝侧躺，是因为参考图会把姿势一起注入。锚点图带床，后面每一集她都会执意躺下，而且压不干净。
- 核对必须做，是因为不核对的代价不报错、不崩画面——它只是让每条提示词都花一部分注意力去压一个不存在的特征，累积三集之后脸就认不出了。
- 只留最新成片，是因为两份成片记录的是两个不同的时刻。模型面对互斥的空间关系不选一个，**取中间值**，于是距离就跳了。
- 视角轮换，是因为 12 个 10 秒如果都在同一机位，观众会疲。但换视角本身有成本（观众要重新定位），所以整集的视角变化控制在 6–8 次，且都放在情绪节点上。

**换个选择会怎样**

- 如果先写视频提示词再让用户去生成图 → 图一定对不上，返工点出现在第 2 条提示词，而资产已经付过成本。
- 如果锚点图做成"侧躺" → 每条提示词都要写 `both knees bent, lying on her right side` 去压它，压到第 4 集开始失效。
- 如果继续用那个不存在的虎口疤做伏笔 → 第 5 集发现无解，只能改剧本。
- 如果两张成片都传 → 她的距离变成"两张之间"，衔接断开，而画面"看起来好像也对"，最难发现。

**崩点**：她睁着眼睛一动不动躺着（恐怖谷）；锚点图带姿势导致后患；两张四视图互相串特征（她的长发跑到他头上）；空镜被模型补出一个人。

**这个案例反向提炼出的文件**：`series-workflow.md`、`asset-production.md`、`slot-economy.md`、`performance-physics.md`、`shot-continuity.md`。

## 跨案例的六条共同结论

1. **机位写错，全篇作废。** 六个案例里，诊断顺序永远从机位开始。
2. **转折点永远在总时长 70% 之前。** 10 秒片子的转折集中在 4.8–7.2 秒区间。
3. **一致性锁必须写关节状态和数字。** `keep the pose` 一次都没生效过。
4. **衰减型比上升型难写一倍。** 因为"不动"需要理由，"动"不需要。
5. **带台词的片子，后 3 秒必须彻底静止。** 这不是偏好，是口型的物理要求。
6. **一条提示词只能有一个笑点 / 一个转折 / 一个高潮。** 塞第二个一定互相稀释。
