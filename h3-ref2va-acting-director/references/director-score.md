# 导演总谱：锚定、调度、表演、镜头、台词

**这份文件的定位**：`SKILL.md` 2.1、2.6、4.x、5.x、4.8、4.11 的完整版。它回答三件事：

1. **参考图到底是什么，锚定到底是什么，H3 怎么锚定**；
2. 从导演视角，**空间调度、表演、镜头、台词**四层分别怎么写；
3. 怎么把四层串成一张**又长又准的总谱**——不是散文，是分层的电影总谱。

**一句话**：好的长提示词不是"写得多"，是**每一句都在做四件事之一**——下一个锚、放一个变量、排一个节拍、堵一个失败。做不到这四件事的句子，删。

---

# 第一部 锚定论

## 一、参考图：不是图，是语义包

### 1.1 模型看到的不是像素

参考图不是"给模型看一张图"，而是**被视觉编码器压成一个语义包，整体注入生成过程**。这个包里有脸、发型、服装、材质、姿态、光线、背景、镜头角度、画风——它们不是分开的字段，是一团互相牵连的语义。

所以你没法"只取脸、别的都不要"。所有 `supplies X only / ignore Y` 做的都是**减法**：规定这团语义里哪些允许通过，哪些必须挡掉。它是**语义过滤器**，不是像素遮罩——挡不干净是常态，挡得越具体越干净。

### 1.2 语义包里最显眼的东西，会赢

模型对一张图的注意力不是均匀的。**最显眼的结构会压过你真正想要的结构。**

| 素材 | 最显眼的东西 | 你可能想要的 | 后果 |
|---|---|---|---|
| 四视图角色卡 | 版面、站姿、白底 | 脸、服装 | 三联排、立正姿势被抄进每一镜 |
| 场景空镜 | 机位、构图、光 | 房间结构 | 所有单元同一个视角 |
| 上一镜成片 | 那一镜的构图、机位 | 上一刻的状态 | 这一单元变成上一单元的翻拍 |
| 姿势参考 | 别人的脸、衣服 | 动作、机位高度 | 身份污染、服装残留 |
| 多人物群像 | 所有人的位置 | 某个人的身份 | 多人身份互相渗透 |

**结论**：参考图管理的第一件事不是"它有什么"，是"它最显眼的是什么，会不会压过我要的东西"。压得过，就裁掉、排除、换图，或者用文字把真正要的东西重新抬到最显眼的位置。

### 1.3 一张图只回答一个问题

| 问题 | 素材 | 只准提供 |
|---|---|---|
| 世界看起来什么样 | 场景图 / 空镜 | 外观、家具、光向、材质；**不提供机位/焦段/构图** |
| 世界的关系是什么样 | 站位图 / 俯视图（可选） | 平面拓扑、家具节点、可走区域；**不提供外观** |
| 这个人长什么样 | 人设图 / 四视图 | 脸、发型、发饰、痣、服装结构；**不提供姿势/镜头/背景** |
| 上一刻发生了什么 | 成片 | 状态：谁在哪、手上有什么、眼睛看哪、光落在哪；**不提供构图/机位** |
| 这个动作怎么摆 | 姿势参考 | 动作、机位高度；**不提供身份** |
| 这个器物长什么样 | 道具图 | 形状、大小、握法；**不提供身份/场景** |

"一张图只回答一个问题"不是洁癖，是**防止语义包里的其他维度偷渡**。一张图承担两个职责，两个职责的排除项就会互相打架，模型取平均。

## 二、什么是锚定：四元组与契约

### 2.1 定义

> **锚定 = 用某个输入，把生成分布里的某个维度固定住，并声明其余维度自由。**

它不是"传一张图"，也不是"写一句描述"。它是一个**四元组**：

```text
锚定 = 维度 × 载体 × 强度 × 寿命
```

再加一个必填项：**排除**——这个锚点不准带进来的维度。

| 项 | 回答的问题 | 例 |
|---|---|---|
| **维度** | 锁什么？ | 身份 / 拓扑 / 站位 / 状态 / 轴线 / 人数 / 风格 / 光 / 运动 / 台词 |
| **载体** | 用什么锁？ | 身份卡 / 环境卡 / 站位图 / 成片 / 首尾帧 / 视频 / 音频 / 文字 / 种子 |
| **强度** | 锁多死？ | 硬 / 强 / 中 / 软 |
| **寿命** | 锁多久？ | 一帧 / 一次转场 / 一个单元 / 一场 / 一集 / 全剧 |
| **排除** | 不准带什么？ | 机位 / 构图 / 背景 / 姿势 / 画风 / 原音轨 |

### 2.2 锚定是一份契约

写锚点时，你其实在对模型说：

> **我锁 [维度] 为 [值]，用 [载体]，锁 [寿命]，排除 [污染维度]；其余自由。**

例：

> 我锁 **c3 的脸/盘发/十字耳坠/黑裙结构**，用 **`<Picture 1>` 的上半脸与服装**，锁 **整集**，排除 **白底、多视图版面、静态摆姿、棚拍光**；其余自由。

这句话同时回答了两个问题：**什么不能变**，以及**什么可以变**。后者同样重要——不声明自由，模型会把整个语义包都当成必须保留的东西。

### 2.3 锚定不是记忆，是"这次生成的条件"

H3 每次生成都是无状态的。它不记得上一单元。**锚点不是模型的记忆，是你在这一次生成里提供给它的条件。**

所以：

- 每个单元都要**重新提供**锚点，不能写"同上"。
- 上一单元成片是"上一刻的状态锚"，只活一次转场；下一单元要重新传最新一张。
- 身份卡、环境卡、文字账本是"长期锚"，可以跨单元复用，但**每个单元都要重新写进提示词**。
- 文字必须自包含：`as before` / `previous shot` / `still`（单独用）在跨条时是空词。

### 2.4 锚定不是复制，是约束采样

锚点不会把像素贴进画面。它做的是**缩小采样空间**：让模型更可能生成符合这个锚点的结果，而不是保证逐像素一致。

这解释了三件事：

1. **锚点越强，越像"只能这样"**；越弱，越像"大概这样"。
2. **两个锚点冲突时，模型不会报错，它会平均**——画面"看起来好像也对"，但两边都不像。
3. **锚点不能保证每一次都对**；种子、采样、上下文都会影响。所以要先换种子，再改锚点。

## 三、H3 怎么锚定：六种载体与可观察行为

> 下面说的是**可观察行为**，不是对 H3 内部实现的猜测。导演只需要按行为工作。

### 3.1 六种载体

| 载体 | 锁什么 | 强度 | 寿命 | 主要风险 |
|---|---|---|---|---|
| **图锚**（身份卡/环境卡/站位图/姿态卡/道具卡/成片） | 外观、身份、拓扑、状态、姿态、道具 | 强 | 一镜到整集 | 语义包偷渡：构图、光、姿势、背景 |
| **文锚**（账本/五锁/台词/风格锁） | 拓扑、轴线、人数、关系、动作、台词 | 中 | 整集 | 太长会稀释；太虚会漂 |
| **首帧 / 尾帧锚** | 第一帧/最后一帧的画面 | 最硬 | 一次转场 | 继承上一帧的瑕疵；与参考图模式互斥 |
| **视频锚** | 动作、节奏、运镜、剪辑 | 强（运动） | 一段参考 | 身份/背景/机位残留；一次只能一条 |
| **音频锚** | 音色、节奏、语气、台词 | 强（声音） | 一句/一段 | 需要一张嘴；原音轨会串入 |
| **种子** | 随机分布 | 硬（可复现） | 一次实验 | 换种子结果可能完全不同 |

> 首尾帧 / 视频 / 音频是否可用，取决于平台与模式；不可用时，用上一帧成片 + 参考图 + 文字代替，不要硬写一个平台不吃的载体。

### 3.2 图强文弱，但各管一段

从可观察行为看：

- **图锚**更容易压住身份、服装、材质、光线、姿态；但也会把构图、机位、背景一起带进来。
- **文锚**更容易压住关系、动作、时间、台词、谁在画外；但压不住毛孔级的脸和随机褶皱。
- **首尾帧**最容易压住"第一帧/最后一帧长什么样"；但会把那一帧的瑕疵一起继承。
- **视频锚**最容易压住"怎么动"；但压不住"这是谁"。
- **音频锚**最容易压住"声音像谁"；但它需要一个可见的嘴。

**所以锚定不是"图越多越好"，是"每个维度用对的载体"。**

### 3.3 可观察的五条 H3 特性

1. **多图会竞争。** 两张脸同时存在，语义会互相渗透；不是"提供两个角色"，是"提供两个可能被融合的面部分布"。
2. **没有负向分支。** `no` / `不要` 不会进入独立压制；排除句是语义过滤器，不是硬遮罩。所有约束要写成正向的确定状态。
3. **长文会稀释。** 提示词不是越长越强；结构清楚的长文强，重复啰嗦的长文弱。锚点要分层，不要复读。
4. **台词是音频-时间锚。** 一句台词同时锁嘴型、声音、语气、时间；台词越长，口型越容易漂。一句台词一个呼吸。
5. **种子敏感。** 同一提示词换种子可能完全不同；先换种子，再改锚点。

### 3.4 锚定的"有效层级"

不是所有锚点生而平等。按维度看，大致是：

```text
身份：身份卡 > 上一帧（如果它是身份源）> 文字
拓扑：账本/站位图 > 环境卡 > 上一帧（上一帧是投影，不是地图）
状态：上一帧 > 文字 > 身份卡
轴线：轴线表/账本 > 上一帧 > 文字
风格：风格锁 > 环境卡 > 上一帧
光：环境卡/账本（世界方向）> 上一帧（画面投影）> 文字
运动：视频锚 > 文字 > 上一帧
台词：文字 <d> > 音频锚 > 上一帧的嘴
```

这张表是**冲突仲裁**的基础：同一维度有两个锚点时，按这张表定谁赢；不是把所有锚点都塞进去。

## 四、锚定的八个维度

| # | 维度 | 具体锁什么 | 主要载体 | 验证 |
|---|---|---|---|---|
| 1 | **身份** | 脸、发型、发饰、痣、瞳色、体型 | 身份卡 | 每帧脸是否同一个人 |
| 2 | **服装/道具** | 服装结构、配饰、手持物、开合状态 | 身份卡 + 文字 + 道具卡 | 结构/配饰/持有者是否一致 |
| 3 | **拓扑** | 房间节点、家具、门/窗、可走区域 | 环境卡 + 账本/站位图 | 空间关系是否变 |
| 4 | **站位** | 谁在哪个 P#、朝向、距离、承重 | 账本 + 文字 | 人是否瞬移/换位 |
| 5 | **轴线/人数** | 正反打轴线、手性、帧内人数、画外名单 | 轴线表 + 文字 | 视线相反、人数不变 |
| 6 | **关系/权力** | 高低、领土、视线、谁看谁 | 调度图 + 文字 | 权力关系是否读得出来 |
| 7 | **风格/光** | 渲染、调色、焦段、光向、明暗 | 风格锁 + 环境卡 + 文字 | 画风/光向是否漂 |
| 8 | **运动/声音/台词** | 动作、节奏、运镜、音色、台词 | 视频锚 + 音频锚 + 文字 | 动作/口型/声音是否对 |

**一个维度一个主人。** 两个锚点管同一个维度，模型会平均；这不是加强，是自伤。

## 五、强度与寿命

### 5.1 五档强度

| 档 | 载体 | 行为 | 适用 |
|---|---|---|---|
| **硬** | 首帧/尾帧、精确数值 | 几乎只能这样 | 转场接续、关键帧、轴线 |
| **强** | 身份卡、环境卡、站位图 | 大概率这样 | 身份、拓扑、服装 |
| **中** | 上一帧状态、具体文字 | 大概这样 | 姿态、手、眼、道具状态 |
| **软** | 风格词、情绪词、氛围词 | 往这个方向 | 风格、氛围、情绪类别 |
| **噪声** | `beautiful` / `cinematic` / `dramatic` | 什么也没说 | 删 |

### 5.2 用最弱的足够锚

**强锚点会污染未声明的维度。** 能用文字锁住的，不要传图；能用一个文字值的，不要写一段形容词。反过来说，高方差维度（身份、拓扑）必须用强锚，低方差维度（情绪类别、氛围）用软锚就够。

### 5.3 寿命与半衰期

| 载体 | 寿命 | 半衰期 |
|---|---|---|
| 首帧/尾帧 | 一次转场 | 下一单元即失效（除非再传） |
| 上一帧成片 | 一次转场 | 一单元；越旧越错 |
| 身份卡 | 整集 | 全剧，但每单元要重写 |
| 环境卡 | 一场 | 换场即失效 |
| 站位图 | 一场/一段 | 换段即失效 |
| 文字账本 | 整集 | 全剧，但要逐字复用 |
| 风格锁 | 整集 | 全剧，逐字复用 |
| 视频锚 | 一段参考 | 一次迁移 |
| 音频锚 | 一句/一段 | 一句 |
| 种子 | 一次实验 | 换种子即失效 |

**上一帧是"状态锚"，不是"拓扑锚"。** 它只记录一个机位下的投影；换机位后，空间关系要回到账本。

## 六、冲突与仲裁

### 6.1 冲突从哪来

锚定冲突不是"两个锚点写得不一样"这么简单。它来自：

1. **同一维度两个主人**：身份卡和上一帧都声称自己是脸；环境卡和站位图都声称自己定义门的位置。
2. **语义包偷渡**：身份卡把构图带进来；环境卡把机位带进来；上一帧把整张画面带进来。
3. **强锚点压弱锚点**：图压文字；首帧压参考图；视频压文字。
4. **重复定义**：同一事实在三个段落写三遍，模型取平均。

### 6.2 仲裁顺序

同一维度冲突时，按顺序：

```text
1 维度所有权（谁是这一维度的主人）
2 强度（硬 > 强 > 中 > 软）
3 时效（最新 > 更旧）
4 显式覆盖（用户明确指定 > 默认）
```

不是"谁写得多谁赢"。

### 6.3 冲突矩阵

| 维度 | 第一主人 | 第二主人 | 永远不要让谁当主人 |
|---|---|---|---|
| 身份 | 身份卡 | 上一帧（仅当它是身份源） | 文字长描述 |
| 拓扑 | 账本/站位图 | 环境卡 | 上一帧（它是投影） |
| 站位 | 账本 Slots | 调度图 | 身份卡的姿势 |
| 轴线/人数 | 轴线表/账本 | 上一帧 | 文字"同侧" |
| 状态 | 上一帧 | 文字 | 身份卡 |
| 关系/权力 | 调度图 | 上一帧 | 风格词 |
| 风格 | 风格锁 | 环境卡 | 上一帧（除非 1:1） |
| 光 | 环境卡/账本（世界方向） | 上一帧（画面投影） | 文字"电影感" |
| 运动 | 视频锚 | 文字 | 上一帧 |
| 台词 | 文字 `<d>` | 音频锚 | 上一帧的嘴 |

**口诀：状态从成片，拓扑从账本；身份从卡，风格从锁；运动从视频，台词从文字。**

## 七、预算与槽位

### 7.1 图锚预算

| 张数 | 状态 | 纪律 |
|---|---|---|
| 2–3 | 稳定区 | 每张一个职责，排除句写全 |
| 4–5 | 可控 | 每张必须有不可替代的职责；开始删边缘图 |
| 6 | 警戒 | 准备删；同一维度不要两张 |
| 7+ | 平均区 | 同一张脸会被平均成"谁也不像" |

### 7.2 文字预算

| 任务 | 建议英文词数 | 超了先砍什么 |
|---|---|---|
| 10s，1–2 人 | 250–400 | 形容词、重复身份描述 |
| 10s，3–4 人 | 350–500 | 次要角色服装细节，保节点/人数 |
| 完整总谱（多镜/多角色） | 600–900 | 重复锚点、无 job 的镜头、无动作的台词 |

**长不是罪，重复是。** 一段话只做一件事：下锚、放变量、排节拍、堵失败。

### 7.3 锚点替代

| 想省 | 用 | 别用 |
|---|---|---|
| 多张人物站位图 | 一张站位图 / 文字账本 | 每个人一张位置图 |
| 文字描述身份 | 身份卡 | 200 词外貌描写 |
| 文字描述房间 | 环境卡 + 节点表 | 逐段复述家具 |
| 文字描述动作 | 视频锚（动作迁移） | 逐拍写舞步 |
| 文字描述声音 | 音频锚 | 用形容词猜音色 |

## 八、验证与修复

### 8.1 生成后按维度验

```text
[ ] 身份：每帧同一个人？配饰/痣/发型在？
[ ] 服装/道具：结构、持有者、开合状态对？
[ ] 拓扑：门/窗/家具/通道没换边？
[ ] 站位：谁在哪个 P#？有没有瞬移？
[ ] 轴线/人数：视线相反？帧内人数对？画外的人没进来？
[ ] 关系/权力：高低/距离/视线读得出？
[ ] 风格/光：画风/光向没漂？
[ ] 运动/声音/台词：动作/口型/声音对？
```

### 8.2 漂了先修哪一层

```text
1 换种子（先排除随机方差）
2 找维度：哪一维漂了？
3 找冲突：这一维有几个主人？
4 换载体：文字压不住 → 换图；图污染 → 换文字/裁图
5 加强度：中 → 强；强 → 硬（关键帧）
6 最后才重写整条
```

**不要用"加更多形容词"修身份；不要用"加更多锚点"修一个已经有两个主人的维度。**

## 十一、锚定三条铁律

1. **一个维度一个主人。** 两个锚点管同一维度，模型会平均；不是加强，是自伤。
2. **锚点越强越窄。** 强锚点会污染未声明的维度；能用弱锚解决的，不要上强锚。
3. **锚点不是记忆。** 每个单元都要重新提供；上一帧只活一次转场，身份卡/账本要每单元重写。

# 第二部 空间调度

> 空间账本（N/P/K/c/轴线）解决"在哪"；这一部解决"这个'在哪'说明了什么关系"。

## 一、空间是关系，不是背景

同一张桌子，两个人**并排坐**是同盟，**对坐**是对峙，**一个人站着俯视**是权力，**一个人从背后靠近**是入侵。空间不是背景板，是**人物关系的物理化**。

导演看空间，不看"房间长什么样"，看六张图：

| 图 | 回答 | 写法 |
|---|---|---|
| **节点图** | 门/窗/家具在哪 | 账本 N# |
| **权力图** | 谁高谁低、谁站谁坐、谁占主光 | 高度/机位/光位 |
| **领土图** | 谁拥有哪块地方、谁侵入谁 | P# 归属、距离变化 |
| **视线图** | 谁看谁、谁看不见谁 | 视线向量、遮挡 |
| **运动图** | 谁从哪进、经过哪、停在哪 | 入口/路径/停点 |
| **声音图** | 画外有什么声音、从哪来 | 鞋声/门/走廊人声 |

## 二、十个调度原则

1. **高度 = 权力。** 站着俯视坐着的人，权力立刻成立；让被压制的人坐着、压制者站着，比任何台词都直接。
2. **距离 = 关系。** 公共/社交/个人/亲密四档；一个人主动进入另一个人的个人距离，是关系的转折点。
3. **领土 = 占有。** 谁坐主位、谁靠窗、谁守门、谁占通道；侵入领土比进入画面更有戏。
4. **轴线 = 冲突线。** 两人连线是权力分界；跨轴必须靠切，不能在一个镜头里漂移。
5. **纵深 = 等级。** 前景/中景/远景不是构图，是"谁在明处、谁在暗处、谁在看着"。
6. **斜线 > 直线。** 三个人排成一条线，画面就死了；用斜线、三角、前后错位。
7. **入口 = 戏剧。** 谁从哪扇门进、什么时候进、进来后停在哪，比"她走进来"具体一百倍。
8. **房间是角色。** 柜台、窗、桌子、门框、走廊，都可以成为压力、屏障、诱惑或出口。
9. **为剪辑而调度。** 站位要能给出多个可用机位；不要把所有人物贴在一面墙上，否则只能拍正面。
10. **每一个移动都要改变权力。** 起身、坐下、靠近、后退、转身、走出画——每一个动作都要改变"谁占上风/谁被围住/谁被看见"。

## 三、调度节拍：建立 → 入侵 → 占有 → 见证 → 余波

| 节拍 | 空间发生什么 | 权力变化 | 镜头任务 |
|---|---|---|---|
| **建立** | 两个人对坐/并排，桌子是屏障 | 平衡 | 交代空间、距离、关系 |
| **入侵** | 第三人从入口进入，穿过通道，停在桌边 | 空间被打破 | 用入口/走位/高度差交代 |
| **占有** | 她坐下/俯身/侵入个人距离/勾手臂 | 她占上风 | 低角/近景/前景 |
| **见证** | 旁观者的视线、身体、筷子停下 | 关系被公开 | 反应镜/脏单/过肩 |
| **余波** | 被压制者试图恢复/失败，旁观者开口 | 新平衡/新冲突 | 三人镜/侧面/定格 |

**食堂场景的调度**：

- 建立：两个男生坐在长桌北侧，一个在左、一个在右，桌子横在镜头和他们之间；窗光从右侧来，售卖台在左侧。桌子是屏障。
- 入侵：黑裙女从右侧窗边通道进入，逆光，经过桌尾，停在右侧男生的右边。她站着，他们坐着——高度差先说话。
- 占有：她坐下，进入他的个人距离，左臂穿过他的右臂，头靠肩；桌子不再是屏障，反而把她和他围在一起。
- 见证：左侧男生隔着同伴看她，筷子停在碗上；他的视线从她→同伴→她，形成三角。
- 余波：她转头对左侧男生礼貌又占有的笑；右侧男生试图抽臂失败；左侧男生破音。

## 四、调度总谱与写法

| 拍 | 时间 | 谁移动 | 从哪到哪 | 为什么 | 权力变化 | 视线 | 声音 |
|---|---|---|---|---|---|---|---|
| 1 | 0.0–2.0 | 无 | — | 建立 | 平衡 | 室友→男主 | 食堂底噪 |
| 2 | 2.0–4.0 | c3 | 东侧通道→桌右 | 入侵 | 她出现 | 两人→她 | 高跟鞋 |
| 3 | 4.0–6.0 | c3 | 站→坐（P5） | 占有 | 她压住他 | 她→他 | 皮裙/裙摆 |
| 4 | 6.0–8.0 | 无 | — | 见证 | 室友被排除 | 室友→两人 | 筷子停 |
| 5 | 8.0–10.0 | 男主 | 试图后撤 | 余波 | 他失败 | 他→室友 | 吞咽 |

**写法**：先写 `World`（节点/光），再写 `Blocking`（谁在哪、面朝哪、距离多少），再写 `Power/Territory`（谁占哪、谁侵入谁），再写 `Sightlines`（谁看谁、谁看不见），最后写 `Movement`（从哪到哪、用了多久、为什么）。不要写"她坐在他旁边"——写"她坐在他右侧，髋部贴着他的髋，左臂穿过他的右臂，胸口距他不到二十厘米"。

## 五、调度与镜头

调度不是给一个机位看的，是给**一组机位**看的。好的调度自带覆盖：

- 一个高角能看到整张桌和三人的位置；
- 一个低角能看到站姿的权力；
- 一个侧向剖面能看到两人的距离；
- 一个脏前景能看到旁观者的反应；
- 一个插入能看到手/道具/耳饰。

**如果你调度完发现只有正面能拍，说明你把人排在了同一面墙上。** 重新排成斜线/三角/前后错位，让每个机位都有东西可拍。

# 第三部 表演总谱

## 一、表演是行动，不是情绪

> **不要演情绪，演"他想得到什么，以及他愿意为此做什么"。**

每个角色在每个节拍有四个东西：

| 项 | 问题 | 例（黑裙女） |
|---|---|---|
| **目标 Objective** | 他想要什么？ | 公开宣示"他是我的" |
| **障碍 Obstacle** | 什么挡着他？ | 室友在场、男主尴尬 |
| **战术 Tactic** | 他做什么来得到？ | 逆光进入、站高、贴近、勾臂、耳语、对室友笑 |
| **调整 Adjustment** | 对方反应后他怎么变？ | 男主僵住→她扣得更紧；室友瞪→她笑得更明显 |

**情绪是行动的结果，不是行动本身。** 你写"她很得意"，模型给你一个表情；你写"她当着室友的面把他的手扣进自己臂弯，眼睛弯起来"，模型给你一个行为。

### 1.2 反应动作：被触碰 / 被抱住 / 被拉拽

**意图动作写"力"，反应动作写"反射弧"。** 被触碰的人不是先"决定"怎么演，而是先被身体出卖。你写 `freeze`，模型就真的把他冻住——**冻结不是反应，是反应的缺席**。

#### 反射弧六拍

| 拍 | 时间 | 身体发生什么 | 写法 |
|---|---|---|---|
| **1 局部** | 0.1–0.3s | 被碰到的地方先缩：手臂一抽、肩一抬、筷子一抖 | `his forearm flinches; the chopsticks jerk` |
| **2 惊跳** | 0.3–0.6s | 躯干后撤半寸、肩胛上提、半口吸气、眼睛睁大 | `his torso jerks back an inch, his shoulder jerks up, a sharp inhale` |
| **3 定向** | 0.2–0.4s | 头/眼转向接触源：谁碰我？ | `his head turns to her` |
| **4 评估** | 0.4–0.8s | 看是谁，再看旁观者：证明清白/求助/尴尬 | `his eyes flick to the roommate and back` |
| **5 对抗/顺从** | 0.4–1.0s | 后撤、撑桌、被拉回、僵住、靠过去 | `he braces his free hand on the table as she pulls him in` |
| **6 余波** | 到切点 | 呼吸、吞咽、手的位置、眼神 | `his ears redden; he swallows; his hand stays on the table` |

**顺序不能反。** 先惊跳再定向，是真人；先看再缩，是演。**不要用 `freeze` 当第一拍**；要冻，也放在惊跳/定向之后，写成 `stiffens after the pull`。

#### 两力模型：拉入 vs 后撤

| 力 | 谁出力 | 写法 |
|---|---|---|
| **拉入力** | 主动方 | 她的手臂收紧、把他往自己身上带、他的重心被带偏 |
| **后撤力** | 被动方 | 他的躯干后仰、肩胛上提、后脚/椅面向后撑、自由手撑桌 |
| **合成** | 两者同时 | 僵住、前倾、踉跄、椅脚刮地、筷子脱手 |

只写"他被抱住" = 一个静态姿势；写"她拉 + 他撑 + 他僵 + 惯性靠过去" = 一段反应。

#### 接触图

- 谁碰谁、碰哪里、用哪只手、隔着什么布料；
- 先写局部反应，再写全身；
- 被动方的自由手在哪、撑着什么、有没有抓住桌沿/椅背/衣角；
- 接触前他正在做什么（吃饭/说话/拿筷子），被打断的动作要留下证据（筷子停在半空/落桌/汤洒）。

#### 镜头与声音

- **镜头要带到肩、腰、桌面**；只拍脸的特写会把身体反应切掉。**不要一有反应就推近。**
- 高角/侧面/中景比紧特写更能看见躯干后撤和撑桌。
- **声音**：椅脚刮地、筷子落桌、半口吸气、布料摩擦。声音比表情更能卖"吓一跳"。

#### 接触反应总谱表

| 时间 | 接触 | 局部 | 惊跳 | 定向 | 评估 | 对抗/顺从 | 合成 | 声音 | 镜头 |
|---|---|---|---|---|---|---|---|---|---|
| 0.00 | 她扣住他的右前臂 | 前臂一缩、筷子一抖 | — | — | — | — | — | 筷子轻响 | 微距 |
| 0.30 | 她还握着 | — | 躯干后撤半寸、肩胛上提、半口吸气、眼瞪 | — | — | — | — | 吸气 | 低角双人 |
| 0.80 | 她靠近 | — | — | 头转向她 | 眉头内收、嘴唇微张 | — | — | — | 低角双人 |
| 1.40 | 她耳语 | — | — | — | 眼睛从她移到室友，头只转一半 | 自由手抬到一半停 | — | — | 低角双人 |
| 3.40 | 她双臂收拢 | — | — | — | 眼睛还在室友方向 | 他撑桌、她拉回 | 肩被压紧、重心被带偏、筷子落桌 | 筷落/椅响 | 侧面三人 |
| 8.40 | 她扣回 | — | — | — | 眼睛短暂闭上 | 他放弃、惯性靠过去 | 身体靠向她 | 呼吸 | 侧面三人 |

#### 食堂场景的男主反应（可直接照抄）

```text
0.00 她的手指扣上他的右前臂：他的前臂一缩，筷子一抖，轻响。
0.30 他的躯干向后撤了半寸，肩胛上提，半口吸气，眼睛睁大。
0.80 他转头看她，眉头内收，嘴唇微张（不可置信）。
1.40 他的眼睛从她脸上移到室友方向，头只转一半，自由手抬到一半停住（表示清白）。
3.40 她双臂收拢把他拉回：他的躯干被带向她，肩被压紧，自由手撑住桌沿，筷子脱手落在桌上。
4.20 他僵在她怀里，重心被带偏，耳朵红，喉结吞咽；眼睛还在室友方向。
8.40 他试图直起身体，被她扣回；他放弃，身体惯性靠向她，眼睛短暂闭上。
```

**判据**：把这段交给一个没看过戏的人，他能不能演出"先吓一跳、再看她、再看室友、被拉回、僵住、靠过去"？不能，就是反射弧没写全。

### 1.3 双人：一场戏是来回，不是两段独白

> **越规范，越不像人在反应。清晰 + 准确 + 有序 = 假。**（资料原图 11）
>
> 不是台词写得不好，是**关系没有发生**：A 说完，B 接上；A 演完，B 反应。两个人各自完成了任务，却没有真正接住对方。

#### 什么叫"接住"：回合与反反应

关系不是"两个人各有情绪"，是 **A 的动作改变了 B，B 的改变又改变了 A**。一次这样的交换叫一个**回合（exchange）**。

```text
刺激 → 接收（局部反射）→ 解释（他为什么这样）→ 冲动 → 行动 → 对方接收 → ……
```

- 一个回合 **2–3 秒**；10 秒单元 **3–6 个回合**。少于 3 个会僵，多于 6 个会碎。
- 每个回合必须有**反反应（counter-reaction）**：一方对另一方的反应做出调整——通常是主动方调整战术，也可以是被动方反施（她拉，他撑；他撑，她扣得更紧）。
- **没有反反应，就是两段独白剪在一起。** 她抱他，他僵住——到此为止，是两张照片；她抱他，他后撤，**她因此扣得更紧**——关系才发生。

#### 七种回合

| 回合 | 结构 | 食堂例 | H3 写法 |
|---|---|---|---|
| **施—受** | A 出力，B 承受并变形 | 她扣臂，他后撤 | `her fingers close; his forearm flinches, his torso jerks back` |
| **施—拒** | A 出力，B 顶回 | 她拉，他撑桌 | `she pulls; he plants his free hand on the table and pushes back` |
| **施—反施** | A 出力，B 用另一个动作回敬 | 她抱，他转头看室友 | `she hugs; he turns to the roommate — which makes her tighten` |
| **试探—回应** | A 给信号，B 决定接不接 | 她看他，他移开又看回 | `her eyes stay on him; his drop to the table, then return halfway` |
| **逼近—冻结** | A 缩短距离，B 停住 | 她贴近，他不敢动 | `her knee passes his; his breath stops, his hand frozen mid-air` |
| **撤退—追** | A 退，B 跟 | 他后仰，她跟上 | `his torso goes back; she follows, keeping the same gap` |
| **给—不接** | A 递出，B 不接 | 她递纸，他手不动 | `she holds out the tissue; his hand stays on the table` |

#### 双人七状态：每个回合只变一两项

| 状态 | 每回合问 | 写法 |
|---|---|---|
| **距离** | 谁进谁退？进了多少？ | 膝盖过膝盖、胸口 20cm、鞋尖对鞋尖 |
| **接触点** | 谁碰谁、碰哪里、用哪只手、隔什么布料 | 指节扣前臂、掌心压肩、手背贴手背 |
| **权力** | 谁定节奏？谁在等？ | 主动方动作慢、被动方呼吸浅 |
| **信息差** | 谁不知道什么？谁在瞒？ | 他看室友（求证），她看他的眼（知道他在想什么） |
| **情绪同步** | 两人同时外显，还是一泄一控？ | 她笑、他僵；她软、他硬 |
| **节奏差** | 谁快谁慢？谁抢谁让？ | 她 0.2s 完成，他 0.6s 才跟上 |
| **视线债** | 谁欠谁一个回看？谁不还？ | 她看他，他必须回看或故意不看 |

```text
1.2–2.2s
```

#### 遮住测试：唯一可操作的判据

> **遮住 A 的脸，只看 B，能不能读出 A 刚才做了什么？**
> **遮住 B 的脸，只看 A，能不能读出 B 刚才怎么反应？**

两边都成立，关系才发生。只成立一边，是"一个人在演，另一个人在摆姿势"。

#### 双人四个常见错

1. **镜像**：她进 10cm，他退 10cm，速度一样——像排练好的舞。真实是**不对称**：她进，他先僵、再退、退到椅背停住。
2. **同频**：同时吸气、同时眨眼、同时转头——像两个共享一个身体。错开 0.1–0.3 秒。
3. **各演各的**：两个人都对"事件"反应，不对"对方的反应"反应——没有反反应。
4. **反应太快**：事件一落，立刻给出完整表情——跳过了"评估"。真人要先看、再判断、才决定怎么反应；中间那 0.4–0.8 秒才是戏。

### 1.4 心理活动：不写内心，写三条泄露通道

**H3 没有内心。** 你写 `he realizes`、`she decides`、`he understands`，模型只会给一张"若有所思"的脸。心理必须变成三样可拍的东西：

| 通道 | 写什么 | 例 |
|---|---|---|
| **注意力的去向** | 看谁、看多久、什么时候移开、移开后又回到哪 | 他的视线在她脸上停了 0.8 秒，被室友看见后落到桌面，半秒后又回到她下巴 |
| **身体的失败** | 想做但没做完、顺序错、力道失控 | 手抬到一半停住；笑只到嘴角；筷子夹空；起身起到一半又坐下 |
| **社交面具** | 用来遮盖的动作 | 喝水、擦嘴、整理袖口、突然笑、清嗓子、看手机、给孩子夹菜 |

#### 心理的三个时间层

| 层 | 时间 | 内容 | 写法 |
|---|---|---|---|
| **反射层** | 0.1–0.3s | 身体先出卖，意识还没跟上 | 吸气停、手指收紧、瞳孔放大、肩胛上提 |
| **社交层** | 0.3–0.8s | 遮盖、解释、维持体面 | 移开视线、笑、喝水、清嗓、假装没听见 |
| **关系层** | 0.8s+ | 决定怎么对待对方 | 靠近/后退/回答/不回答/触碰/离开 |

**提示词必须按"反射→社交→关系"写。** 直接写关系层（"他决定原谅她"）= 演结果，观众看不到过程。

#### 心理 → 生理证据表（16 条）

| 心理 | 眼神 / 面部（0.3s 内） | 肢体（0.3–1s） | 回收 / 面具 | 常见错写 |
|---|---|---|---|---|
| **心动 / 被吸引** | 视线停留多 0.5s、瞳孔微放 | 身体前倾半寸、手指停在杯沿 | 被撞见快速移开、假装看别处 | "她心动了"→梦幻滤镜 |
| **心虚 / 隐瞒** | 回答前多停 0.4s、视线先看对方再看别处 | 手摸后颈、整理袖口、脚转向门口 | 语速变快、主动补细节 | "他撒谎"→坏人脸 |
| **嫉妒** | 视线钉在第三者、假笑只动嘴 | 下颌收紧、手指抠掌心、筷子停半空 | 转头问一个无关问题 | "她吃醋"→撇嘴 |
| **愧疚** | 不敢对视、视线下落 | 主动倒水/递纸、肩膀内收 | 过度解释、笑 | "他内疚"→低头哭 |
| **恐惧** | 瞳孔放大、眨眼变少 | 吸气变浅、重心后移、手指抓衣角 | 僵笑、后退半步 | "他害怕"→发抖 |
| **愤怒但克制** | 鼻翼张、视线定住 | 咬肌鼓、手指伸直又握回、呼气从鼻出 | 突然礼貌、语速放慢 | "他生气"→吼 |
| **轻蔑** | 单侧嘴角、下巴微抬、慢眨眼 | 身体后靠、整理袖口、转身 | 不看、不理 | "她看不起他"→翻白眼 |
| **占有** | 不躲视线、视线扫过旁人 | 动作慢、占据空间、触碰不问、挪杯子 | 对旁人礼貌笑 | "她占有欲强"→阴笑 |
| **服从** | 视线跟随、被看就低头 | 身体朝向对方、点头幅度小、手放低 | 重复对方最后一个词 | "他服从"→鞠躬 |
| **期待** | 眉毛轻抬、瞳孔放大 | 身体前倾、呼吸停半口、手伸出一半 | 被拒绝后立刻恢复 | "她期待"→瞪眼 |
| **失望** | 眉毛内侧塌、视线下落 | 呼气、肩塌 1cm、手松开 | 更快地挂回笑 | "她失望"→哭 |
| **释然** | 闭眼半秒、眼角松 | 长呼气、肩塌、手从桌沿松开 | 笑一下、说无关的话 | "他松口气"→大笑 |
| **怀疑** | 眯眼、头微侧、视线在两眼间来回 | 身体后靠、手停、延迟回应 | 问一个具体细节 | "他怀疑"→皱眉盯 |
| **羞耻** | 视线向下、颈红 | 手遮嘴/摸脸、含胸、想缩小 | 突然整理头发 | "她羞耻"→捂脸 |
| **决心** | 视线定住、下颌锁 | 吸满一口气、身体停止晃动、手按桌 | 动作变慢、声音变低 | "他决心"→握拳 |
| **心疼** | 眉心内收、下眼睑上推 | 手抬起又放下、身体前倾半寸 | 转过身去 | "他心疼"→流泪 |

#### 物件是心理证据

H3 对**手和物件**的理解，好于对"心理"的理解。把内心转成物件状态：

| 心理 | 物件写法 |
|---|---|
| 心虚 | 他把杯子转了半圈，杯柄从朝她变成朝自己 |
| 嫉妒 | 她的筷子停在半空，夹着的菜掉了 |
| 克制 | 他把餐巾纸叠了两次，边角对齐 |
| 占有 | 她把他的杯子挪到自己这边 |
| 恐惧 | 他的手在桌下抓住裤缝 |
| 走神 | 他的筷子在碗里搅了三圈，没夹起任何东西 |
| 决定离开 | 他把筷子并齐，放在碗沿上 |

#### 泄露 + 遮盖 = 一个完整心理节拍

- 只有泄露（红眼、吞咽、手抖）= 过火。
- 只有遮盖（微笑、喝水、看手机）= 面瘫。
- **一个泄露 + 一个遮盖**，观众才相信"这个人不想被看出来"。

```text
❌ 他很难过，但不想让她看见。
✅ 他的下眼睑绷了一下，视线落到桌面上；然后他拿起杯子喝了一口，
   杯沿挡住了半张脸。
```

#### 心理词改写表

| 不要写 | 改写 |
|---|---|
| He realizes she is lying. | His eyes stop on her mouth; he does not answer for half a second; his thumb presses the rim of the cup. |
| She is jealous. | Her eyes drop to his hand on the other woman's sleeve; her smile stays; her chopsticks stop in mid-air. |
| He is relieved. | His shoulders drop; one long exhale; his hand slides off the table edge. |
| She is suspicious. | Her eyes narrow; her head tilts; her gaze moves between his eyes and his mouth; she answers a beat late. |
| He wants to leave. | His weight shifts to the outer edge of the chair; his hand finds the back of it; he does not stand up. |

#### 不接触的双人心理对峙（可直接照抄）

没有拥抱、没有拉拽，全靠**视线债 + 物件 + 失败动作**：

```text
0.0–0.8s   她问："你昨晚去哪了。" 他继续夹菜，筷子没停。
0.8–1.6s   他答："加班。" 比正常晚半拍；眼睛看碗，不看她的眼睛。
1.6–2.4s   她的视线落到他衬衫领口；他的下眼睑跳了一下。
2.4–3.2s   他把领口往上拉，动作做到一半停住；她移开视线，笑了一下。
3.2–4.4s   她把杯子推到他手边；他接过来，指节发白。
4.4–6.0s   他喝水，喉结动；她的视线停在他喉咙上，然后回到他的眼睛。
```

**每一拍都有一个"看"和一个"躲"**：她看领口，他拉领口；她看喉咙，他喝水。没有一句心理描写，但观众知道两个人都没说实话。

### 1.5 六层交互与双人同步

一场双人戏，身体同时在六个**交互层**上说话。这六层不是身体生理六层（呼吸/潮红/汗/颤动/瞳孔/吞咽，见重型版 `physiology.md`），是**两个人之间**的交互层。**单写脸，只有一层；六层里至少写三层，人物才活。**

| 层 | 单人写什么 | 双人怎么同步 / 错位 |
|---|---|---|
| **呼吸** | 吸/停/呼/屏；半口、一次长呼气 | 惊后两人都乱，但一个浅快、一个屏住；亲密时呼吸才逐渐同步——**同步是结果，不是起点** |
| **视线** | 看谁、看哪里、停多久、何时移开 | A 看 B，B 看 C，C 看 A 的手；一人视线"欠债"，另一人必须回看或故意不看 |
| **姿态** | 重心、脊柱、肩、下巴 | 一个人前倾，另一个后仰；两人同向前倾 = 合唱 |
| **接触** | 谁碰谁、哪里、力度、布料 | 接触是**共享关节**：主动/承重/松开；一人收紧，另一人必须有可见形变 |
| **距离** | 数值/参照物 | 一人进，一人退或不退；每回合最多一次明显距离变化 |
| **话轮** | 谁说、谁听、谁插不进 | 听者在台词中反应；说话者被听者反应改变下一句 |

#### 眼神：起、持、落

眼神不是"看着对方"一个状态，是四拍：**起（谁先看）→ 持（停多久）→ 落（看哪里）→ 回（何时回来）**。

**落点决定关系**：

| 落点 | 读作 |
|---|---|
| 左眼 / 右眼 | 对峙、审问、亲密 |
| 嘴 | 想吻、想打断、读唇 |
| 下巴 | 打量、压制 |
| 手 | 关注动作；嫉妒（他给别人夹菜的手） |
| 肩 / 胸口 | 退缩、回避、害羞 |
| 身后 / 门口 | 分心、有人来了、想走 |
| 桌面 | 认输、羞愧、忍住 |
| 失焦 | 走神、崩溃、回忆 |

**持的时长**：

- 0.2–0.5s：正常扫视，不构成关系；
- 1–2s：停留，观众开始读"有意思"；
- 超过 2s：压迫、亲密或异常（病娇/威胁）；
- **不看**：回避，或权力（我允许你看，但我不看你）。

**眨眼是标点**：

| 眨眼 | 读作 |
|---|---|
| 正常 0.1–0.4s | 无信息 |
| 慢眨 0.5–0.8s | 轻蔑、调情、疲惫、慢半拍的挑衅 |
| 连眨两下 | 紧张、撒谎、忍住泪 |
| 不眨 | 恐惧、僵住、攻击前 |
| 单眼眯 | 怀疑、强光、瞄准 |

**眼睑与瞳孔**：上睑下垂 = 疲惫/轻蔑；下睑绷紧 = 强忍/要哭；眼下跳 = 崩溃前；眼周先松 = 假笑崩塌；瞳孔放大 = 兴趣/恐惧；缩小 = 厌恶/强光。

**双人四动作**：

- **追**：A 移开，B 的视线跟过去（B 更在意）；
- **躲**：A 看 B，B 看桌面（B 欠债）；
- **钉**：B 不躲，A 先移开（权力反转）；
- **借**：A 不直接看 B，借看 C 来观察 B（第三方当镜子）。

**不要写 `they stare into each other's eyes`**——真人每 1–2 秒会断开一次。写断开和回来：

```text
❌ They stare into each other's eyes.
✅ Her eyes stay on his mouth for two seconds; his drop to her hand on his arm,
   then climb back to her eyes.
```

#### 接触是一个共享关节

写接触前先回答四个问题：

1. **谁主动碰到谁？**（主动方）
2. **谁承重？**（被动方把重量交给谁，或抵住谁）
3. **谁先松？**（结束接触的人）
4. **接触后谁的平衡变了？**（重心、脚步、椅面、桌面）

四个都答不出，这个接触就是贴纸，不是关系。

#### 呼吸编排

- **惊后**：她吸，他屏；她呼，他才敢吸——一个呼吸就把权力写出来。
- **说谎**：说话前偷吸一口气；说完立刻呼气。
- **压抑**：吸气到一半停住，句子从剩余的气里挤出来。
- **亲密**：呼吸逐渐同步，但**始终差半拍**；完全同频像机器。

#### 视线债

- A 看 B = B 欠 A 一个回应：回看、移开、低头、闭眼。
- **不还债 = 权力**（她看他，他偏不看她）。
- **还债太快 = 心虚/服从**（一被看就低头）。
- **还债太慢 = 挑衅/迟钝**（停两秒才回看）。
- 写"谁欠、谁还、什么时候还"，比写"他们对视"有用得多。

#### 距离用参照物，不用形容词

- ❌ `she moves closer`
- ✅ `her knee passes his knee; her chest is twenty centimeters from his shoulder`
- ❌ `he backs away`
- ✅ `his weight is already on his back heel; his front foot drags; the chair leg scrapes`
- **每回合只改一个距离维度**：横向、纵向、高度，不要同时"贴近 + 站高 + 转身"。
- 距离变化要有**阻力**：桌沿、椅背、托盘、手臂、人群。

#### 双人同步检查表

| 检查 | 通过标准 |
|---|---|
| 呼吸 | 两人不在同一拍吸/呼（除刻意的亲密或惊后同频） |
| 视线 | 至少一次"看—被看—移开—回看"的完整债 |
| 姿态 | 两人重心方向不同（一前一后 / 一高一低） |
| 接触 | 主动方收紧时，被动方有可见形变（衣料/肩/重心） |
| 距离 | 每回合最多一次明显距离变化，且有参照物 |
| 话轮 | 听者在说话中反应，说话者被反应改变 |

**六项里至少三项要"不同步"**，否则就是两个人共享一个身体。

### 1.6 多人同时动作：六相与错峰

多人戏的两个死法：

- **只有一个人动**，其他人在等指令——像群演等开机。
- **所有人一起动**，做同一个反应——像合唱。

真实的情况是：**不同步、不同型、有因果**。

#### 六相编排

| 相 | 时间 | 发生什么 | 写法 |
|---|---|---|---|
| **1 冲击** | 0–0.3s | 事件落地，各自第一反应，错峰 0.1/0.2/0.3 | 近处的人先动；**一个人不动** |
| **2 定向** | 0.3–0.8s | 头/眼转向源；近者先，远者后 | 有人不转头，只转眼 |
| **3 分化** | 0.8–1.5s | 每人的反应类型出现 | 退/冻/前探/遮掩/撤离/附和/记录/无关 |
| **4 评估** | 1.5–2.5s | 互相看，确认"你也看见了？" | 视线三角；一人看地 |
| **5 回应** | 2.5–5.0s | 一人主导行动/台词，其他人对其反应 | **主动方只有一个** |
| **6 沉淀** | 5.0–10.0s | 余波：一人保持、一人恢复假正常、一人离场 | 最静的人最响 |

**相与相之间可以压缩，但顺序不能反**：先冲击后定向，先分化后评估。反过来就是"先想好怎么演，再被吓到"。

#### 十种反应类型：一人一种，不许重复

| 类型 | 物理签名 | 用在 |
|---|---|---|
| **后撤** | 重心后移、椅脚刮地、手抬到胸前 | 被吓到 |
| **冻结** | 呼吸停、筷子停半空、眨眼停止 | 无法相信 |
| **前探** | 头/上身向前、眯眼、嘴微张 | 想看清/听清 |
| **遮掩** | 低头喝水、擦嘴、假装夹菜 | 尴尬/回避 |
| **撤离** | 起身、拿托盘、推椅 | 不愿在场 |
| **附和** | 先看别人再决定表情 | 没主见/看脸色 |
| **表演** | 过度惊讶、捂嘴、拍桌 | 戏剧型/讨好 |
| **记录** | 掏手机、举一半又放下 | 现代题材/证据 |
| **权威** | 站起、抬手压场、沉声 | 领导/长辈 |
| **无关** | 继续吃、只抬一次眼 | 最真实的路人 |

#### 错峰五规则

1. **距离错峰**：近者 0.0–0.1s，中景 0.2–0.3s，远景 0.4–0.6s（写 `a beat later`，不用精确毫秒）。
2. **角色错峰**：主动方 0，被动方 0.2s，旁观者 0.3–0.5s。
3. **一人不动**：至少一个在场者第一拍不动（继续吃/继续说/继续擦桌子）——这是最便宜的"真"。
4. **部位不同**：一人手、一人呼吸、一人视线；不要三人都"后退 + 张嘴"。
5. **声音错峰**：椅响、筷落、吸气、咳嗽分开 0.1–0.2s；不要同时发生。

#### 因果传播：物理链 > 视线链 > 台词链

H3 不理解抽象的"因为"，但理解**物理传导**。把因果写在物件上：

- **物理链**：他后撤 → 肘碰桌 → 托盘一响 → 室友低头看托盘 → 再抬头看她。
- **视线链**：她看室友 → 室友看男主 → 男主看她 → 她笑。
- **台词链**：她的台词 → 室友破音 → 她答室友 → 男主耳红。

**最好的多人调度，是让一个动作通过桌面、托盘、椅子传到下一个人身上。**

#### 空间锚：每人四件

写每个人时，四件至少写三件：

1. **位置**：P# / 画面区（左三分之一、右缘、后景桌）
2. **距离参照**：离谁几步、隔着什么
3. **朝向**：胸口/脸朝哪
4. **手在做什么**：拿筷子、扶托盘、插兜、抓椅背

**4 人以上**：分前景/中景/背景；**最多 3 张脸可读**，其余用肩、背、虚焦。**帧内人数锁死**：`exactly three people in frame; no one enters or leaves`。

#### 视线三角

画一个三角，标"谁看谁"：

```text
她 → 男主
男主 → 室友
室友 → 她
```

至少一条边是**"不看"**（故意避开/看桌面/看手机）。三角全通 = 所有人都很闲；缺一条 = 有人在躲。

#### 声音分层

- 每人一个声音，但**只让 1–2 个声音可辨**，其余进环境声。
- 关键声音落在切点上：椅脚、筷落、托盘、半口吸气。
- 不要给三个人同时配"惊呼"——那是合唱的声音版。

#### 镜头覆盖

10 秒多人戏不要一个镜头拍完，也不要每人一个特写。一个可用的阶梯：

```text
master（全员，3s）→ 主动方 single（2s）→ 反应方 single（2s）
→ insert（手/筷子/托盘，1s）→ master 或侧面（2s）
```

- 用**脏前景**（肩/背/托盘/椅背）把 4 个人压进一个画面，比让 4 个人并排站好更真。
- 一场多人戏至少一个**插入镜**：它替你说"桌上发生了什么"。

| 拍 | 时间 | 事件 | 主动方 | 人物 A（位置/类型） | 人物 B | 人物 C | 因果传播 | 视线 | 声音 | 镜头 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 0.0–1.2 | 她扣臂 | 她 | 男主：缩/后撤 | 室友：筷停/肩弹 | 邻桌：只抬眼 | 她拉→他偏 | 她→他 | 筷响 | 低角双人 |
| 2 | 1.2–2.4 | 他看室友 | 男主 | 她：跟视线/笑 | 室友：张嘴 | 邻桌：继续吃 | 他的头转→她的眼跟 | 三角 | 吸气 | 脏单 |

#### 食堂三人六相（可直接照抄）

```text
0.0s  She sits down and hooks his right arm. (trigger)
0.1s  He flinches: his forearm jerks, his torso pulls back, his shoulder lifts. (nearest)
0.3s  The roommate's chopsticks stop halfway; his shoulders jerk; his heel slides back. (mid)
0.6s  At the next table, a woman keeps eating; only her eyes lift. (far / non-reactor)
1.2s  He turns to her; she leans in. The roommate looks at him, then at her. (differentiate + assess)
2.0s  The roommate: "嫂——嫂子？！" His voice cracks. She answers him while her hand tightens on the arm. (respond)
3.4s  He pushes off the table; she pulls him back; the tray clicks; the next table looks down at it. (physical chain)
6.0s  He gives up and leans; she rests her head on his shoulder; the roommate's mouth is still open;
      the next table resumes eating. (settle)
```

#### 四人以上：三张脸原则

- 给 **3 个人**完整反应（各一种类型），第 4 个人只给一个**"无关"或"撤离"**动作。
- 不要给 4 个人各写一套"眼→眉→嘴"——H3 会糊，观众也读不过来。
- 用前景肩/背/虚焦把人数补齐；台词只给其中 1–2 人。
- 超过 5 人，按"两桌/两组"写，不要写成一个整体。

#### 两个多人测试

- **点名测试**：闭眼，能不能说出每个人**在做不同的什么**？说不出，或有两个一样，就是合唱。
- **删人测试**：删掉一个人，这场戏有没有少一个反应/一个信息/一个阻力？没少，他是道具，不是人物。

### 1.7 双人 / 多人提示词语法

#### 双人：一回合三句

```text
[EXCHANGE 1 | 0.0–1.2s]
Driver: 主动方出力（3–4 个部位协同，写接触点/方向）。
Receiver: 被动方接收（局部 → 躯干 → 头/眼 → 评估，3–4 个部位）。
Counter: 反反应（一方对另一方的反应做出调整，1–2 个部位；通常主动方，亦可被动方反施）。
```

规则：

1. **三句必须形成闭环**：Driver 改变 Receiver，Receiver 的反应引出 Counter；Counter 又改变下一拍的 Driver。缺 Counter，就是独白。
2. **被动方写 3–4 个部位，Counter 只写 1–2 个**，不要抢戏。
3. **一段最多一个 `while`**；错峰用 `a beat later` / `half a beat later`，不用 `at the same time`。
4. **写力与接触点，不写 `tries to`**：`he braces his palm on the table and pushes his shoulder free`。
5. **台词放在第三句或第四句**，不要塞在反应中间；说完留一个尾帧。
6. **每回合写"收在哪"**：手停在哪、视线停在哪、呼吸停在哪。

#### 多人：三波 + 链 + 三角

```text
[TRIGGER 0.0s] 主动事件。
[WAVE 1 0.1s] 最近的人：局部反射 + 定向。
[WAVE 2 0.3s] 中景的人：另一种反应类型（错峰）。
[WAVE 3 0.6s] 远景的人：只做一个最小动作（不转头/继续吃/只抬眼）。
[CHAIN] 一个物理传导（肘→桌→托盘→下一个人）。
[SIGHTLINE] A→B, B→C, C→不看。
[SOUND] 两个可辨声音，错开。
[COUNT] exactly three people in frame; no one enters or leaves.
```

规则：

1. **一段最多 3 个主动作**；其他人都是反应，且必须挂在触发上。
2. **每人一个动词**，不重复：一个退、一个冻、一个前探。
3. **至少一人不动**：非反应者比反应者更真实。
4. **多人"同时"用时间码错峰**，不用 `all at once`；`all at once` 会得到合唱。
5. **4 人以上最多 3 张脸可读**，其余肩/背/虚焦；人数锁死。
6. **波次写在同一段 TIMELINE 里**：切镜只换机位，不重置时间。多人错峰是"同一段时间里不同人不同拍"，不是"每人一个镜头"。

#### 最终判据

| 对象 | 判据 |
|---|---|
| **双人** | 遮住 A 看 B 能读出 A；遮住 B 看 A 能读出 B |
| **心理** | 每条心理至少一个身体证据 + 一个遮盖动作 |
| **同步** | 呼吸/视线/姿态/接触/距离/话轮，至少三项"不同步" |
| **多人** | 点名测试 + 删人测试都通过；至少一人第一拍不动 |

| 拍 | 时间 | 角色 | 目标 | 障碍 | 战术/动作 | 触发 | 可见反应链 | 声音 | 听者反应 | 镜头 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 0.0–1.0 | 男主 | 吃完这顿饭 | 她的出现 | 咀嚼、低头 | 鞋声 | 下颌停→眼移→吞咽 | 无 | 室友抬头 | 双人 |
| 2 | 1.0–3.4 | 黑裙女 | 宣示占有 | 室友在场 | 贴近、勾臂、耳语 | 他僵住 | 眼弯→嘴角→扣紧 | 软、近、拖尾 | 男主僵、室友瞪 | 低角近景 |
| 3 | 3.4–6.4 | 室友 | 搞清状况 | 她的气场 | 瞪、张嘴、破音 | 她的台词 | 筷子停→嘴张→眼镜反光 | 破音 | 她笑、男主耳红 | 脏单 |
| 4 | 6.4–10.0 | 三人 | 各自收场 | 彼此 | 她笑、他抽臂、室友结巴 | 筷子落 | 三人定格 | 筷子响 | — | 三人/侧面 |

**每一拍只让一个角色做主动作；其他人做反应。** 不是"三个人一起演"，是"一个人行动，其他人反应，反应又触发下一个行动"。

**双人戏在"听者反应"后补一列"调整"**：对方的反应如何改变我下一拍。没有这一列，表格只是两份单人总谱并排。

## 三、微表情语法

### 3.1 部位顺序

```text
眼（视线/瞳孔）→ 眼睑（上/下）→ 眉（内/外）→ 下颌 → 嘴 → 喉/吞咽 → 呼吸
```

**先眼后眉，先眉后嘴。** 顺序反了就像在"演"。同一秒最多两个部位明显变化；其余用"保持不变"锚住。

**三区分工**：

| 区 | 部位 | 倾向 |
|---|---|---|
| **上区** | 眉、上睑、额 | 最诚实，先泄露（眉先动） |
| **中区** | 鼻翼、颧、下睑 | 最难控制，强忍时先抖 |
| **下区** | 下颌、嘴、舌 | 最会演，负责社交面具 |

顺序：**上区先动 → 中区漏 → 下区收**。反过来（先笑再皱眉）= 假。

**这条只管一张脸。** 一帧里几个人可以同时各有反应——那不是"部位过多"，是群像。多人写法见 1.6：一人一个部位、错峰、至少一人不动。

### 3.2 五个装置

| 装置 | 写法 | 效果 |
|---|---|---|
| **差一点** | `almost forms a smile, then relaxes` | 克制 |
| **冻结** | `his jaw stops, his breath holds` | 过载 |
| **失败动作** | `his hand starts to lift, then settles` | 想动但不敢 |
| **回收** | `her lips part and close again` | 欲言又止 |
| **余味** | `her eyes remain on him after the line` | 不泄气 |

### 3.3 微表情的幅度

- 只用 `micro expressions` 收幅度，不指定部位 = 幅度对了，内容空。
- 只写部位，不用 `micro expressions` = 内容有了，幅度可能过。
- **两层叠加**：`quietly hurt micro expressions` + "眼下垂→唇张又闭→吞咽"。

## 四、三股力量

强情绪不是"一个情绪"，是**三股同时存在的力**：

| 力 | 作用 | 写法 | 例 |
|---|---|---|---|
| **冲动/泄露** | 身体先出卖 | 眼眶红、吞咽、呼吸乱、手指抖 | 他耳朵红、喉结动 |
| **控制** | 意志压回去 | 移开视线、不落泪、压回哭腔、下颌紧 | 他不看她、把笑压回去 |
| **目标** | 他真正想完成的事 | 保护对方、减轻罪恶感、维持体面 | 他替她圆场、对室友摇头 |

**三股同时存在，不是从 A 变成 B。** 最强的时刻是泄露和控制同时可见，而目标决定他选哪种失败。外显只留一个；脸只出微表情，身体负责强度。

## 五、听者与群像

### 5.1 听者在演

听不是"没动作"。听者的身体在台词进行中反应：

- 手指收紧/松开；
- 下眼睑动；
- 呼吸停半拍；
- 筷子停在半空；
- 视线从说话人移到另一个人。

**台词落下才给反应，是"演完了"。** 把听者的反应插进台词的时间段里。

**听者的反应还要改变说话者的下一句**（1.3 的反反应）：他皱眉，她把后半句放软；他看别处，她停半拍再说。只插入反应、不改变说话者，仍然是两条平行线。

### 5.2 群像反应

一件事发生，在场每个人反应**类型不同**：

- 一个人后退；
- 一个人僵住；
- 一个人往前半步想看仔细；
- 一个人假装没看见。

**因果链要清楚**：因为她扑过来，所以两个人各自后退——一个错愕，一个本能。不是"所有人都做同一个反应"。

> 完整的六相、十种反应类型、错峰五规则、多人总谱与提示词语法见 1.6、1.7。

### 5.3 权力三角

三人戏不是"两个人演、一个人看"，是**三角**：

- 谁在主动；
- 谁被围住；
- 谁在见证；
- 谁看谁、谁不看谁；
- 谁的反应改变了下一拍。

## 六、表演与镜头/光/剪辑

- **镜头**：微表情要近景以内；中景只能读身体；全景只能读轮廓。
- **光**：眼底、下眼睑、嘴角需要侧光/眼窝阴影；全平光下微表情等于没写。
- **剪辑**：一个反应镜可以创造表演；一个插入（手/道具）可以替代一句台词；一个切点可以把"没演完"变成"余味"。
- **时间**：3–4 秒的关键近景要有 3–4 个有序微节拍；10 秒的单元仍按时间码拍数走，两套计数不要混。

## 七、AI 演员的边界

1. **脸的可读性随景别衰减。** 要读脸，中近景以内；不要在全景里要求微表情。
2. **中文口型需要短句。** 一句一个呼吸；超过 12 字拆段；紧特写最不稳。
3. **身份会漂。** 每个单元重申 4–6 个身份标志物；小结构（耳坠/眼镜/痣）丢失率最高。
4. **容易过火。** 情绪越强越要写"忍住"；外显给身体，脸只出微表情；全场一个最外显点。
5. **不要写 FACS/AU 编号进正文。** 用可见的解剖微动作；编号只作内部推导。
6. **不要用情绪形容词代替动作。** "她很伤心" → "下眼睑对抗湿润、喉结吞咽、视线落在桌面"。
7. **模型会严格执行 `freeze`。** 别把"冻结"当反应；被触碰/被抱住的人先有反射弧（局部→惊跳→定向→评估→对抗/顺从），冻住只能放在惊跳之后。

## 八、表演提示词语法

```text
[角色] Objective: 他想要 ______。
Obstacle: ______ 挡着他。
Tactic: 他做 ______（3–4 个部位协同）。
Trigger: 当 ______ 发生时。
Visible chain: 眼 ______ → 眼睑 ______ → 眉 ______ → 下颌 ______ → 嘴 ______ → 喉 ______。
Voice: 音量/气息/语速/尾音 ______。
Listener: ______ 在台词进行中 ______。
Tail: 台词后 ______ 停在 ______。
```

**一段只写一个主动作；一段只让一个部位大类先动；每个动作写"收在哪"。**

## 九、食堂场景的表演总谱

### 黑裙女

- 目标：公开宣示"他是我的"。
- 障碍：室友在场、男主尴尬。
- 战术：逆光进入 → 站高 → 坐下侵入个人距离 → 左臂穿右臂 → 头靠肩 → 耳语 → 对室友礼貌笑。
- 触发：他的筷子停。
- 可见链：眼弯 → 单侧嘴角 → 头偏 → 手指扣紧。
- 声音：软、近、带笑、尾音落下。
- 听者：男主僵住、耳朵红；室友筷子停。
- 尾：说完不移开，笑挂在脸上。

### 男主

- 目标：吃完这顿饭、别失态。
- 障碍：她的手臂、室友的目光。
- 战术：冻结 → 吞咽 → 眼神来回 → 试图抽臂 → 失败。
- 触发：她的耳语、室友的瞪视。
- 可见链：下颌停 → 眼移 → 喉结 → 耳朵红 → 重心后撤。
- 声音：无台词；一次失败吸气。
- 听者：她扣得更紧；室友张嘴。
- 尾：筷子仍悬在半空。

### 室友

- 目标：搞清自己看到了什么。
- 障碍：她的气场、场景的荒谬。
- 战术：瞪 → 张嘴 → 看男主 → 看她 → 破音 → 筷子落。
- 触发：她的台词。
- 可见链：眼瞪 → 嘴张 → 眼镜反光 → 手松 → 筷子落。
- 声音：`嫂——嫂子？！` 第一个字破音，第二个更高更薄。
- 听者：她对他笑；男主耳朵更红。
- 尾：嘴还张着。

# 第四部 镜头总谱

## 一、镜头是叙事者

每个镜头都要有 **job**：

- 交代空间；
- 揭示关系；
- 给权力；
- 给反应；
- 给证据（手/道具/伤）；
- 给节奏（插入/空镜）；
- 给转场。

**没有 job 的镜头是装饰。** 一个 10 秒单元里，如果两个镜头做同一件事，删一个。

## 二、五个变量 + 四个附加

| 变量 | 写什么 | 语义 |
|---|---|---|
| **高度** | 贴地/胸高/眼高/顶高 | 权力、亲密、压迫 |
| **角度** | 平视/俯/仰/侧/背 | 审视、臣服、疏离 |
| **焦段** | 广/中/长 | 空间/亲密/压缩 |
| **距离/景别** | 远/全/中/近/特 | 信息量、脸的权重 |
| **运动** | 推/拉/摇/移/升降/环绕 | 注意力、揭示、跟随 |

附加：

| 附加 | 写什么 | 作用 |
|---|---|---|
| **焦点** | 锁谁/从谁到谁/耗时 | 引导注意力 |
| **前景** | 桌沿/托盘/肩/门框 | 纵深、窥视、遮挡 |
| **背景锚** | 窗墙/柜台/北门 | 防止背景漂移 |
| **轴线侧/人数** | 轴左/右、帧内几人 | 空间连续、正反打 |

## 三、镜头阶梯

### 3.1 五镜版（10 秒，群像/对话）

```text
1 建立：高角/低角宽景，交代空间与人数
2 插入：手/道具/脚/耳饰，无脸，给节奏
3 权力：低角站姿/高角坐姿/过肩压迫
4 反应：听者/旁观者的脸
5 收束：三人/侧面/定格，给余味
```

### 3.2 四镜版（10 秒，单主线）

```text
1 建立（高/低/侧）
2 插入（手/道具）
3 权力或台词（低/高/近景）
4 反应/收束（脏单/三人/侧面）
```

### 3.3 一镜版（POV/长镜）

```text
起幅：不是场景图的机位
路径：沿轴一侧移动/推进
落幅：新信息/新人物/新状态
靠焦点、呼吸、手入画维持注意力
```

## 四、覆盖语法

| 镜头 | 作用 | 注意 |
|---|---|---|
| **Master 主镜** | 交代空间/关系 | 不要用最广的、最平的；用高/低/侧 |
| **OTS 过肩** | 站在谁那边 | 肩侧=视线侧；前景肩锁住 |
| **Clean single 干净单人** | 读脸 | 背景要有空间信息，不要白墙 |
| **Dirty single 脏单** | 读脸+关系 | 前景放肩/杯/桌沿/门框 |
| **Two-shot 双人** | 关系 | 不要并排站；用前后/斜线 |
| **Three-shot 三人** | 权力三角 | 谁在中间、谁在前、谁在暗处 |
| **Insert 插入** | 证据/节奏 | 手/道具/脚/耳饰；无脸 |
| **POV** | 主观 | 主体不入画；位移写剧情 |
| **Profile 剖面** | 距离/对峙 | 避开正面；看两人之间的距离 |
| **Reflection 反射** | 疏离/双重 | 镜面/玻璃/水面 |
| **Silhouette 剪影** | 氛围/权力 | 不读脸；读轮廓 |
| **Top-down 顶拍** | 图案/命运 | 人变成棋子；不要滥用 |
| **Low angle 低角** | 压迫/英雄 | 站姿/权力 |
| **High angle 高角** | 脆弱/审视 | 坐姿/被围 |
| **Dutch 荷兰角** | 不安 | 需要 LoRA；不挂别用 |
| **Handheld 手持** | 真实/紧迫 | 幅度小；台词窗口不用 |
| **Dolly/Zoom/Pan/Arc/Crane** | 注意力/揭示 | 一个时间段一个主运镜 |

## 五、镜头语言

- **焦段**：广角=空间/压迫/畸变；中焦=客观/对话；长焦=亲密/压缩/窥视。
- **高度**：低角=权力；高角=脆弱；眼高=平等；顶拍=命运/图案。
- **运动**：推=看清；拉=揭示/离开；摇=连接；移=陪伴；环绕=审视；升降=揭示/压迫。
- **焦点**：最便宜的叙事工具；从手到眼，从前景到后景；写耗时和 `no hunting`。
- **切**：切在动作完成、反应、声音、视线；切点后要换骨架/高度。

## 六、背景锚与连续性

换机位时，选一个远端地标做**背景锚**：

- 食堂：窗墙（东）/售卖台（西）/北门；
- 办公室：窗墙/远端门/打印机；
- 宿舍：远端门/窗/桌；
- 楼外：玻璃门/台阶/侧墙。

保持它在相邻镜里的**相对大小和位置**。机位靠近/拉远要有动机，或用前景遮挡过渡。**不要出现"人没动，窗墙却变大了"**——这是机位距离没锁，不是空间错。

# 第五部 台词总谱

## 一、台词是行动

一句台词不是"信息"，是**一个人对另一个人做的一件事**：

- 试探；
- 宣示；
- 安抚；
- 攻击；
- 诱惑；
- 拒绝；
- 求和；
- 告别。

写台词前先问：**这句话想改变对方什么？** 答不出来，这句话可以删。

### 1.1 三层

| 层 | 是什么 | 写不写进提示词 |
|---|---|---|
| **文本** | 说出来的字 | 写，`<d>` |
| **潜台词** | 真正想说的 | 不直接写；转成动作/语气/停顿 |
| **行动** | 这句话对对方做什么 | 写进表演方向（objective/tactic） |

## 二、话轮设计

| 话轮 | 机制 | 写法 |
|---|---|---|
| **完整轮** | A 说完 B 接 | A 最后一个音节落下，B 半拍后开口 |
| **抢话** | B 压进 A 的尾音 | B 第一个字压进 A 最后两个字；A 嘴还动半拍 |
| **叠话** | 两人同时说 | 重叠约 0.4s；A 主音，B 更低更轻 |
| **插不进** | B 尝试失败 | 张嘴、吸气、没声；手抬一半停 |
| **沉默** | 一轮没有词 | 吞咽、移开视线、呼吸 |
| **自我修正** | 改口 | "I— 不是。算了。" |
| **失败启动** | 口型先成、声音不出 | 一次失败吸气，然后吞咽 |

**一轮只服务一个关系变化。** 不要一轮里又抢话、又沉默、又修正。

## 三、台词的音乐

| 参数 | 写法 | 效果 |
|---|---|---|
| 音量 | `barely voiced` / `a thin whisper` / `carrying voice` | 小=亲密；大=失控 |
| 气息 | `breathy` / `cracked` / `hoarse` / `tight` | 破音放第一个字 |
| 语速 | `unhurried` / `trailing` / `rushed` | 慢=掌控；快=泄漏 |
| 尾音 | `the last syllable dropping` / `rising` | 落=陈述；升=求 |
| 音高 | `low in the chest` / `thin and high` | 胸腔=稳；高薄=崩 |
| 音色 | `dry` / `wet` / `hollow` | 干燥=克制；湿=哭腔 |
| 口音/咬字 | `clipped` / `soft consonants` | 咬字=控制；含混=失控 |
| 犹豫 | `a half-beat hesitation` | 停顿=寻找语言 |

## 四、长度、呼吸与失语

- 一句一个呼吸；中文每秒 4–5 字；加 30% 余量。
- 超过 12 字拆段；拆点在语义停顿；两段之间留 0.6–0.8s 的纯呼吸。
- **不要写 `<pause>` 标签**；停顿写进正文、拆句或时间码。
- 失语落在**最难面对的词**上：口型先成、声音不出、失败吸气、吞咽、改口。
- 不要写"口吃"两个字；写身体。

## 五、台词与调度/镜头/听者/声音

- **调度**：停手说话，或说完再动；不要边大幅度走位边说。
- **镜头**：台词窗口脸可见、镜头静止、时间够；中近景以内；不要紧特写。
- **听者**：听者在台词进行中反应；台词后切反应镜。
- **声音**：台词不进 `overall_soundscape`；环境声/呼吸/吞咽进；重叠只短插话。
- **画外音**：只给声音不给词最安全；给词就可能被塞一张脸。

## 六、台词总谱表

| 时间 | 说话人 | 台词 | 目标 | 潜台词 | 话轮 | 触发词 | 声音 | 听者反应 | 镜头 |
|---|---|---|---|---|---|---|---|---|---|
| 0.9–2.6 | 室友 S1 | 你这两天怎么了？ | 试探 | 你不对劲 | 完整轮 | "怎么了" | 低、随意 | 男主咀嚼不答 | 双人 |
| 0.6–3.4 | 女主 S2 | 老公，怎么吃饭不叫我。 | 宣示占有 | 你是我的 | 完整轮（压场） | "老公" | 软、近、拖尾 | 男主僵、室友瞪 | 低角近景 |
| 5.2–6.4 | 室友 S1 | 嫂——嫂子？！ | 确认 | 这不可能 | 失败启动 | "嫂" | 破音、第二声更高 | 她笑、他耳红 | 脏单 |


## 八、食堂场景的台词总谱

### 室友的开场

- 目标：试探男主为什么走神。
- 潜台词：你不对劲。
- 话轮：完整轮；说完等半拍，男主不答。
- 声音：低、随意、嘴里还有饭。
- 听者：男主咀嚼、眼睛在碗里。
- 镜头：双人中景，镜头静止。

### 女主的主句

- 目标：公开宣示"他是我的"。
- 潜台词：你逃不掉，而且我要让他们看见。
- 话轮：完整轮，但她压着场；说完不急着收，笑留在脸上。
- 台词：`老公，怎么吃饭不叫我。`
- 触发词：`老公` 轻而近；`不叫我` 放慢、尾音落下。
- 声音：软、近、带笑、气声；不是喊，是耳语。
- 听者：男主下颌停、耳朵红；室友筷子停。
- 镜头：低角近景，脸可见，镜头静止。

### 室友的破音

- 目标：确认自己没看错。
- 潜台词：这不可能。
- 话轮：失败启动；`嫂` 破音，停半拍，`嫂子` 更高更薄。
- 声音：第一个字破，第二个字提；气不够。
- 听者：她转头对他笑；男主耳朵更红。
- 镜头：脏单，前景是男主的肩/水杯；镜头静止。

# 第六部 四层总谱（永乐大典）

## 一、总谱的结构

一张完整总谱，不是散文，是**六层对齐在同一时间轴上**：

```text
[0] 锚定总谱    维度/载体/强度/寿命/排除/冲突
[1] 世界与调度  N/P/K + 权力/领土/视线/运动/声音
[2] 人物与身份  身份卡 + 服装 + 标志物
[3] 表演总谱    目标/障碍/战术/触发/可见链/声音/听者
[4] 镜头总谱    Job/焦段/高度/角度/景别/运动/前景/背景锚/轴线
[5] 台词总谱    说话人/台词/目标/潜台词/话轮/触发词/声音/听者
[6] 时间轴      节拍 + 切点 + 台词窗口
[7] 声音        环境声 + 动作声 + 非语言人声
[8] 一致性锁    人数/状态/惯性/身份/轴线/背景锚
```

**每一层只回答自己的问题。** 空间不抢表演的活，表演不抢镜头的活，镜头不抢台词的活。

## 二、总谱模板

## 四、总谱自检

```text
[ ] 每个维度只有一个主人？
[ ] 每个锚点都写了强度/寿命/排除？
[ ] 空间账本与调度图一致？权力/领土/视线/运动/声音都写了？
[ ] 每个角色都有 Objective/Obstacle/Tactic？每个节拍只有一个主动作？
[ ] 被触碰/被抱住的人有反射弧（局部→惊跳→定向→评估→对抗/顺从）？两力都写了？
[ ] 每个近景有 1–2 个部位变化 + 回收？全场只有一个最外显点？
[ ] 每个镜头都有 Job？相邻镜头换了高度/角度或轴线？
[ ] 第一镜不是场景图的机位？有插入/反应/脏前景/背景锚？
[ ] 台词一句一个呼吸？话轮不是排队？听者在台词中反应？
[ ] 声音/台词/口型在同一条时间轴？没有 `<pause>` 之类规范外标签？
[ ] 每一句都在做"下锚/放变量/排节拍/堵失败"之一？没有就删。
```

## 五、最后三条

1. **锚定是契约，不是图。** 你锁什么、用什么、锁多久、排除什么，四件事写不清，模型就自己决定。
2. **导演的四层是同一张谱。** 空间给关系，表演给行动，镜头给注意力，台词给动作；四层不在同一拍上对齐，长提示词也只是四段散文。
3. **长不是罪，重复是。** 好的长提示词像总谱：每一行都有声部、每一拍都有事件；坏的长提示词像复读：同一个锚点写三遍，同一个情绪换三个形容词。
