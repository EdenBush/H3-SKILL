# 导演总谱：锚定、调度、表演、镜头、台词

**这份文件的定位**：`SKILL.md` 2.1、2.6、4.x、5.x、4.8、4.11 的完整版。它回答三件事：

1. **参考图到底是什么，锚定到底是什么，H3 怎么锚定**；
2. 从导演视角，**空间调度、表演、镜头、台词**四层分别怎么写；
3. 怎么把四层串成一张**又长又准的总谱**——不是散文，是分层的电影总谱。

**一句话**：好的长提示词不是"写得多"，是**每一句都在做四件事之一**——下一个锚、放一个变量、排一个节拍、堵一个失败。做不到这四件事的句子，删。

---

# 第一部 锚定论

## 一、参考图：不是图，是语义包

### 1.1 模型看到的不是像素

参考图不是"给模型看一张图"，而是**被视觉编码器压成一个语义包，整体注入生成过程**。这个包里有脸、发型、服装、材质、姿态、光线、背景、镜头角度、画风——它们不是分开的字段，是一团互相牵连的语义。

所以你没法"只取脸、别的都不要"。所有 `supplies X only / ignore Y` 做的都是**减法**：规定这团语义里哪些允许通过，哪些必须挡掉。它是**语义过滤器**，不是像素遮罩——挡不干净是常态，挡得越具体越干净。

### 1.2 语义包里最显眼的东西，会赢

模型对一张图的注意力不是均匀的。**最显眼的结构会压过你真正想要的结构。**

| 素材 | 最显眼的东西 | 你可能想要的 | 后果 |
|---|---|---|---|
| 四视图角色卡 | 版面、站姿、白底 | 脸、服装 | 三联排、立正姿势被抄进每一镜 |
| 场景空镜 | 机位、构图、光 | 房间结构 | 所有单元同一个视角 |
| 上一镜成片 | 那一镜的构图、机位 | 上一刻的状态 | 这一单元变成上一单元的翻拍 |
| 姿势参考 | 别人的脸、衣服 | 动作、机位高度 | 身份污染、服装残留 |
| 多人物群像 | 所有人的位置 | 某个人的身份 | 多人身份互相渗透 |

**结论**：参考图管理的第一件事不是"它有什么"，是"它最显眼的是什么，会不会压过我要的东西"。压得过，就裁掉、排除、换图，或者用文字把真正要的东西重新抬到最显眼的位置。

### 1.3 一张图只回答一个问题

| 问题 | 素材 | 只准提供 |
|---|---|---|
| 世界看起来什么样 | 场景图 / 空镜 | 外观、家具、光向、材质；**不提供机位/焦段/构图** |
| 世界的关系是什么样 | 站位图 / 俯视图（可选） | 平面拓扑、家具节点、可走区域；**不提供外观** |
| 这个人长什么样 | 人设图 / 四视图 | 脸、发型、发饰、痣、服装结构；**不提供姿势/镜头/背景** |
| 上一刻发生了什么 | 成片 | 状态：谁在哪、手上有什么、眼睛看哪、光落在哪；**不提供构图/机位** |
| 这个动作怎么摆 | 姿势参考 | 动作、机位高度；**不提供身份** |
| 这个器物长什么样 | 道具图 | 形状、大小、握法；**不提供身份/场景** |

"一张图只回答一个问题"不是洁癖，是**防止语义包里的其他维度偷渡**。一张图承担两个职责，两个职责的排除项就会互相打架，模型取平均。

## 二、什么是锚定：四元组与契约

### 2.1 定义

> **锚定 = 用某个输入，把生成分布里的某个维度固定住，并声明其余维度自由。**

它不是"传一张图"，也不是"写一句描述"。它是一个**四元组**：

```text
锚定 = 维度 × 载体 × 强度 × 寿命
```

再加一个必填项：**排除**——这个锚点不准带进来的维度。

| 项 | 回答的问题 | 例 |
|---|---|---|
| **维度** | 锁什么？ | 身份 / 拓扑 / 站位 / 状态 / 轴线 / 人数 / 风格 / 光 / 运动 / 台词 |
| **载体** | 用什么锁？ | 身份卡 / 环境卡 / 站位图 / 成片 / 首尾帧 / 视频 / 音频 / 文字 / 种子 |
| **强度** | 锁多死？ | 硬 / 强 / 中 / 软 |
| **寿命** | 锁多久？ | 一帧 / 一次转场 / 一个单元 / 一场 / 一集 / 全剧 |
| **排除** | 不准带什么？ | 机位 / 构图 / 背景 / 姿势 / 画风 / 原音轨 |

### 2.2 锚定是一份契约

写锚点时，你其实在对模型说：

> **我锁 [维度] 为 [值]，用 [载体]，锁 [寿命]，排除 [污染维度]；其余自由。**

例：

> 我锁 **c3 的脸/盘发/十字耳坠/黑裙结构**，用 **`<Picture 1>` 的上半脸与服装**，锁 **整集**，排除 **白底、多视图版面、静态摆姿、棚拍光**；其余自由。

这句话同时回答了两个问题：**什么不能变**，以及**什么可以变**。后者同样重要——不声明自由，模型会把整个语义包都当成必须保留的东西。

### 2.3 锚定不是记忆，是"这次生成的条件"

H3 每次生成都是无状态的。它不记得上一单元。**锚点不是模型的记忆，是你在这一次生成里提供给它的条件。**

所以：

- 每个单元都要**重新提供**锚点，不能写"同上"。
- 上一单元成片是"上一刻的状态锚"，只活一次转场；下一单元要重新传最新一张。
- 身份卡、环境卡、文字账本是"长期锚"，可以跨单元复用，但**每个单元都要重新写进提示词**。
- 文字必须自包含：`as before` / `previous shot` / `still`（单独用）在跨条时是空词。

### 2.4 锚定不是复制，是约束采样

锚点不会把像素贴进画面。它做的是**缩小采样空间**：让模型更可能生成符合这个锚点的结果，而不是保证逐像素一致。

这解释了三件事：

1. **锚点越强，越像"只能这样"**；越弱，越像"大概这样"。
2. **两个锚点冲突时，模型不会报错，它会平均**——画面"看起来好像也对"，但两边都不像。
3. **锚点不能保证每一次都对**；种子、采样、上下文都会影响。所以要先换种子，再改锚点。

## 三、H3 怎么锚定：六种载体与可观察行为

> 下面说的是**可观察行为**，不是对 H3 内部实现的猜测。导演只需要按行为工作。

### 3.1 六种载体

| 载体 | 锁什么 | 强度 | 寿命 | 主要风险 |
|---|---|---|---|---|
| **图锚**（身份卡/环境卡/站位图/姿态卡/道具卡/成片） | 外观、身份、拓扑、状态、姿态、道具 | 强 | 一镜到整集 | 语义包偷渡：构图、光、姿势、背景 |
| **文锚**（账本/五锁/台词/风格锁） | 拓扑、轴线、人数、关系、动作、台词 | 中 | 整集 | 太长会稀释；太虚会漂 |
| **首帧 / 尾帧锚** | 第一帧/最后一帧的画面 | 最硬 | 一次转场 | 继承上一帧的瑕疵；与参考图模式互斥 |
| **视频锚** | 动作、节奏、运镜、剪辑 | 强（运动） | 一段参考 | 身份/背景/机位残留；一次只能一条 |
| **音频锚** | 音色、节奏、语气、台词 | 强（声音） | 一句/一段 | 需要一张嘴；原音轨会串入 |
| **种子** | 随机分布 | 硬（可复现） | 一次实验 | 换种子结果可能完全不同 |

> 首尾帧 / 视频 / 音频是否可用，取决于平台与模式；不可用时，用上一帧成片 + 参考图 + 文字代替，不要硬写一个平台不吃的载体。

### 3.2 图强文弱，但各管一段

从可观察行为看：

- **图锚**更容易压住身份、服装、材质、光线、姿态；但也会把构图、机位、背景一起带进来。
- **文锚**更容易压住关系、动作、时间、台词、谁在画外；但压不住毛孔级的脸和随机褶皱。
- **首尾帧**最容易压住"第一帧/最后一帧长什么样"；但会把那一帧的瑕疵一起继承。
- **视频锚**最容易压住"怎么动"；但压不住"这是谁"。
- **音频锚**最容易压住"声音像谁"；但它需要一个可见的嘴。

**所以锚定不是"图越多越好"，是"每个维度用对的载体"。**

### 3.3 可观察的五条 H3 特性

1. **多图会竞争。** 两张脸同时存在，语义会互相渗透；不是"提供两个角色"，是"提供两个可能被融合的面部分布"。
2. **没有负向分支。** `no` / `不要` 不会进入独立压制；排除句是语义过滤器，不是硬遮罩。所有约束要写成正向的确定状态。
3. **长文会稀释。** 提示词不是越长越强；结构清楚的长文强，重复啰嗦的长文弱。锚点要分层，不要复读。
4. **台词是音频-时间锚。** 一句台词同时锁嘴型、声音、语气、时间；台词越长，口型越容易漂。一句台词一个呼吸。
5. **种子敏感。** 同一提示词换种子可能完全不同；先换种子，再改锚点。

### 3.4 锚定的"有效层级"

不是所有锚点生而平等。按维度看，大致是：

```text
身份：身份卡 > 上一帧（如果它是身份源）> 文字
拓扑：账本/站位图 > 环境卡 > 上一帧（上一帧是投影，不是地图）
状态：上一帧 > 文字 > 身份卡
轴线：轴线表/账本 > 上一帧 > 文字
风格：风格锁 > 环境卡 > 上一帧
光：环境卡/账本（世界方向）> 上一帧（画面投影）> 文字
运动：视频锚 > 文字 > 上一帧
台词：文字 <d> > 音频锚 > 上一帧的嘴
```

这张表是**冲突仲裁**的基础：同一维度有两个锚点时，按这张表定谁赢；不是把所有锚点都塞进去。

## 四、锚定的八个维度

| # | 维度 | 具体锁什么 | 主要载体 | 验证 |
|---|---|---|---|---|
| 1 | **身份** | 脸、发型、发饰、痣、瞳色、体型 | 身份卡 | 每帧脸是否同一个人 |
| 2 | **服装/道具** | 服装结构、配饰、手持物、开合状态 | 身份卡 + 文字 + 道具卡 | 结构/配饰/持有者是否一致 |
| 3 | **拓扑** | 房间节点、家具、门/窗、可走区域 | 环境卡 + 账本/站位图 | 空间关系是否变 |
| 4 | **站位** | 谁在哪个 P#、朝向、距离、承重 | 账本 + 文字 | 人是否瞬移/换位 |
| 5 | **轴线/人数** | 正反打轴线、手性、帧内人数、画外名单 | 轴线表 + 文字 | 视线相反、人数不变 |
| 6 | **关系/权力** | 高低、领土、视线、谁看谁 | 调度图 + 文字 | 权力关系是否读得出来 |
| 7 | **风格/光** | 渲染、调色、焦段、光向、明暗 | 风格锁 + 环境卡 + 文字 | 画风/光向是否漂 |
| 8 | **运动/声音/台词** | 动作、节奏、运镜、音色、台词 | 视频锚 + 音频锚 + 文字 | 动作/口型/声音是否对 |

**一个维度一个主人。** 两个锚点管同一个维度，模型会平均；这不是加强，是自伤。

## 五、强度与寿命

### 5.1 五档强度

| 档 | 载体 | 行为 | 适用 |
|---|---|---|---|
| **硬** | 首帧/尾帧、精确数值 | 几乎只能这样 | 转场接续、关键帧、轴线 |
| **强** | 身份卡、环境卡、站位图 | 大概率这样 | 身份、拓扑、服装 |
| **中** | 上一帧状态、具体文字 | 大概这样 | 姿态、手、眼、道具状态 |
| **软** | 风格词、情绪词、氛围词 | 往这个方向 | 风格、氛围、情绪类别 |
| **噪声** | `beautiful` / `cinematic` / `dramatic` | 什么也没说 | 删 |

### 5.2 用最弱的足够锚

**强锚点会污染未声明的维度。** 能用文字锁住的，不要传图；能用一个文字值的，不要写一段形容词。反过来说，高方差维度（身份、拓扑）必须用强锚，低方差维度（情绪类别、氛围）用软锚就够。

### 5.3 寿命与半衰期

| 载体 | 寿命 | 半衰期 |
|---|---|---|
| 首帧/尾帧 | 一次转场 | 下一单元即失效（除非再传） |
| 上一帧成片 | 一次转场 | 一单元；越旧越错 |
| 身份卡 | 整集 | 全剧，但每单元要重写 |
| 环境卡 | 一场 | 换场即失效 |
| 站位图 | 一场/一段 | 换段即失效 |
| 文字账本 | 整集 | 全剧，但要逐字复用 |
| 风格锁 | 整集 | 全剧，逐字复用 |
| 视频锚 | 一段参考 | 一次迁移 |
| 音频锚 | 一句/一段 | 一句 |
| 种子 | 一次实验 | 换种子即失效 |

**上一帧是"状态锚"，不是"拓扑锚"。** 它只记录一个机位下的投影；换机位后，空间关系要回到账本。

## 六、冲突与仲裁

### 6.1 冲突从哪来

锚定冲突不是"两个锚点写得不一样"这么简单。它来自：

1. **同一维度两个主人**：身份卡和上一帧都声称自己是脸；环境卡和站位图都声称自己定义门的位置。
2. **语义包偷渡**：身份卡把构图带进来；环境卡把机位带进来；上一帧把整张画面带进来。
3. **强锚点压弱锚点**：图压文字；首帧压参考图；视频压文字。
4. **重复定义**：同一事实在三个段落写三遍，模型取平均。

### 6.2 仲裁顺序

同一维度冲突时，按顺序：

```text
1 维度所有权（谁是这一维度的主人）
2 强度（硬 > 强 > 中 > 软）
3 时效（最新 > 更旧）
4 显式覆盖（用户明确指定 > 默认）
```

不是"谁写得多谁赢"。

### 6.3 冲突矩阵

| 维度 | 第一主人 | 第二主人 | 永远不要让谁当主人 |
|---|---|---|---|
| 身份 | 身份卡 | 上一帧（仅当它是身份源） | 文字长描述 |
| 拓扑 | 账本/站位图 | 环境卡 | 上一帧（它是投影） |
| 站位 | 账本 Slots | 调度图 | 身份卡的姿势 |
| 轴线/人数 | 轴线表/账本 | 上一帧 | 文字"同侧" |
| 状态 | 上一帧 | 文字 | 身份卡 |
| 关系/权力 | 调度图 | 上一帧 | 风格词 |
| 风格 | 风格锁 | 环境卡 | 上一帧（除非 1:1） |
| 光 | 环境卡/账本（世界方向） | 上一帧（画面投影） | 文字"电影感" |
| 运动 | 视频锚 | 文字 | 上一帧 |
| 台词 | 文字 `<d>` | 音频锚 | 上一帧的嘴 |

**口诀：状态从成片，拓扑从账本；身份从卡，风格从锁；运动从视频，台词从文字。**

## 七、预算与槽位

### 7.1 图锚预算

| 张数 | 状态 | 纪律 |
|---|---|---|
| 2–3 | 稳定区 | 每张一个职责，排除句写全 |
| 4–5 | 可控 | 每张必须有不可替代的职责；开始删边缘图 |
| 6 | 警戒 | 准备删；同一维度不要两张 |
| 7+ | 平均区 | 同一张脸会被平均成"谁也不像" |

### 7.2 文字预算

| 任务 | 建议英文词数 | 超了先砍什么 |
|---|---|---|
| 10s，1–2 人 | 250–400 | 形容词、重复身份描述 |
| 10s，3–4 人 | 350–500 | 次要角色服装细节，保节点/人数 |
| 完整总谱（多镜/多角色） | 600–900 | 重复锚点、无 job 的镜头、无动作的台词 |

**长不是罪，重复是。** 一段话只做一件事：下锚、放变量、排节拍、堵失败。

### 7.3 锚点替代

| 想省 | 用 | 别用 |
|---|---|---|
| 多张人物站位图 | 一张站位图 / 文字账本 | 每个人一张位置图 |
| 文字描述身份 | 身份卡 | 200 词外貌描写 |
| 文字描述房间 | 环境卡 + 节点表 | 逐段复述家具 |
| 文字描述动作 | 视频锚（动作迁移） | 逐拍写舞步 |
| 文字描述声音 | 音频锚 | 用形容词猜音色 |

## 八、验证与修复

### 8.1 生成后按维度验

```text
[ ] 身份：每帧同一个人？配饰/痣/发型在？
[ ] 服装/道具：结构、持有者、开合状态对？
[ ] 拓扑：门/窗/家具/通道没换边？
[ ] 站位：谁在哪个 P#？有没有瞬移？
[ ] 轴线/人数：视线相反？帧内人数对？画外的人没进来？
[ ] 关系/权力：高低/距离/视线读得出？
[ ] 风格/光：画风/光向没漂？
[ ] 运动/声音/台词：动作/口型/声音对？
```

### 8.2 漂了先修哪一层

```text
1 换种子（先排除随机方差）
2 找维度：哪一维漂了？
3 找冲突：这一维有几个主人？
4 换载体：文字压不住 → 换图；图污染 → 换文字/裁图
5 加强度：中 → 强；强 → 硬（关键帧）
6 最后才重写整条
```

**不要用"加更多形容词"修身份；不要用"加更多锚点"修一个已经有两个主人的维度。**

## 九、锚定图谱与锚定总谱

### 9.1 锚定图谱

把剧集想成一张图：

- **节点** = 单元；
- **边** = 锚点；
- 每条边记：维度、载体、强度、寿命、排除。

```text
Unit 01 ──身份卡(c1/c2/c3, 整集)──┐
        ──环境卡(食堂, 整场)──────┤
        ──文字账本(拓扑/轴线, 整集)─┤

Unit 02 ──同上 + 上一单元尾帧/成片──→ ...
```

**提示词是这张图在某个单元上的局部投影。** 账本是这张图的文字形式；槽位是这张图的边预算。

## 十一、锚定三条铁律

1. **一个维度一个主人。** 两个锚点管同一维度，模型会平均；不是加强，是自伤。
2. **锚点越强越窄。** 强锚点会污染未声明的维度；能用弱锚解决的，不要上强锚。
3. **锚点不是记忆。** 每个单元都要重新提供；上一帧只活一次转场，身份卡/账本要每单元重写。

# 第二部 空间调度

> 空间账本（N/P/K/c/轴线）解决"在哪"；这一部解决"这个'在哪'说明了什么关系"。

## 一、空间是关系，不是背景

同一张桌子，两个人**并排坐**是同盟，**对坐**是对峙，**一个人站着俯视**是权力，**一个人从背后靠近**是入侵。空间不是背景板，是**人物关系的物理化**。

导演看空间，不看"房间长什么样"，看六张图：

| 图 | 回答 | 写法 |
|---|---|---|
| **节点图** | 门/窗/家具在哪 | 账本 N# |
| **权力图** | 谁高谁低、谁站谁坐、谁占主光 | 高度/机位/光位 |
| **领土图** | 谁拥有哪块地方、谁侵入谁 | P# 归属、距离变化 |
| **视线图** | 谁看谁、谁看不见谁 | 视线向量、遮挡 |
| **运动图** | 谁从哪进、经过哪、停在哪 | 入口/路径/停点 |
| **声音图** | 画外有什么声音、从哪来 | 鞋声/门/走廊人声 |

## 二、十个调度原则

1. **高度 = 权力。** 站着俯视坐着的人，权力立刻成立；让被压制的人坐着、压制者站着，比任何台词都直接。
2. **距离 = 关系。** 公共/社交/个人/亲密四档；一个人主动进入另一个人的个人距离，是关系的转折点。
3. **领土 = 占有。** 谁坐主位、谁靠窗、谁守门、谁占通道；侵入领土比进入画面更有戏。
4. **轴线 = 冲突线。** 两人连线是权力分界；跨轴必须靠切，不能在一个镜头里漂移。
5. **纵深 = 等级。** 前景/中景/远景不是构图，是"谁在明处、谁在暗处、谁在看着"。
6. **斜线 > 直线。** 三个人排成一条线，画面就死了；用斜线、三角、前后错位。
7. **入口 = 戏剧。** 谁从哪扇门进、什么时候进、进来后停在哪，比"她走进来"具体一百倍。
8. **房间是角色。** 柜台、窗、桌子、门框、走廊，都可以成为压力、屏障、诱惑或出口。
9. **为剪辑而调度。** 站位要能给出多个可用机位；不要把所有人物贴在一面墙上，否则只能拍正面。
10. **每一个移动都要改变权力。** 起身、坐下、靠近、后退、转身、走出画——每一个动作都要改变"谁占上风/谁被围住/谁被看见"。

## 三、调度节拍：建立 → 入侵 → 占有 → 见证 → 余波

| 节拍 | 空间发生什么 | 权力变化 | 镜头任务 |
|---|---|---|---|
| **建立** | 两个人对坐/并排，桌子是屏障 | 平衡 | 交代空间、距离、关系 |
| **入侵** | 第三人从入口进入，穿过通道，停在桌边 | 空间被打破 | 用入口/走位/高度差交代 |
| **占有** | 她坐下/俯身/侵入个人距离/勾手臂 | 她占上风 | 低角/近景/前景 |
| **见证** | 旁观者的视线、身体、筷子停下 | 关系被公开 | 反应镜/脏单/过肩 |
| **余波** | 被压制者试图恢复/失败，旁观者开口 | 新平衡/新冲突 | 三人镜/侧面/定格 |

**食堂场景的调度**：

- 建立：两个男生坐在长桌北侧，一个在左、一个在右，桌子横在镜头和他们之间；窗光从右侧来，售卖台在左侧。桌子是屏障。
- 入侵：黑裙女从右侧窗边通道进入，逆光，经过桌尾，停在右侧男生的右边。她站着，他们坐着——高度差先说话。
- 占有：她坐下，进入他的个人距离，左臂穿过他的右臂，头靠肩；桌子不再是屏障，反而把她和他围在一起。
- 见证：左侧男生隔着同伴看她，筷子停在碗上；他的视线从她→同伴→她，形成三角。
- 余波：她转头对左侧男生礼貌又占有的笑；右侧男生试图抽臂失败；左侧男生破音。

## 四、调度总谱与写法

| 拍 | 时间 | 谁移动 | 从哪到哪 | 为什么 | 权力变化 | 视线 | 声音 |
|---|---|---|---|---|---|---|---|
| 1 | 0.0–2.0 | 无 | — | 建立 | 平衡 | 室友→男主 | 食堂底噪 |
| 2 | 2.0–4.0 | c3 | 东侧通道→桌右 | 入侵 | 她出现 | 两人→她 | 高跟鞋 |
| 3 | 4.0–6.0 | c3 | 站→坐（P5） | 占有 | 她压住他 | 她→他 | 皮裙/裙摆 |
| 4 | 6.0–8.0 | 无 | — | 见证 | 室友被排除 | 室友→两人 | 筷子停 |
| 5 | 8.0–10.0 | 男主 | 试图后撤 | 余波 | 他失败 | 他→室友 | 吞咽 |

**写法**：先写 `World`（节点/光），再写 `Blocking`（谁在哪、面朝哪、距离多少），再写 `Power/Territory`（谁占哪、谁侵入谁），再写 `Sightlines`（谁看谁、谁看不见），最后写 `Movement`（从哪到哪、用了多久、为什么）。不要写"她坐在他旁边"——写"她坐在他右侧，髋部贴着他的髋，左臂穿过他的右臂，胸口距他不到二十厘米"。

## 五、调度与镜头

调度不是给一个机位看的，是给**一组机位**看的。好的调度自带覆盖：

- 一个高角能看到整张桌和三人的位置；
- 一个低角能看到站姿的权力；
- 一个侧向剖面能看到两人的距离；
- 一个脏前景能看到旁观者的反应；
- 一个插入能看到手/道具/耳饰。

**如果你调度完发现只有正面能拍，说明你把人排在了同一面墙上。** 重新排成斜线/三角/前后错位，让每个机位都有东西可拍。

# 第三部 表演总谱

## 一、表演是行动，不是情绪

> **不要演情绪，演"他想得到什么，以及他愿意为此做什么"。**

每个角色在每个节拍有四个东西：

| 项 | 问题 | 例（黑裙女） |
|---|---|---|
| **目标 Objective** | 他想要什么？ | 公开宣示"他是我的" |
| **障碍 Obstacle** | 什么挡着他？ | 室友在场、男主尴尬 |
| **战术 Tactic** | 他做什么来得到？ | 逆光进入、站高、贴近、勾臂、耳语、对室友笑 |
| **调整 Adjustment** | 对方反应后他怎么变？ | 男主僵住→她扣得更紧；室友瞪→她笑得更明显 |

**情绪是行动的结果，不是行动本身。** 你写"她很得意"，模型给你一个表情；你写"她当着室友的面把他的手扣进自己臂弯，眼睛弯起来"，模型给你一个行为。

## 二、表演总谱表

| 拍 | 时间 | 角色 | 目标 | 障碍 | 战术/动作 | 触发 | 可见反应链 | 声音 | 听者反应 | 镜头 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 0.0–1.0 | 男主 | 吃完这顿饭 | 她的出现 | 咀嚼、低头 | 鞋声 | 下颌停→眼移→吞咽 | 无 | 室友抬头 | 双人 |
| 2 | 1.0–3.4 | 黑裙女 | 宣示占有 | 室友在场 | 贴近、勾臂、耳语 | 他僵住 | 眼弯→嘴角→扣紧 | 软、近、拖尾 | 男主僵、室友瞪 | 低角近景 |
| 3 | 3.4–6.4 | 室友 | 搞清状况 | 她的气场 | 瞪、张嘴、破音 | 她的台词 | 筷子停→嘴张→眼镜反光 | 破音 | 她笑、男主耳红 | 脏单 |
| 4 | 6.4–10.0 | 三人 | 各自收场 | 彼此 | 她笑、他抽臂、室友结巴 | 筷子落 | 三人定格 | 筷子响 | — | 三人/侧面 |

**每一拍只让一个角色做主动作；其他人做反应。** 不是"三个人一起演"，是"一个人行动，其他人反应，反应又触发下一个行动"。

## 三、微表情语法

### 3.1 部位顺序

```text
眼（视线/瞳孔）→ 眼睑（上/下）→ 眉（内/外）→ 下颌 → 嘴 → 喉/吞咽 → 呼吸
```

**先眼后眉，先眉后嘴。** 顺序反了就像在"演"。同一秒最多两个部位明显变化；其余用"保持不变"锚住。

### 3.2 五个装置

| 装置 | 写法 | 效果 |
|---|---|---|
| **差一点** | `almost forms a smile, then relaxes` | 克制 |
| **冻结** | `his jaw stops, his breath holds` | 过载 |
| **失败动作** | `his hand starts to lift, then settles` | 想动但不敢 |
| **回收** | `her lips part and close again` | 欲言又止 |
| **余味** | `her eyes remain on him after the line` | 不泄气 |

### 3.3 微表情的幅度

- 只用 `micro expressions` 收幅度，不指定部位 = 幅度对了，内容空。
- 只写部位，不用 `micro expressions` = 内容有了，幅度可能过。
- **两层叠加**：`quietly hurt micro expressions` + "眼下垂→唇张又闭→吞咽"。

## 四、三股力量

强情绪不是"一个情绪"，是**三股同时存在的力**：

| 力 | 作用 | 写法 | 例 |
|---|---|---|---|
| **冲动/泄露** | 身体先出卖 | 眼眶红、吞咽、呼吸乱、手指抖 | 他耳朵红、喉结动 |
| **控制** | 意志压回去 | 移开视线、不落泪、压回哭腔、下颌紧 | 他不看她、把笑压回去 |
| **目标** | 他真正想完成的事 | 保护对方、减轻罪恶感、维持体面 | 他替她圆场、对室友摇头 |

**三股同时存在，不是从 A 变成 B。** 最强的时刻是泄露和控制同时可见，而目标决定他选哪种失败。外显只留一个；脸只出微表情，身体负责强度。

## 五、听者与群像

### 5.1 听者在演

听不是"没动作"。听者的身体在台词进行中反应：

- 手指收紧/松开；
- 下眼睑动；
- 呼吸停半拍；
- 筷子停在半空；
- 视线从说话人移到另一个人。

**台词落下才给反应，是"演完了"。** 把听者的反应插进台词的时间段里。

### 5.2 群像反应

一件事发生，在场每个人反应**类型不同**：

- 一个人后退；
- 一个人僵住；
- 一个人往前半步想看仔细；
- 一个人假装没看见。

**因果链要清楚**：因为她扑过来，所以两个人各自后退——一个错愕，一个本能。不是"所有人都做同一个反应"。

### 5.3 权力三角

三人戏不是"两个人演、一个人看"，是**三角**：

- 谁在主动；
- 谁被围住；
- 谁在见证；
- 谁看谁、谁不看谁；
- 谁的反应改变了下一拍。

## 六、表演与镜头/光/剪辑

- **镜头**：微表情要近景以内；中景只能读身体；全景只能读轮廓。
- **光**：眼底、下眼睑、嘴角需要侧光/眼窝阴影；全平光下微表情等于没写。
- **剪辑**：一个反应镜可以创造表演；一个插入（手/道具）可以替代一句台词；一个切点可以把"没演完"变成"余味"。
- **时间**：3–4 秒的关键近景要有 3–4 个有序微节拍；10 秒的单元仍按时间码拍数走，两套计数不要混。

## 七、AI 演员的边界

1. **脸的可读性随景别衰减。** 要读脸，中近景以内；不要在全景里要求微表情。
2. **中文口型需要短句。** 一句一个呼吸；超过 12 字拆段；紧特写最不稳。
3. **身份会漂。** 每个单元重申 4–6 个身份标志物；小结构（耳坠/眼镜/痣）丢失率最高。
4. **容易过火。** 情绪越强越要写"忍住"；外显给身体，脸只出微表情；全场一个最外显点。
5. **不要写 FACS/AU 编号进正文。** 用可见的解剖微动作；编号只作内部推导。
6. **不要用情绪形容词代替动作。** "她很伤心" → "下眼睑对抗湿润、喉结吞咽、视线落在桌面"。

## 八、表演提示词语法

```text
[角色] Objective: 他想要 ______。
Obstacle: ______ 挡着他。
Tactic: 他做 ______（3–4 个部位协同）。
Trigger: 当 ______ 发生时。
Visible chain: 眼 ______ → 眼睑 ______ → 眉 ______ → 下颌 ______ → 嘴 ______ → 喉 ______。
Voice: 音量/气息/语速/尾音 ______。
Listener: ______ 在台词进行中 ______。
Tail: 台词后 ______ 停在 ______。
```

**一段只写一个主动作；一段只让一个部位大类先动；每个动作写"收在哪"。**

## 九、食堂场景的表演总谱

### 黑裙女

- 目标：公开宣示"他是我的"。
- 障碍：室友在场、男主尴尬。
- 战术：逆光进入 → 站高 → 坐下侵入个人距离 → 左臂穿右臂 → 头靠肩 → 耳语 → 对室友礼貌笑。
- 触发：他的筷子停。
- 可见链：眼弯 → 单侧嘴角 → 头偏 → 手指扣紧。
- 声音：软、近、带笑、尾音落下。
- 听者：男主僵住、耳朵红；室友筷子停。
- 尾：说完不移开，笑挂在脸上。

### 男主

- 目标：吃完这顿饭、别失态。
- 障碍：她的手臂、室友的目光。
- 战术：冻结 → 吞咽 → 眼神来回 → 试图抽臂 → 失败。
- 触发：她的耳语、室友的瞪视。
- 可见链：下颌停 → 眼移 → 喉结 → 耳朵红 → 重心后撤。
- 声音：无台词；一次失败吸气。
- 听者：她扣得更紧；室友张嘴。
- 尾：筷子仍悬在半空。

### 室友

- 目标：搞清自己看到了什么。
- 障碍：她的气场、场景的荒谬。
- 战术：瞪 → 张嘴 → 看男主 → 看她 → 破音 → 筷子落。
- 触发：她的台词。
- 可见链：眼瞪 → 嘴张 → 眼镜反光 → 手松 → 筷子落。
- 声音：`嫂——嫂子？！` 第一个字破音，第二个更高更薄。
- 听者：她对他笑；男主耳朵更红。
- 尾：嘴还张着。

# 第四部 镜头总谱

## 一、镜头是叙事者

每个镜头都要有 **job**：

- 交代空间；
- 揭示关系；
- 给权力；
- 给反应；
- 给证据（手/道具/伤）；
- 给节奏（插入/空镜）；
- 给转场。

**没有 job 的镜头是装饰。** 一个 10 秒单元里，如果两个镜头做同一件事，删一个。

## 二、五个变量 + 四个附加

| 变量 | 写什么 | 语义 |
|---|---|---|
| **高度** | 贴地/胸高/眼高/顶高 | 权力、亲密、压迫 |
| **角度** | 平视/俯/仰/侧/背 | 审视、臣服、疏离 |
| **焦段** | 广/中/长 | 空间/亲密/压缩 |
| **距离/景别** | 远/全/中/近/特 | 信息量、脸的权重 |
| **运动** | 推/拉/摇/移/升降/环绕 | 注意力、揭示、跟随 |

附加：

| 附加 | 写什么 | 作用 |
|---|---|---|
| **焦点** | 锁谁/从谁到谁/耗时 | 引导注意力 |
| **前景** | 桌沿/托盘/肩/门框 | 纵深、窥视、遮挡 |
| **背景锚** | 窗墙/柜台/北门 | 防止背景漂移 |
| **轴线侧/人数** | 轴左/右、帧内几人 | 空间连续、正反打 |

## 三、镜头阶梯

### 3.1 五镜版（10 秒，群像/对话）

```text
1 建立：高角/低角宽景，交代空间与人数
2 插入：手/道具/脚/耳饰，无脸，给节奏
3 权力：低角站姿/高角坐姿/过肩压迫
4 反应：听者/旁观者的脸
5 收束：三人/侧面/定格，给余味
```

### 3.2 四镜版（10 秒，单主线）

```text
1 建立（高/低/侧）
2 插入（手/道具）
3 权力或台词（低/高/近景）
4 反应/收束（脏单/三人/侧面）
```

### 3.3 一镜版（POV/长镜）

```text
起幅：不是场景图的机位
路径：沿轴一侧移动/推进
落幅：新信息/新人物/新状态
靠焦点、呼吸、手入画维持注意力
```

## 四、覆盖语法

| 镜头 | 作用 | 注意 |
|---|---|---|
| **Master 主镜** | 交代空间/关系 | 不要用最广的、最平的；用高/低/侧 |
| **OTS 过肩** | 站在谁那边 | 肩侧=视线侧；前景肩锁住 |
| **Clean single 干净单人** | 读脸 | 背景要有空间信息，不要白墙 |
| **Dirty single 脏单** | 读脸+关系 | 前景放肩/杯/桌沿/门框 |
| **Two-shot 双人** | 关系 | 不要并排站；用前后/斜线 |
| **Three-shot 三人** | 权力三角 | 谁在中间、谁在前、谁在暗处 |
| **Insert 插入** | 证据/节奏 | 手/道具/脚/耳饰；无脸 |
| **POV** | 主观 | 主体不入画；位移写剧情 |
| **Profile 剖面** | 距离/对峙 | 避开正面；看两人之间的距离 |
| **Reflection 反射** | 疏离/双重 | 镜面/玻璃/水面 |
| **Silhouette 剪影** | 氛围/权力 | 不读脸；读轮廓 |
| **Top-down 顶拍** | 图案/命运 | 人变成棋子；不要滥用 |
| **Low angle 低角** | 压迫/英雄 | 站姿/权力 |
| **High angle 高角** | 脆弱/审视 | 坐姿/被围 |
| **Dutch 荷兰角** | 不安 | 需要 LoRA；不挂别用 |
| **Handheld 手持** | 真实/紧迫 | 幅度小；台词窗口不用 |
| **Dolly/Zoom/Pan/Arc/Crane** | 注意力/揭示 | 一个时间段一个主运镜 |

## 五、镜头语言

- **焦段**：广角=空间/压迫/畸变；中焦=客观/对话；长焦=亲密/压缩/窥视。
- **高度**：低角=权力；高角=脆弱；眼高=平等；顶拍=命运/图案。
- **运动**：推=看清；拉=揭示/离开；摇=连接；移=陪伴；环绕=审视；升降=揭示/压迫。
- **焦点**：最便宜的叙事工具；从手到眼，从前景到后景；写耗时和 `no hunting`。
- **切**：切在动作完成、反应、声音、视线；切点后要换骨架/高度。

## 六、背景锚与连续性

换机位时，选一个远端地标做**背景锚**：

- 食堂：窗墙（东）/售卖台（西）/北门；
- 办公室：窗墙/远端门/打印机；
- 宿舍：远端门/窗/桌；
- 楼外：玻璃门/台阶/侧墙。

保持它在相邻镜里的**相对大小和位置**。机位靠近/拉远要有动机，或用前景遮挡过渡。**不要出现"人没动，窗墙却变大了"**——这是机位距离没锁，不是空间错。

# 第五部 台词总谱

## 一、台词是行动

一句台词不是"信息"，是**一个人对另一个人做的一件事**：

- 试探；
- 宣示；
- 安抚；
- 攻击；
- 诱惑；
- 拒绝；
- 求和；
- 告别。

写台词前先问：**这句话想改变对方什么？** 答不出来，这句话可以删。

### 1.1 三层

| 层 | 是什么 | 写不写进提示词 |
|---|---|---|
| **文本** | 说出来的字 | 写，`<d>` |
| **潜台词** | 真正想说的 | 不直接写；转成动作/语气/停顿 |
| **行动** | 这句话对对方做什么 | 写进表演方向（objective/tactic） |

## 二、话轮设计

| 话轮 | 机制 | 写法 |
|---|---|---|
| **完整轮** | A 说完 B 接 | A 最后一个音节落下，B 半拍后开口 |
| **抢话** | B 压进 A 的尾音 | B 第一个字压进 A 最后两个字；A 嘴还动半拍 |
| **叠话** | 两人同时说 | 重叠约 0.4s；A 主音，B 更低更轻 |
| **插不进** | B 尝试失败 | 张嘴、吸气、没声；手抬一半停 |
| **沉默** | 一轮没有词 | 吞咽、移开视线、呼吸 |
| **自我修正** | 改口 | "I— 不是。算了。" |
| **失败启动** | 口型先成、声音不出 | 一次失败吸气，然后吞咽 |

**一轮只服务一个关系变化。** 不要一轮里又抢话、又沉默、又修正。

## 三、台词的音乐

| 参数 | 写法 | 效果 |
|---|---|---|
| 音量 | `barely voiced` / `a thin whisper` / `carrying voice` | 小=亲密；大=失控 |
| 气息 | `breathy` / `cracked` / `hoarse` / `tight` | 破音放第一个字 |
| 语速 | `unhurried` / `trailing` / `rushed` | 慢=掌控；快=泄漏 |
| 尾音 | `the last syllable dropping` / `rising` | 落=陈述；升=求 |
| 音高 | `low in the chest` / `thin and high` | 胸腔=稳；高薄=崩 |
| 音色 | `dry` / `wet` / `hollow` | 干燥=克制；湿=哭腔 |
| 口音/咬字 | `clipped` / `soft consonants` | 咬字=控制；含混=失控 |
| 犹豫 | `a half-beat hesitation` | 停顿=寻找语言 |

## 四、长度、呼吸与失语

- 一句一个呼吸；中文每秒 4–5 字；加 30% 余量。
- 超过 12 字拆段；拆点在语义停顿；两段之间留 0.6–0.8s 的纯呼吸。
- **不要写 `<pause>` 标签**；停顿写进正文、拆句或时间码。
- 失语落在**最难面对的词**上：口型先成、声音不出、失败吸气、吞咽、改口。
- 不要写"口吃"两个字；写身体。

## 五、台词与调度/镜头/听者/声音

- **调度**：停手说话，或说完再动；不要边大幅度走位边说。
- **镜头**：台词窗口脸可见、镜头静止、时间够；中近景以内；不要紧特写。
- **听者**：听者在台词进行中反应；台词后切反应镜。
- **声音**：台词不进 `overall_soundscape`；环境声/呼吸/吞咽进；重叠只短插话。
- **画外音**：只给声音不给词最安全；给词就可能被塞一张脸。

## 六、台词总谱表

| 时间 | 说话人 | 台词 | 目标 | 潜台词 | 话轮 | 触发词 | 声音 | 听者反应 | 镜头 |
|---|---|---|---|---|---|---|---|---|---|
| 0.9–2.6 | 室友 S1 | 你这两天怎么了？ | 试探 | 你不对劲 | 完整轮 | "怎么了" | 低、随意 | 男主咀嚼不答 | 双人 |
| 0.6–3.4 | 女主 S2 | 老公，怎么吃饭不叫我。 | 宣示占有 | 你是我的 | 完整轮（压场） | "老公" | 软、近、拖尾 | 男主僵、室友瞪 | 低角近景 |
| 5.2–6.4 | 室友 S1 | 嫂——嫂子？！ | 确认 | 这不可能 | 失败启动 | "嫂" | 破音、第二声更高 | 她笑、他耳红 | 脏单 |

## 八、食堂场景的台词总谱

### 室友的开场

- 目标：试探男主为什么走神。
- 潜台词：你不对劲。
- 话轮：完整轮；说完等半拍，男主不答。
- 声音：低、随意、嘴里还有饭。
- 听者：男主咀嚼、眼睛在碗里。
- 镜头：双人中景，镜头静止。

### 女主的主句

- 目标：公开宣示"他是我的"。
- 潜台词：你逃不掉，而且我要让他们看见。
- 话轮：完整轮，但她压着场；说完不急着收，笑留在脸上。
- 台词：`老公，怎么吃饭不叫我。`
- 触发词：`老公` 轻而近；`不叫我` 放慢、尾音落下。
- 声音：软、近、带笑、气声；不是喊，是耳语。
- 听者：男主下颌停、耳朵红；室友筷子停。
- 镜头：低角近景，脸可见，镜头静止。

### 室友的破音

- 目标：确认自己没看错。
- 潜台词：这不可能。
- 话轮：失败启动；`嫂` 破音，停半拍，`嫂子` 更高更薄。
- 声音：第一个字破，第二个字提；气不够。
- 听者：她转头对他笑；男主耳朵更红。
- 镜头：脏单，前景是男主的肩/水杯；镜头静止。

# 第六部 四层总谱（永乐大典）

## 一、总谱的结构

一张完整总谱，不是散文，是**六层对齐在同一时间轴上**：

```text
[0] 锚定总谱    维度/载体/强度/寿命/排除/冲突
[1] 世界与调度  N/P/K + 权力/领土/视线/运动/声音
[2] 人物与身份  身份卡 + 服装 + 标志物
[3] 表演总谱    目标/障碍/战术/触发/可见链/声音/听者
[4] 镜头总谱    Job/焦段/高度/角度/景别/运动/前景/背景锚/轴线
[5] 台词总谱    说话人/台词/目标/潜台词/话轮/触发词/声音/听者
[6] 时间轴      节拍 + 切点 + 台词窗口
[7] 声音        环境声 + 动作声 + 非语言人声
[8] 一致性锁    人数/状态/惯性/身份/轴线/背景锚
```

**每一层只回答自己的问题。** 空间不抢表演的活，表演不抢镜头的活，镜头不抢台词的活。

## 二、总谱模板

```text
subject_definitions:
<Subject 1> = c1 = [身份卡 + 屏幕位 + 说话人/听者]
<Subject 2> = c2 = ...
<Subject 3> = c3 = ...

[reference generation] [一句话：谁、在哪、做什么、这一条要干什么]

retention_analysis:
<Subject N>: fully_preserved — ...; attribute_transfer — ...; strictly_avoided — ...

detailed_description:
CHARACTER: [风格锁] + [每个角色的身份/服装/标志物]

POSE AND STAGING:

Slots: [c# 在哪个 P#、朝向、距离、承重、手/道具]

PERFORMANCE SCORE:
[每个角色的 Objective / Obstacle / Tactic / Trigger / Visible chain / Voice / Listener / Tail]

[说话人/台词/目标/潜台词/话轮/触发词/声音/听者]

```

## 四、总谱自检

```text
[ ] 每个维度只有一个主人？
[ ] 每个锚点都写了强度/寿命/排除？
[ ] 空间账本与调度图一致？权力/领土/视线/运动/声音都写了？
[ ] 每个角色都有 Objective/Obstacle/Tactic？每个节拍只有一个主动作？
[ ] 每个近景有 1–2 个部位变化 + 回收？全场只有一个最外显点？
[ ] 每个镜头都有 Job？相邻镜头换了高度/角度或轴线？
[ ] 第一镜不是场景图的机位？有插入/反应/脏前景/背景锚？
[ ] 台词一句一个呼吸？话轮不是排队？听者在台词中反应？
[ ] 声音/台词/口型在同一条时间轴？没有 `<pause>` 之类规范外标签？
[ ] 每一句都在做"下锚/放变量/排节拍/堵失败"之一？没有就删。
```

## 五、最后三条

1. **锚定是契约，不是图。** 你锁什么、用什么、锁多久、排除什么，四件事写不清，模型就自己决定。
2. **导演的四层是同一张谱。** 空间给关系，表演给行动，镜头给注意力，台词给动作；四层不在同一拍上对齐，长提示词也只是四段散文。
3. **长不是罪，重复是。** 好的长提示词像总谱：每一行都有声部、每一拍都有事件；坏的长提示词像复读：同一个锚点写三遍，同一个情绪换三个形容词。
